# 格内占比标准 · 无孔规格（小豆档，`hideHole`）

> **从属文件**：母体 = [`cell-standard.md`](cell-standard.md)（§1 基准口径 / §3 判据 J1–J7 / §4 变更纪律 / §5 边界，**通用真源只住母体**）。本文件只承载**无孔档**的确认值；数值与母体 r2 拆分批一致，**零新拍板**。
> 参数实现真源 = `src/config/tuning.ts`（`BEAD_DRAW_INSET_SMALL` / `BEAD_CARD.radius`）。无孔开关 = `drawFilledBead` 的 `options.hideHole`（豆径档驱动，珠面**不烘孔、live 不画孔**）。拦截判据 = `tests/bead-cell-standard.test.ts`。

| 项 | 值 | 真源 |

## 边界与关联（本档特有）

- **无孔语义**：小豆档物理上是「孔不可辨」的尺寸档，读感 = 实心豆；有孔/无孔**共用同一张风格纹理会露孔** ⇒ 若走「孔打穿 mask」方案（ADR-0028 讨论线），烘焙须出**有孔/无孔两版 mask**（色无关性质保持，成本 = 每风格 ×2，烘焙期一次性）。该实现归 ADR-0028 实现批，本文件只钉边界。
- **实心 ≠ 实心豆旧值**：`inset_small = 3` 是 WXG-T-214 重拍值（旧 `8` 为孤立值事故，母体 §4 反例段有案）。
- 底透全部由目标色环承担（无孔真透项）⇒ 环宽 4 dp 是本档**唯一** J1/J2 贡献者，改 `inset_small` 直接动底透账，走母体 §4。
