# 《拼豆》可访问性规范（Accessibility Spec）

> 项目：微信小游戏矩阵 · 第二款《拼豆填色消除》
> 版本：v1.1（demo 阶段）｜ 作者：林绘澄（可访问性）
> 配套：`art-bible.md`、`assets-spec.md`。方法论与分级体系：`my-skills/wxgame-art-spec-programmatic/SKILL.md`
> 设计分辨率 750×1334 / `FIXED_WIDTH` → **1 设计 px ≈ 0.5 pt**，88 设计 px ≈ 44pt。

---

## 1. 分级选择

三级承诺：Basic / Standard / Comprehensive。

| 分级 | 本 demo 目标 |
|---|---|
| Basic | ✅ 必须全部满足 |
| **Standard** | ✅ **本 demo 目标等级** |
| Comprehensive | 🔶 部分落地，其余延后（见 §3） |

> **结论：本 demo 承诺达到 Standard，并落地 Comprehensive 中成本低的若干项。**
> 与 breakout 一致：微信小游戏平台不支持屏幕阅读器，属平台限制，不计入本团队承诺范围。

> 对角 X 线。可辨性不受影响（非颜色通道仍在），但密度低于规格。

> **D1/E2 开关落地（2026-09-14，WXG-T-088）—— 第三次假绿根治**。此前 D1 标 ✅ 但**根本没有开关**

## 3. 落地范围小结

**本 demo 落地（15 项）**：A1 A2 A2b A3 A4 B1 B2 B3 C2 D1 D2 E1 E2（基础版）F1 F2

> D1 / E2 开关随 WXG-T-088 真实接通（此前 D1 标 ✅、E2 标 🔶 均无开关实现，属假绿；见 §2 复核）。

> A2b 为 WXG-T-080 新增（空槽目标色识别），随 T-085 落码实现。

> A4 的转真路径（留档，防再次假绿）：WXG-T-060 补三图标形状识别 → WXG-T-062 补「卡下方 28px 文字标签并列」并裁定 `assets-spec §1.4`（卡 176×150）与 `systems-index §3.1`（`POWERUP_BAND` 高 152）的几何冲突（改卡高 150→116，带位与底部留白不动）。

**落地含修正（1 项，已实装）**：C1 —— `btn_expand` 视觉 48px 高但**热区扩至 88px 高**（132×88），视觉不变。WXG-T-097/BD-15 落码：为腾出不与槽热区重叠的 88 高净空，`systems-index` 升 **v1.20**（`TRAY_BAND` 上沿 420→450、托盘面板改贴带上沿）；玩法数值与 `PUZZLE_BAND` / 网格布局**零改动**。

**部分落地**：**无**——B3 脉冲已随 WXG-T-087（GAP-10 三通道）落地，状态行于 WXG-T-093 回写；复验以 T-092 G4 探针重跑为准。

**延后（2 项）**：G2（屏幕阅读器，平台限制）、H1（符号显示开关，待用户拍板）
