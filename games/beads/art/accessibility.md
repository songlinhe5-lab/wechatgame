## 1. 分级选择

三级承诺：Basic / Standard / Comprehensive。

| 分级 | 本 demo 目标 |
|---|---|
| Basic | ✅ 必须全部满足 |
| **Standard** | ✅ **本 demo 目标等级** |
| Comprehensive | 🔶 部分落地，其余延后（见 §3） |

> **结论：本 demo 承诺达到 Standard，并落地 Comprehensive 中成本低的若干项。**
> 与 breakout 一致：微信小游戏平台不支持屏幕阅读器，属平台限制，不计入本团队承诺范围。
