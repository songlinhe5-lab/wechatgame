## §0 一句话背景

托盘空槽当前**由矢量算法固定死**：`drawEmptySocket` 的矢量臂恒画「4 层同心圆角内阴影 + S3/S4 两线」，墨档由 `neutralEndpoints(palette)` 锁死 ⇒ **美术无法自由设计托盘槽**。盘面格早已改用 tint mask（美术可美术导向的系数图）。

⇒ 本单：**给托盘出专属 mask**，把托盘从那套固定算法里解耦出来。

⚠ **2026-10-03 追加实测（原先只核了槽、漏了珠）**：`drawFilledBead` 的 tint 门同样含
`options.maskGauge !== undefined`，而托盘珠调用点**不传 `maskGauge`** ⇒ **托盘珠现在也走矢量臂**。
⇒ 托盘上**珠与槽都不碰那 4 张 mask**；`styleId` 只用于选**风格层集**，与是否用 mask 无关。
用户据此裁「乙」⇒ 范围扩为**槽 + 珠两张**。

## §1 工程侧已定的事实（美术只需知约束，不必重推）

### 1.1 托盘几何（冻结值）

| 项 | 值 |
|---|---|
| 托盘列数 | `TRAY_COLS = 12` |
| **托盘槽画布** | **`TRAY_SLOT = 48`** |
| 托盘珠绘制边长 | `TRAY_BEAD_SIZE = 44`（= 槽 − 4，**满幅、恒有孔、不随豆径档**） |
| 托盘槽坑外廓 | `48 − 2 × max(minStroke, 48 × 0.07)` ≈ **41.3dp** |
| 托盘槽墨档 | **`neutralEndpoints(palette)`**（中性，**无 per-cell 目标色**） |

ⓘ **坑 41.3dp < 珠 44dp ⇒「有豆时看不到坑」在托盘同样成立** ⇒ 托盘槽的可见面**只有空槽态**。

### 1.2 交付面 = **2 张**（槽 1 + 珠 1），各自的**归属与风格语义不同** ⭐

**托盘槽三态** ⇒ mask 只覆盖空槽：

| 态 | 现有画法 | 进 mask？ |
|---|---|---|
| **空槽（free）** | `drawEmptySocket(..., TRAY_SLOT)` | ✅ **对象①** |
| 未解锁虚位 | `drawDashedRect` 合成虚线框 | ❌ 叠加层 |
| 选中 | 抬起 4px + 状态点/环 | ❌ 叠加层 |

**托盘珠** ⇒ **对象②**（用户 2026-10-03 裁「乙」纳入）

| 项 | 托盘珠 | 盘面 holed 珠（对照） |
|---|---|---|
| 绘制边长 | **`TRAY_BEAD_SIZE = 44`**（`inset = 0`，满幅） | 26（`BEAD_DRAW_INSET 2`） |
| 圆角 | **`round(44 × 0.30) = 13dp`** | 8dp |
| 孔（`holeRatio 0.44`） | **`round(44 × 0.44) = ⌀20dp`**（孔边线 1dp 绝对） | ⌀12dp |
| 画布 | 48dp | 30dp |
| 豆径档 | **无**（满幅恒有孔） | 随档 `holed`/`holeless` |
| 是否随风格 | ✅ `styleId = snap.beadStyle` | ✅ 同 |

⇒ ⛔ **尺寸体系完全不同 ⇒ 不能复用 `bead-holed` mask**，托盘珠**必须另烘一张**。

### 2.3 ⭐ 两侧的**风格语义相反**（本单最易漏的一条）

| | mask 归属 | 换皮肤时 | 现状语义 |
|---|---|---|---|
| **托盘槽** | **中性 · 全局一张** · **不受风格白名单管辖** | **不变** | 不变 ⇒ 必须保持 |
| **托盘珠** | **随风格** · 走白名单（与盘面 `bead` mask 同性质） | **变** | 变（矢量臂也随风格）⇒ 一致 |

⇒ mask 化**不得**改变这两条 ⇒ 单测须分别钉住（见 §4 A-7 拆成两条）。
⚠ 由此产生一条**治理风险**：托盘珠的 mask 是**按风格**交付的 ⇒ 新增风格时若漏烘托盘珠 mask，
该风格的托盘珠会**静默回退矢量** ⇒ 同一风格出现**两种观感**（与 WXG-T-238 八轮修的
「`styleId` 漏传 ⇒ 珠新风格 / 槽默认风格」同族）。⇒ 见 §5 B-7。

### 1.3 与现有 mask 体系的关系

现有体系 = **`kind` × `gauge` 两轴**：`kind` ∈ {`bead`,`cell`} · `gauge` ∈ {`holed`,`holeless`}；
驱动链 `beadSize → sizeSmall → gauge → maskId = 白名单(kind, gauge, styleId)`。
**`gauge` 是「豆径档」轴、属盘面概念**；托盘珠满幅恒有孔 ⇒ **不需要 gauge 轴**。

### 1.4 尺寸与预算约束

| 项 | 值 |
|---|---|
| 烘焙 canonical | `MASK_CANONICAL_SIZE = 128`（现有四件套画布 = 格径 30dp） |
| 托盘 mask 画布 | **待裁（Q2）**：画到 48dp（**槽与珠同画布**，建议）⇒ ≈205px；只画坑口 41.3dp ⇒ ≈176px |
| 单张字节基准 | 槽 ≈ **4.8 KB**（`grid-holed` 3395 B 为下限参照）· 珠 ≈ **8.8 KB**（`bead-holed` 实测 **8750 B**） |
| **新增预算** | **≈13.6 KB**（槽 4.8 + 珠 8.8；+ 可能的 base，母体 §5「base 为条件交付」）⇒ ⚠ **须查 `systems-index §3.9` 是否超** |
| upscale 阀 | `tintUpscaleAllowed(..., TINT_LOD_MAX_UPSCALE)`，**现值 `null`（不设限）** ⇒ 画布变大须复核放大压力 |

### 1.5 编码（沿用母体，⛔ 不改）

`R = d` / `G = l` / `B = 形状` / `A = 255`；合成式 `out = base·d + (1−base)·l`（逐通道仿射 ⇒ 亮度线性）。
**托盘槽 `base` = `palette.slot`（全托盘同一个色）** ⇒ 一套 mask、**无 per-cell 目标色**。

## §3 工程侧承诺（美术交卷后）

1. **新增 `kind = trayCell` + 单档 mask**（Q1 甲）⇒ `MASK_ID_TABLE` 加一层。
2. **接线**：`view-model` 托盘调用点补传 `{ styleId = 中性槽专属键, trayZone: true }`；并**放宽 tint 臂的 `colorIdx !== undefined` 门**为「`colorIdx !== undefined || trayZone`」⇒ **这是本单唯一的结构性代码改动，须单独留痕**。
3. **画布尺寸**按 Q2；复核 upscale 压力（§1.4）。
4. **判据**：`bead-tint-arm.test.ts` 加两条 —— 「命中 ⇒ 恰好 1 blit / ⛔ 0 矢量 rect」+「漏参 ⇒ 必回退」（承八轮教训：**分流开关必须测「命中」与「未命中」两条腿**）。
5. **封箱**：托盘**每帧都画** ⇒ mask 命中会改静息帧像素 ⇒ **需第 N 次复评**（工程走官方复取器，⛔ 不手填 sha）。
6. **a11y**：只登记影响面（`[待真机]`），判定归 `accessibility.md`。

## §5 边界与风险（如实登记）

| # | 项 | 说明 |
|---|---|---|
| **B-1** | 放宽 `colorIdx !== undefined` 门是**结构性改动** | 该门隐含假设「盘面格才有目标色才能按目标色合成 mask」；托盘无目标色 ⇒ 门必须开一个显式口。⚠ 开错会让**盘面格在缺 `colorIdx` 时也去查 tray mask** ⇒ 须有反向守卫单测 |
| **B-2** | `MASK_ID_TABLE` 增维 ⇒ **白名单语义扩大** | 现 `whitelistedTintStyles()` 只认风格；新增「中性槽」后需明确它**不受风格白名单管辖**，否则换皮肤会连带换掉托盘 |
| **B-3** | 画布变大 ⇒ **upscale 回退压力** | 现 `TINT_LOD_MAX_UPSCALE = null`（不设限）⇒ 205px 画布在高 dpr 大 zoom 下会被放大；须复核是否需设限（**属工程裁量，不代裁**） |
| **B-4** | 托盘槽改 mask ⇒ **封箱必复评** | 托盘在每帧 ⇒ 静息帧像素会变（非「补画被遮住的图元」）⇒ 本单**不是**零复评单 |
| **B-5** | 「微拱白瓷」面板已有独立内阴影 | 槽内斜面若与面板内阴影不同源，接缝可能读出**两层凹陷**（与 `D1` 同族的观感风险） |
| **B-7** | **托盘珠 mask 按风格交付 ⇒ 漏烘即静默回退矢量** | 新增风格若没烤托盘珠 mask，该风格托盘珠会回退矢量臂 ⇒ **同一风格两种观感**（与八轮修的「`styleId` 漏传 ⇒ 珠新风格/槽默认风格」同族）。⇒ 须有**清单校验**：白名单里每个有 `bead` mask 的风格，是否都有 `trayBead` mask |
| **B-8** | **两侧风格语义相反**（槽不变 / 珠变） | mask 化**不得**改变这两条；若将来有人「顺手」让槽也走风格白名单 ⇒ Q7 甲的语义被推翻（且换皮肤时托盘整块变色） |
| **B-6** | 无真机 | A-10 全部 `[待真机]`；`check:size` 现为 SKIP（K-089 既有缺口）⇒ 包体这条**本轮无法机检** |
