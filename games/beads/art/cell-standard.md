# 格内占比标准（珠面 / 底色 / 孔径 / 圆角）· WXG-T-214

> **地位**：本文件是「**格子内**珠面-底色占比标准」的**唯一真源（SSOT）**，由用户 2026-09-26 逐项拍板。
> 拦截判据 = `games/beads/tests/bead-cell-standard.test.ts`（进 `pnpm test` ⇒ `verify`）。
> 参数实现真源 = `src/config/tuning.ts`（`BEAD_DRAW_INSET` / `BEAD_DRAW_INSET_SMALL` / `BEAD_CARD.radius` / `BEAD_CARD.holeRatio`）；本文只钉**确认值与判据**，不重复实现。

## 1. 基准口径（先读这个，防止算错）

| 量 | 值 | 说明 |
|---|---|---|
| 格径 `BEAD_PITCH` | **32** 设计 px | 格心距（§3.3 冻结）；B0 底图按 32 **满铺、方角**（K8 连续马赛克 ⇒ 格间**无可见缝**） |
| 格 `BEAD_CELL` | **30** = 32 − `BEAD_GAP 2` | **珠体边长基准**（不是格径！）⇒ 珠面 = `30 − 2×inset` |
| 屏幕 | ×0.5（750→375 CSS） | 1 设计 px = 0.5 CSS px ≈ 0.08 mm（~160 dpi，观看距 30 cm ⇒ 1° 视角 ≈ 65.9 设计 px） |

## 2. 确认值（两档）

| 项 | 有孔（满豆档） | 无孔（小豆档） | 真源 |
|---|---|---|---|
| 内缩 `inset` | **2** | **3** | `BEAD_DRAW_INSET` / `_SMALL` |
| 珠面（边长） | **26**（格径 **81.3%** / 格 86.7%） | **24**（**75%** / 80%） | `30 − 2×inset` |
| 孔径 ⌀ | **12** 设计 px（**6.0 CSS px**）= 珠面 **46.2%** | —（无孔，`hideHole`） | `round(面 × 0.44 / 2) × 2`，真源 `holeRatio 0.44`（Midi 实物真比） |
| 圆角 | **8** = 珠面 **30.8%** | **7** = **29.2%** | `round(面 × 0.30)`，真源 `BEAD_CARD.radius` |
| 目标色环宽 | **3** 设计 px（1.5 CSS px） | **4**（2.0 CSS px） | `(格径 − 珠面) / 2` |
| **底透面积**（环+孔，占格径²） | **516.0 = 50.4%**（环 402.9 + 孔 113.1） | **490.0 = 47.9%**（全为环） | 圆角方面积 = `面² − (4−π)·圆角²` |
| 珠色面积（占格径²） | 508.0（49.6%） | 534.0（52.1%） | 珠外廓 − 孔 |
| **珠 : 底** | **49.6 : 50.4** | **52.1 : 47.9** | — |
| 空槽坑外廓 | 21.8（坑色占格 34%） | 19.8（30%） | `珠面 − 2×relief(0.07×格径)` |

> ⚠️ **取整偏移须知情**：孔径/圆角按整数 px 落地后，实际比率 ≠ 设计常量——孔 0.44 → **46.2%**（+4.9%）、圆角 0.30 → **30.8% / 29.2%**。这是「像素取整」与「比率精确」二选一的既定选择（用户拍板：取整）。改回比率精确 = 撤销「孔径偶数 px」裁定，须走 §4 变更纪律。

## 3. 拦截判据（J1–J7，全部可自动执行）

| # | 判据 | 门槛 | 性质 |
|---|---|---|---|
| **J1** | 目标色环宽 | **≥ 2 设计 px（1.0 CSS px）** | 可见性地板（×0.5 屏上半像素环不可见） |
| **J2** | 底透面积 / 格径² | **≥ 30%** | ⚠️ **代理指标**：几何可算、防"珠吃满格"；**不是感知标准**（辨色样本的感知门槛另见 §5） |
| **J3** | 坑 ⊂ 珠（包围盒包含，含圆角） | 严格小于 | 用户裁定「坑永远比豆小一圈，有豆时看不到坑」 |
| **J4** | 孔径 | **偶数整数设计 px**；真源 `holeRatio` 派生末端取整 | 用户裁定；半径取整 ⇒ 直径恒偶数 |
| **J5** | 珠面 / 格径 | **≥ 70%**（"豆子基本覆盖格子"） | 两档 81.3% / 75% |
| **J6** | 珠 : 底 | **∈ [40:60, 60:40]** | 格内两块样本都够大、不悬殊（错豆检测形态） |
| **J7** | `inset` 与 `holeRatio` 成对变更 | 同批提交 | 互为对冲（assets-spec §1.10.9 硬约束②） |

配套既有判据（不重复实现，列锚点）：坑⊂珠 包围盒（`bead-render.test.ts`）· 孔径取整+偶数（`bead-render` / `ledger` / `fill-pop`）· 豆径档作用域（凹槽随档恒⊂珠，`bead-style-settings.test.ts`）· C12 钉值（`bead-style-pool.test.ts`）。

## 4. 变更纪律（⛔ 本节是硬约束）

**任何 J1–J7 的值或门槛修改，必须同批提供：**

1. **调研数据**：改前/改后对照图（`temp/` 出图，标注孔径/环/坑，同帧同源）+ 面积账（按 §1 口径计算，方角近似**不认**，须含圆角修正）；
2. **原因说明**：为什么现值不满足（哪条判据失效 / 哪个真机反馈）；
3. **判据与文档同批更新**：`bead-cell-standard.test.ts` 钉值 + 本文 §2/§3 同步，⛔ 只改代码不改文档 = 判红即假绿；
4. **台账登记**：`production/TASKS.md` 任务行 + 影响面（封箱腿 1/3 属珠体族，须走 `§K.5.1` 复评归因通道，⛔ 禁自更新基准）。

> 反例提醒（已发生）：`BEAD_DRAW_INSET_SMALL = 8` 曾是「2 倍满豆内缩」规则的产物，满豆改 2 后规则失效、8 变孤立值，豆面缩到 43.8% 读不出色——这就是"无调研的顺手继承"的下场。

## 5. 明确不在本标准内（防越界）

- **颜色区分辨识度**（等亮度色对、色觉障碍、WCAG 3:1 对比度门）：**单开话题调研**，结论出来前不在本文件立门；
- **相邻格可辨**（跨格的色块/图案可读性）：同上；
- 感知类门槛（视角/mm）：本标准只有 J2 一条**代理指标**，面积 ≠ 感知——单颗珠面 0.39° 视角低于 ~0.5° 小视野辨色可靠区，**孤立辨色不可靠、同色连片 ≥3×3 格（1.46°）才够**，此结论供后续调研引用，不是本标准的门。
