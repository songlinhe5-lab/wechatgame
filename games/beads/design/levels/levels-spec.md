- 项目：`games/beads`（拼豆填色消除）· 版本 v1.0 · 任务号 WXG-T-015

- 消费方：S3（图案矩阵）、S4（供料间隔/杂色）、S5（时限）、S1（BOOT 校验装配，architecture-beads §6）

## 1. 文件结构总览

```
LevelsFile（levels-01-08.json）
├─ version: 1            数据结构版本
├─ gameId: "beads"
├─ description           元信息
└─ levels[]              8 个 LevelDef（ADR-0004 形态）
     ├─ id / name        序号（1..8 连续）/ 显示名
     ├─ cols / rows      网格尺寸（rows = pattern 行数，冗余自检字段）
     ├─ time             本关倒计时秒（合法区间 [180,420]，来源 §3.5）
     ├─ spawnInterval    供料间隔秒（合法区间 [2.0,6.0]，来源 §3.4）
     ├─ decoys           杂色索引数组（≤ DECOY_COLORS_MAX=2，且 ∩ 图案色 = ∅）
     └─ pattern[]        行字符串数组，字符集 BEAD_CHARSET = `.x1-9A`
```

**字符集语义**（来源 §3.2，2026-09-12 澄清）：`.`=空位（无图案位：不可填、不计完成、渲染为空白）、`x`=锁定格（不可填、不计完成，渲染为斜纹收边）——`.` 与 `x` 运行时语义同为 `locked`，差异仅在表现层；`1-9`+`A`=色板索引。

**色板对照**（索引 → `art/art-bible.md` §3.2 十色，demo 只用 1–8）：
1=奶白　2=柠黄　3=活力橙　4=草绿　5=玫红　6=丁香紫　7=湖蓝　8=赭棕

## 2. 单关字段与硬约束（BOOT 校验，architecture-beads §6）

| 约束 | 值/规则 | 来源 |
|---|---|---|
| 尺寸 | `GRID_MIN_COLS`(6) ≤ cols ≤ `GRID_MAX_COLS`(13)；`GRID_MIN_ROWS`(5) ≤ 行数 ≤ `GRID_MAX_ROWS`(12) | §3.3 |
| 字符集 | pattern 每字符 ∈ `BEAD_CHARSET`；每行长度 === cols | §3.2 |
| 色数 | pattern 去重色数 ∈ [3, `BEAD_COLOR_MAX`(8)] | §3.2 |
| 锁定格 | `x` 不计完成；关卡须 ≥1 可填格（全部关卡满足，x 仅装饰） | core-loop §6 / §3.2 |
| 时限 | time ∈ [180, 420] | §3.5 |
| 供料 | spawnInterval ∈ [2.0, 6.0] | §3.4 |
| 杂色 | decoys.length ≤ `DECOY_COLORS_MAX`(2)，且与 pattern 用色**无交集** | §3.2 |
| 图案 | **全部原创**（房屋/爱心/动物/器物剪影），禁用任何第三方 IP 图案 | 参考分析 §8 |

校验器形态沿用 breakout `validateLevel()` 判例（错误信息含关卡 id + 行列 + 违规字符）。

## 5. 难度与时长预估（待 playtest 校准）

- 手速假设：2–3 秒/珠（含选珠）。预估清关 = 可填格 × 2.5s ± 容差：L1 ≈ 55s … L7 ≈ 198s、L8 ≈ 163s。

- 失败重开零惩罚（D7），冲刺模式另见 `gdd/score-combo.md`。

## 7. 关卡设计约束（新增关卡必须遵守）

1. 字符集限定 `BEAD_CHARSET=".x1-9A"`，其余字符（含空格/小写/0）均为错误——校验器报错到 id+行+列。
2. 每关只引入一个主新变量（支柱 3；对照 §3 表"新变量"列）。
3. 色数 ∈ [3, 8] 且 ≤ `BEAD_COLOR_MAX`；索引 9/A（深棕/炭黑）demo 关卡**暂不使用**（为 v1.1 色数 >8 扩展预留，ADR-0004 复评条款）。
4. decoys 与图案色无交集；数量 ≤ `DECOY_COLORS_MAX`。
5. 图案原创；异形轮廓靠 `.` 空位塑形，`x` 仅作视觉收边/教学，≤8 枚/关。
6. time ∈ [180,420]、spawnInterval ∈ [2.0,6.0]，越界即 BOOT 拒绝。
7. 可填格 ≥1 且预估清关时长 ≤ time×0.85（防结构性不可通关；预估法见 §5）。

## 8. 校验分工

与 breakout 判例一致（breakout `levels-spec.md` §5.1）：**结构校验**（字符集/行宽/行数/色数/区间/杂色交集）归 BOOT 期 `validateLevel()` 单一权威；**跨关/玩法校验**（§7 约束 2/7、难度单调性）归 QA 脚本；运行时合法性归 S1/S3。错误信息格式：`L{id} row{i} col{j}: ...`。

sprint 梯级图案从本文件 8 关图案池**循环取用**（`gdd/score-combo.md` §2.3），不另建图案库；梯级参数由公式生成（score-combo 附录 C6，已于 2026-09-12 用户拍板冻结，真源 `gdd/systems-index.md` §3.10——色数/格数为该阶上限预算，实际棋盘取池图案本身，见 score-combo §9 C6 设计说明），不改本 JSON。
