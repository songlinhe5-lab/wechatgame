## 1. 设计原则（沿用 skill 四条 + 本系统一条）

1. **首屏即玩**：演示与回放**不进入首 10 秒关键路径**；首屏仍直进玩法。
2. **拇指可达**：回放传输控件放屏幕下 1/3；回放入口在结算面板下方，独立小钮。
3. **反馈即语言**：回放页用「播放/暂停/倍速/进度」四个自解释控件，不写教学长文。
4. **随时可走**：回放页左上角 88×88 退出；托管可随时暂停并关闭。
5. **回放不是第二套玩法**：回放页只读、零玩法输入；所有视觉语言复用现有玩法四带，避免玩家误以为可操作。

## 2. 界面流程（Screen Flow）

```
主菜单 ──「演示」──► 无头生成 bot-demo（≤1.5s，失败轻提示回菜单）
   │                         │ 成功
   │                         ▼
   │                  REPLAY(source='bot-demo')
   │                         │ 播放结束 → 演示结束条
   │                         │   ├─「再看一遍」→ 从头播放（不重生成）
   │                         │   └─「退出」→ 回主菜单
   │
玩法·PLAYING(assist='off'|'bot') ⇄ 暂停面板（含「托管」开关）
   │
   └─ 错位珠全部归位 ──► LEVEL_CLEAR（ClearPanel）
                              ├─「下一关 / 查看结果」→ 既有分支
                              ├─「回主菜单」→ 既有分支
                              └─「回放」──► REPLAY(source='own-last')
                                                ├─ 播放结束 → 回放结束条
                                                │    ├─「重播」→ 从头播放
                                                │    └─「退出」→ 回 LEVEL_CLEAR
                                                └─ 左上「退出」→ 回 LEVEL_CLEAR
```

- `GAME_OVER` / 冲刺结算 / `FINISH`：**不画**回放/演示入口（有意为之，非遗漏）。
- 回放退出回 `LEVEL_CLEAR` 时，`ClearPanel` 立即恢复可点，**不重播星入场、不二次发豆**。
- 演示生成期间菜单显示轻量 loading（不遮全屏；时长目标 `[TODO]`，与 BOOT 加载同预算但不冻结；失败回菜单轻提示）。

```
┌──────────────────────────────────┐  560×240，x∈[95,655]，y∈[420,660]
│           回放结束 / 演示结束       │  标题中心 (375,620)

│   │  重播/再看 │   │   退出    │    │  x∈[143,363] / [387,607]
│   └──────────┘   └──────────┘    │
└──────────────────────────────────┘
```

- `source='own-last'`：标题「回放结束」，主钮「重播」，次钮「退出」。
- `source='bot-demo'`：标题「演示结束」，主钮「再看一遍」，次钮「退出」；副文案「机器人完成了第 1 关」。
- **演示结束条本身就是回放入口**：「再看一遍」= 对同一份内存录像从头播放（不重新生成、不改 seed）；不另设第二个「回放」钮。
- 播放到尾自动出现；不自动循环、不自动退出。
- 条外点击零响应（结束条是唯一可点区）。

| 元素 | 位置 / 几何 | 说明 |

- 托管开启：HUD 徽标淡入 200ms；关闭：淡出 150ms。
- 托管中玩家点棋盘/托盘/道具卡：**取消托管并消费该次点击**（不产生玩法指令），轻提示「已接管」；HUD 齿轮仍正常暂停。
- 徽标不做呼吸/闪烁（避免与告急脉冲混淆）。

| 回放页退出 | 淡出 + 下移 12px，ease-in | 无 | 150 |
| 播放/暂停钮按下 | scale 0.94→1.00；图标即时切换 | 无（复用现有 UI 点击音若已有） | 120 |

| 结束条退出 | 淡出，ease-in | 无 | 150 |
| 托管徽标进入/退出 | 淡入/淡出，无位移、无脉冲 | 无 | 200 / 150 |

- 倍速只缩放**回放动画**的呈现时长，不改变 `systems-index §5` 的权威毫秒值；这些值在实时玩法中不变。

## 6. 首屏留存策略（微信前 10 秒）

- **不变**：启动 → 读档 → 直进玩法；演示/回放/托管都不在首 10 秒关键路径，不自动播放、不遮挡首屏。
- 演示入口定位 = 主菜单的**次级入口**，服务「看不懂玩法 / 想先看一局」的玩家；不打断首局。
- 托管入口在暂停面板内，首次进关不提示、不自动开启；避免玩家误以为游戏在代打。
- 回放入口只在过关结算出现；失败页不出现（用户拍板），避免失败时增加认知负担。
- 启动路径表（本系统只加一列，不新增落地页）：

| 玩家类型 | 落地页 | 本系统提示 |
|---|---|---|
| 首次进入 | 玩法 L1 | 无（演示入口不弹） |
| 有进度 | 最远关 | 无 |
| 主动好奇 | 主菜单 | 「演示」次级钮 |
| 卡关 | 暂停面板 | 「托管」开关行（不自动开） |
| 刚过关 | ClearPanel | 「回放」入口钮（面板下方） |

## 8. 决策记录与待确认项

### 8.1 已裁定（本单建议，待用户最终确认）

| # | 决策 | 备选与推荐理由 |
