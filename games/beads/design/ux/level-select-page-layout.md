# UX 版式确认单 · 选关整页（版式 P）· beads

- 项目：`games/beads` · 版本 **v0.3** · 日期 2026-10-20 · 状态：**数值已冻结、已落码**（版式 = 用户 2026-10-20 裁定；v0.2 = **WXG-T-310 回写批**：§4 六条清零、§3 与主规格 v1.6 对表完成；v0.3 = **WXG-T-311 落码回填**：§5 状态与 §2 常量落位据实更新，数值**零变动**）
- **缘起**：[ADR-0032](../../../../docs/architecture/adr/ADR-0032-beads-ui-architecture.md) D5 把选关从「弹窗」改为「整页」；[`arc-level-select-spec.md`](arc-level-select-spec.md)（v1.5）的线框、遮罩、面板进出场都是按弹窗写的，需要一份整页版式确认。该主规格已超 8KB 门并靠分片维持，所以本单独立成文，**不往主规格里塞**。
- **本文射程**：只管「`levels` overlay → 选关页」的版式、进出场与受影响条目；格状态矩阵、点格行为、扣心与 0 心处理等**逐条沿用主规格**，不重开。
- **落码已完成（v0.3 · WXG-T-311）**：§2 数值已写进 `tuning.ts` 页专用 `LEVELS_*` 九项（格 170 / 距 30 / 网格左缘 90 / 网格顶 822 / 缩略 134 / back 240×88@116 / 导航带 88@1210）；`WALL_CELL`（120）/ `WALL_CAPACITY`（9）/ `THUMB_AREA`（84）**零改动**。

| 网格范围 | x∈[90,660]，y∈[252,822]，3×3 | 列左缘 x=90 / 290 / 490；行 y 区间 [652,822] / [452,622] / [252,422] |

## 4. 待核与待裁（v0.2：六条已清零，逐条记录见 §4.1）

1. **美术规格回写**：版式 P 的格 / 间距 / 网格范围是美术自有的版面派生值（`systems-index §3` 里没有 `WALL_*`，正本在 [`menu-wall-signage-spec.md`](../art/specs/menu-wall-signage-spec.md)，注明「不进 §3」）⇒ **不需要 §3 变更单**，但要先回写该美术规格再落码。
2. **不要直接改 `WALL_CELL`**：`THUMB_AREA` 由它派生，并是 `drawLevelThumb` 的缺省缩略区；直接改会连带影响其它走缺省值的调用。整页应**新增页专用常量**（命名由工程定），`WALL_CAPACITY` 等容量口径不动。
3. **格轮廓对比度复核（美术）**：去掉纸面板后，格底对页面底约 1.13:1、描边对页面底约 1.18:1（有纸面板时 1.05 / 1.41）。两者都远低于 3:1，但规格的 3:1 只针对星带符号，不阻塞；需美术在整页底上看图确认轮廓可读，必要时再议描边。
4. **缩略图放大后的清晰度**：缩略区从 84 放大到 134；若走预烘位图臂，需核对位图分辨率是否够用（程序化臂无此问题）。
5. **星带 28 / 顶内缩 8 是否同比放大**：美术裁。
6. **主规格回写**：版式落码时由设计策略把本文 §3 的「作废 / 改写 / 订正」同步回主规格（含注 B 订正），归 ADR-0032 对应 TODO 的文档回写项。

## 5. 对架构方案的影响

- **导航栏**：增加「仅标题」用法（无返回键），选关页以此使用；返回仍由底部 `back` 提供。
- **UI-34**（选关整页）：前置 = 本单 §4 第 1–2 条（**v0.2 已清零**）；验收版式 = 本单 §2（数值已冻结），另以 §4.1 为回写证据链。**已落码（WXG-T-311，2026-10-20）**：`levelsLayout()` 按 §2 重算、`buildMetaView` 增整页分支（无遮罩 / 无纸面板）、缩略改传 134；标题带顶缘读逐机 `anchors.btTopY`、兜底 1210。
- **转场**：整页进出走框架弹窗生命周期同一套 200 / 150 计时，不新增计时机制。⚠ **尚未实现（WXG-T-311 披露）**：现 `meta` overlay 无转场机制、`meta:overlay` 事件无监听者，UI-34 验收也未列该项 ⇒ 登记为 UI-42（PhaseRouteBinder）遗留；期间进入/离开为硬切。
