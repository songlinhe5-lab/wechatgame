**判星对照行的四条口径（v0.6 · WXG-T-356，用户 2026-10-23 裁 A 改道）**：

1. **为什么不在格内**（v0.5 作废的实测依据）。无障碍 floor E1「文字最小 28 设计 px」，22px 已在 v1.3 F7⑤ 作废（`art/specs/accessibility.md` E1 行）；**浏览器实测**（Chrome 155 headless，canvas `measureText`，字面 = 渲染层实际用的 `Npx sans-serif`）：三颗实心星 = **整 3 个 em**（22 / 28 / 35px ⇒ 66 / 84 / 105），`≤mm:ss` 在 28px = **96.66**、22px = **75.94** ⇒ 格内右栏**全 28px = 180.66 > 格宽 170**（含左右内缩 10×2 需 **200.66**）；即便星符按 §3.9① 留 22px、只把时间升 28px，= **162.66**，加内缩仍 **182.66 > 170** ⇒ **「同带左右分栏」在任何合规字号组合下几何都不成立**（唯全 22px 才塞得进：141.94 + 20 = 161.94，但破 E1）。且 `menu-wall-signage-spec §3.9①` 的 22px 只裁给**星符号**、不裁给数字文本，且与 `menu-layout-implementation-spec §10`（WXG-T-346 正是把**本页**章名下方那行从 `cell` 22 升到 28、并设了防回退守卫）逆向 ⇒ 故 v0.5 作废、这一行改住空带。**口径来源沿革（K-053）**：本段 2026-10-23 早先按 em 比例估算（178 / 142 / 162），同日已用浏览器实测换真值——估算与实测差 ≤ 3px、结论同向，故估算值不再作判据，只作史证。
2. **只一行，且与结算面板共用同一条串构造**。文案 = `3★ 用时 ≤ mm:ss ｜ 2★ 用时 ≤ mm:ss`，收进 `view/ui-theme.ts::starCriteriaText(levelTime)` 作**唯一真源**（结算面板 v1.23 与本行共调它 ⇒ ⛔ 第二套判星式、⛔ 第二套文案）；1★ 无用时门槛（打完即算）⇒ 本行不写，与 v1.23 同口径。
3. **拿不到当前关引用 ⇒ 不建节点**。数据腿 = `wallSlots.indexOf(currentLevelIndex)` 取槽 → `wallLevels[槽].time`（≤9 元素一次线性查找、零分配 ⇒ 不破热路径纪律；视图 ⛔ `import { LEVELS }`）。查不到（−1 / 越界 / 宿主未下传 `wallLevels`）⇒ **整行不画**，⛔ `--:--` 占位（兜底不猜测，与 §11.4 R2 / WXG-T-340 同精神）。
4. **零新常量、零热区，且随大字模式**。行位 = 带中心再下移 `LEVELS_NAV_H`（= 972 − 88 = **884**），派生自既有常量（章名 972 / 进度件 928 / 本行 884）⇒ 三行都落在空带 [822,1122] 内，带高 300 不用放大；字号 `bodyFont(largeText,'sub')` ⇒ E2 开 = 35px（v0.5 那条「大字模式不放大本行」的缺口随改道**自然消解**）。串宽**实测**：28px 档 10 关最宽 = **497.5**（L00001 最宽；各关只差数字字形宽，全距 22.3px）⇒ 左右各余 **126.3**；E2 35px 档 = **621.9**（最窄 594.0）⇒ 各余 **64.1**；宽字族上界（Verdana，字宽较 `sans-serif` 宽 5.3%）35px = **655.0** ⇒ 各余 **47.5**，仍 **不越画布 750**。原「估 ≈ 580 / 余 ~85」**已作废**（实测宽 42px，估偏低 6.7%）。⛔ 新热区、⛔ 动效、不参与命中。

## 4. 待核与待裁（v0.2：六条已清零，逐条记录见 §4.1）

1. **美术规格回写**：版式 P 的格 / 间距 / 网格范围是美术自有的版面派生值（`systems-index §3` 里没有 `WALL_*`，正本在 [`menu-wall-signage-spec.md`](../art/specs/menu-wall-signage-spec.md)，注明「不进 §3」）⇒ **不需要 §3 变更单**，但要先回写该美术规格再落码。
2. **不要直接改 `WALL_CELL`**：`THUMB_AREA` 由它派生，并是 `drawLevelThumb` 的缺省缩略区；直接改会连带影响其它走缺省值的调用。整页应**新增页专用常量**（命名由工程定），`WALL_CAPACITY` 等容量口径不动。
3. **格轮廓对比度复核（美术）**：去掉纸面板后，格底对页面底约 1.13:1、描边对页面底约 1.18:1（有纸面板时 1.05 / 1.41）。两者都远低于 3:1，但规格的 3:1 只针对星带符号，不阻塞；需美术在整页底上看图确认轮廓可读，必要时再议描边。
4. **缩略图放大后的清晰度**：缩略区从 84 放大到 134；若走预烘位图臂，需核对位图分辨率是否够用（程序化臂无此问题）。
5. **星带 28 / 顶内缩 8 是否同比放大**：美术裁。
6. **主规格回写**：版式落码时由设计策略把本文 §3 的「作废 / 改写 / 订正」同步回主规格（含注 B 订正），归 ADR-0032 对应 TODO 的文档回写项。
