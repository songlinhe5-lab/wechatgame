## 1. 设计原则（沿用 skill 四条）

1. **首屏即玩**（**v1.14 反转 · #1 WXG-T-180**：原红线推翻，**首屏改停主菜单**——启动不再直进玩法、不自动扣心；主菜单含选关列表，进关 ≤ 2 次交互仍成立（菜单→开始/选关）。详见 §6.3 v1.14 注）：~~启动 → 进关 ≤2 次交互，无登录无授权~~（**v1.7 更正（WXG-T-164 反转）**：主菜单已恢复但曾为非启动落地页——启动直进玩法不变；菜单入口 = 暂停面板次钮「回主菜单」；原「core-loop 判例：无主菜单」括注作废）。
2. **拇指可达**：托盘/道具/扩展全在屏幕下 1/3（`TRAY_BAND`+`POWERUP_BAND`），信息区（HUD）在顶部。
3. **反馈即语言 · 0 文字教学**（**GAP-03 已裁定，WXG-T-081，取 (a) 项**）：落座 / 拒绝 / 连击 / 告急 / **新手引导**一律走动效+音效通道，玩法界面**不出现任何教学文字气泡**（原 §6 的「气泡 1『点托盘选珠』/ 气泡 2『同色入格』」**作废**，与本条不可两读）。
   - **引导载体**（v1.4 随「错位归位」更新；**⚠️ v1.5 更正 E4 口径（WXG-T-128，2026-09-17）**——E4 幽灵符号**非「已移除」**：v1.23 Q5 已裁定将其**转为设置开关（默认关）、死路径转正、进 MVP**，`EMPTY_GHOST_ALPHA` 0.32 **恢复有效**（真源：`proposals/v1.23-bold-remake.md` §1 Q5 + `systems-index-changelog` v1.23 **(f)** 条）⇒ 以下三条为**默认态（开关关）**的引导载体，**开关开启时 E4 符号作为色觉冗余通道回归**（`accessibility` A2b/A3 须**分侧核算**）；E1 改纯色直填不变）：① **错位珠本身即谜面**——颜色≠底色的视觉冲突是「找出要动的珠」的无文字表达（就位珠 vs 错位珠的可读性由 WXG-T-131 质感规格承载：就位=凸起高光、空格=凹陷内阴影）；② `hint` 态（`accent_blue` 2px 外描边 + 600ms α 0.5↔1.0 呼吸）把注意力收敛到单一目标（落点格/托盘槽）；③ 托盘空槽脉冲（取回落点）；④ **满槽无落点 ⇒ 指向直填**（v1.30 新增，上位 = `forensics/wxg-t-182-g3-derangement-deadlock.md` §2「可发现性风险」行 + §3 Q1 代价条 + §4 B3）：触发态 = **托盘已满**且**选中态点洞被拒**（`_placeSelected` 返回 false，即 G-3 取证里唯一需要玩家自己发现逃生道的入口）⇒ 把②号载体的 `hint` 态（同一套 `accent_blue` 2px 外描边 + 呼吸，周期复用既有 `tuning/motion::HINT_PULSE_MS`，**零新毫秒值、零新色值、零新容器**）打到**该珠色可直填的错位格**上 ⇒ 拒绝反馈之外，视线被引回棋盘；托盘扩展钮此时走 §3.1 既有态，**不另造提示**。~~**[未实现]**：本条为规格先行，`src/` 无对应分支~~（v1.30 落笔态，划线留档不静默删，K-053）→ **[已实现 · v1.31]**：`beads-game.ts`（满槽色拒闩锁，落子成功即复位）+ `snapshot-projection.ts`（载体④ 分支，与引导①共用同一份行主序扫描）+ `play-page.ts`（去 `snap.onboarding` 渲染门）；判据 = `tests/snapshot-projection.test.ts`「载体④」两条（入 QA `§A3b` 的 TC-G3-6）。**不新造气泡容器**（沿 GAP-03 裁定）。

   - **边界澄清**：本条只约束「教学文字」。按钮标签（继续/重玩本关/下一关/重试本关）、面板标题、道具卡 28px 文字标签（`accessibility` A4 硬要求）**不属教学文字**，不受本条约束。
4. **随时可走**：任意玩法状态 1 次点齿轮暂停；进度自动存档（S8），下次续进。
