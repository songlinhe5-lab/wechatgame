## 1. 设计原则（沿用 skill 四条）

1. **首屏即玩**：启动 → 进关 ≤2 次交互，无登录无授权（**v1.7 更正（WXG-T-164 反转）**：主菜单已恢复但**非启动落地页**——启动直进玩法不变；菜单入口 = 暂停面板次钮「回主菜单」（≤2 次交互），见 §2 / §6.3；原「core-loop 判例：无主菜单」括注作废）。
2. **拇指可达**：托盘/道具/扩展全在屏幕下 1/3（`TRAY_BAND`+`POWERUP_BAND`），信息区（HUD）在顶部。
3. **反馈即语言 · 0 文字教学**（**GAP-03 已裁定，WXG-T-081，取 (a) 项**）：落座 / 拒绝 / 连击 / 告急 / **新手引导**一律走动效+音效通道，玩法界面**不出现任何教学文字气泡**（原 §6 的「气泡 1『点托盘选珠』/ 气泡 2『同色入格』」**作废**，与本条不可两读）。
   - **引导载体**（v1.4 随「错位归位」更新；**⚠️ v1.5 更正 E4 口径（WXG-T-128，2026-09-17）**——E4 幽灵符号**非「已移除」**：v1.23 Q5 已裁定将其**转为设置开关（默认关）、死路径转正、进 MVP**，`EMPTY_GHOST_ALPHA` 0.32 **恢复有效**（真源：`proposals/v1.23-bold-remake.md` §1 Q5 + `systems-index-changelog` v1.23 **(f)** 条）⇒ 以下三条为**默认态（开关关）**的引导载体，**开关开启时 E4 符号作为色觉冗余通道回归**（`accessibility` A2b/A3 须**分侧核算**）；E1 改纯色直填不变）：① **错位珠本身即谜面**——颜色≠底色的视觉冲突是「找出要动的珠」的无文字表达（就位珠 vs 错位珠的可读性由 WXG-T-131 质感规格承载：就位=凸起高光、空格=凹陷内阴影）；② `hint` 态（`accent_blue` 2px 外描边 + 600ms α 0.5↔1.0 呼吸）把注意力收敛到单一目标（落点格/托盘槽）；③ 托盘空槽脉冲（取回落点）。**不新造气泡容器**（沿 GAP-03 裁定）。
   - **依赖登记（诚实口径，不得当已成立用）**：**⚠️ 本段取证已于 2026-09-17 更正（WXG-T-128 主理人复核；原取证为误报，结论仍真但根因不同）**。原文称「①②③ 在 `src/`、`src/view/` **全部零实现**（`EMPTY_TINT_MIX`/`EMPTY_GHOST_ALPHA`/`hint`/脉冲均 grep 零命中）、`accessibility` A2 把 `hint` 标 ✅ 属**假绿**须回写」——**经主理人独立实测不成立**：`EMPTY_TINT_MIX = 0.42`（`palette.ts:203`）与 `EMPTY_GHOST_ALPHA = 0.32`（`:209`）均已定义且被消费；`hint` **已实装**（`view-model.ts:449` `hintAlpha()`、`:701-702` `drawStateRing(builder, bx, cy, BEAD_CELL, palette.hintBlue, hintAlpha(...))`）；`drawLockedBead` 已于 `:692` 调用；`drawEmptySocket` 网格侧 `:699` **传** `cell.colorIdx`（E4 在画）、托盘侧 `:765` **不传**（无 E4 ⇒ 托盘空槽代码真值 1 层）⇒ **`accessibility` A2 的 ✅ 不是假绿，原「须回写」结论作废**（取证纠错人 = 林绘澄，主理人已复算验真）。
     **但「§6 引导路径不成立」的结论仍然为真，根因由「零实现」改写为「循环依赖」**：引导目标派生自**托盘当前持有的最前一颗珠**（`beads-game.ts:2316-2342`，E2 落码后行号），而 v1.22 定时供料关停 + 托盘初始为空 ⇒ `guideSlot = -1`、`firstColor = -1` ⇒ 走 `:2341-2342` 分支使 `hintRow/hintCol` 恒 `-1` ⇒ **开局引导环永不渲染**；而「取回」操作又要求玩家**先认出错位珠** ⇒ **循环依赖**（引导需托盘有珠 → 托盘有珠需玩家先取回 → 取回需引导）。**解除条件**：引导目标改派生自**棋盘错位珠**（而非托盘持有珠）——v1.23 后 `misplaced` 判定已在 E1（WXG-T-134）落码 ⇒ 派生源已可用，归工程单。音效通道依赖 **GAP-05**（音频实质为零，本轮不落地）不变。**裁定：视觉单通道必须能独立完成教学**（对齐 skill §5「静音玩家不失去信息」与 `accessibility` D1「减弱动效时 `hint` 保留静态描边」），GAP-05 落地后为**增强项**、不作为引导成立前提。
   - **边界澄清**：本条只约束「教学文字」。按钮标签（继续/重玩本关/下一关/重试本关）、面板标题、道具卡 28px 文字标签（`accessibility` A4 硬要求）**不属教学文字**，不受本条约束。
4. **随时可走**：任意玩法状态 1 次点齿轮暂停；进度自动存档（S8），下次续进。

### 6.2 首供语义裁定（GAP-02，不可两读）

**裁定：采「`spawner.reset()` 后置 `_acc = interval`」，不采「`_setupLevel` 内同步 feed」。**

| 项 | 内容 |
|---|---|
| 语义 | 装配时先 `reset()`、再赋 `interval`、**最后**置 `_acc = interval`（赋值顺序**不可颠倒**：`interval` 的 setter 会清零累加器，见 `src/systems/spawner.ts` 注释）⇒ 进入 PLAYING 后**第 1 帧的供料段**完成首次供料 |
| 为何不在装配期同步 feed | ① 装配期供料会让 `tray:spawned` 落在 PLAYING **之外**，与 `core-loop` §2.1 状态语义及 S4 §8.8「非 PLAYING 零 `tray:spawned`」的观测口径相冲；② 需新增 `prime()` API 或暴露私有 `_feedOnce`，破坏封装；③ 走既有 `tick` 路径则抽色规则、随机空闲槽、事件广播全部自动一致，且帧内序仍属**供料段**（`core-loop` §2.2.2 真源零改动） |
| 一致适用面 | 冲刺 `_loadStage`（C8 stage 切换托盘清空）**同样立即首供**，避免每 stage 开局 2–3s 空窗；存档恢复路径（`_restoreFromSnapshot`）**不适用**（快照里托盘已有珠，再首供会凭空多一颗） |
| **首珠必须可落子色** | 首供抽色仅从 `demand = needed − held > 0` 的集合中取，**杂色与已满足色不参与首供**。理由：若首珠是死珠，则 1.5s「珠已在托盘」与 ~5s「首个爽点」**两条承诺同时失效**，且纯动效引导会指向一个无法完成的目标格 → 教学反成挫败。**本条独立于 GAP-06 泄压阀方案**（A/B/C/D 任选均成立）；若 A′ 落地，本条为其推论，仍保留作为首屏硬判据 |
| 判据影响（登记，交 QA） | S4 §8.1「60s 内 `tray:spawned` 恰 15 次」与 S1 §8.2「60 秒误差 ≤±1 颗」在首供落地后语义变为 **1 首供 + 15 周期 = 16 颗**；旧容差 ±1 会**恰好吞掉**本次语义变更（16 ∈ [14,16]）⇒ 属假绿风险，须显式改为 16。S4 §8.3（3:1 抽色统计）受「首供强制可落子色」影响恰 1 个样本（100 次中），可忽略但需注明 |
| **等价口径（WXG-T-098，BD-30）** | 本条裁定的是**可观测语义**：`reset()`（新关/stage 切换）后，PLAYING **第 1 个 tick 的供料段**即完成首次供料（≤1 帧）。实现落点两型均满足该语义：**(i)** `_acc = interval` 后置（顺序：先 `reset()` → 赋 `interval` → **最后**置 `_acc`，不可颠倒，因 setter 清零累加器）；**(ii)** 首供标志位 `_firstFeed`——`reset()` 置 true、首个 `tick()` 走 `_feedOnce` 后清零 ⇒ **现实现即 (ii)**（`src/systems/spawner.ts`；本单只读核实、未改码）。**后续轮次以 (ii) 为准据名**，不得因「代码中未见 `_acc = interval` 赋值」按字面误报。**两型唯一的可观测差异**（语义等价，但影响 §8-1 帧量化口径）：(i) 型周期供料相对名义时刻滞后 1 帧、(ii) 型滞后 2 帧（首供分支不占用 `_acc` 累计），故 `tray-spawner §8-1` 容差上界取 **2 帧** 以覆盖两型（BD-27） |
| 文档归位 | 本条规则的 S4 侧正文应补记在 `tray-spawner.md` §2.2（本单 Output Path 限定只改 §2.4，故 §2.2 补记经主理人转后续单落笔）；**权威条文暂以本节为准** |
