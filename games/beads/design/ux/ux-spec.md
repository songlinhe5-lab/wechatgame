## 1. 设计原则（沿用 skill 四条）

1. **首屏即玩**：启动 → 进关 ≤2 次交互，无登录无授权（core-loop 判例：无主菜单）。
2. **拇指可达**：托盘/道具/扩展全在屏幕下 1/3（`TRAY_BAND`+`POWERUP_BAND`），信息区（HUD）在顶部。
3. **反馈即语言**：0 文字教学——落座/拒绝/连击/告急全部动效+音效双通道表达。
4. **随时可走**：任意玩法状态 1 次点齿轮暂停；进度自动存档（S8），下次续进。

## 2. 界面流程（Screen Flow）

```
点击小程序图标
   │  BOOT（加载 ≤1.5s；读档失败/越界 → 安全降级第 1 关，绝不中断）
   ├─ runs==0 ──────────► 玩法·普通 L1（首条教学气泡，见 §6）
   └─ runs>0 ───────────► 玩法·普通 unlockedLevel 最远关
                              │
              ┌───────────────┼────────────────┐
              ▼               ▼                ▼
        暂停面板          结算·过关          结算·失败
      （继续/重玩/      （星级+去冲刺）        （重试本关）
        设置开关）            │                │
              │               ▼                │
              │        有下一关 → 玩法·n+1 ◄───┘
              │        全通关 → 通关画面（含去冲刺/重玩第 1 关）
              ▼
          玩法·恢复
（冲刺模式为玩法态的模式标志，不新增独立界面；入口/结算见 §3.4/§3.5，已定稿）
```

> 已移除的界面（有意为之，非遗漏）：主菜单、独立设置页、返回菜单。退出交微信胶囊/系统返回。设置入口仅齿轮一条通道（S9 §2.1）。

## 5. 交互反馈与动效时长表（权威毫秒值，回写 art-bible §7 占位）

统一缓动：进入 ease-out、退出 ease-in。红线：反馈 ≤400ms（庆祝/结算除外）；关键反馈视觉+音效双通道；无 >3Hz 闪烁；无真屏震（§3.8）。

| 放错拒绝 | ±3px 抖动 ×2 + danger 描边闪 2 次 | 低"咚"（≤2 次/秒） | 200 |

## 6. 首屏留存策略（微信前 10 秒）

| t | 事件 |
|---|---|
| 0s | 点击图标 |
| ≤1.5s | BOOT 完成（程序化绘制零加载资产） |
| 1.5s | **已进 L1，珠已在托盘**（首次供料立即执行 1 颗，不等首个间隔） |
| ~5s | 首颗珠落座 → 首个爽点（pop 动效+音效） |
| ~8s | 教学气泡 1：「点托盘选珠」→ 完成 1 次落座后自动消失，**永不重复** |
| ~10s | 玩家已理解"选珠→填色"；气泡 2（「同色入格」）仅在 20s 内零落座时出现 |

- 无强制引导遮罩、无奖励弹窗打断；失败无惩罚（D7）；教程态写入 runs>0 即不再出现。

## 7. 可访问性（对齐 `art/accessibility.md` 与 §3.8）

| 项 | 落点 |
|---|---|
| 触控 | UI 控件 ≥88px（`TOUCH_MIN`）；棋盘/托盘珠命中区=名义外扩 8px、重叠按格心最近（§3.8 v1.2 消歧） |
| 色盲 | 三重编码（颜色+符号+明度，art-bible §3.3）；连击档位另有 数字"×2/×3/×5" 通道（不靠颜色） |
| 告急/告警 | 图标+颜色+脉冲三通道，不单靠颜色（§3.8） |
| 对比度 | 文本 `text_primary #2A2E43` on `#FFFFFF` ≥12:1；符号对比 ≥3:1（art-bible §3.2 注） |
| 动效 | 屏震默认不使用；伪震屏幅度 ≤1.5% scale；闪烁 ≤3Hz 全局红线 |
| 单手 | 全部核心交互在下 1/3；倒计时只在顶部信息区 |

## 8. 决策记录与裁决项

**已裁定**（沿袭）：无主菜单两路径（core-loop 判例）；齿轮单通道入口；道具 MVP 占位口径（S6 §2.6）；面板 200/150ms（art-bible §7 原占位值转正）。

**已冻结**（U1–U4 全部按推荐值，2026-09-12 用户拍板，WXG-T-020）：
| # | 项 | 推荐 |
|---|---|---|
| U1 | 冲刺入口位置：结算过关页+通关画面+暂停面板三处都放 vs 仅通关画面 | ✅ 三处（转化最高）；按钮样式=副按钮不抢"下一关" |
| U2 | 冲刺结算是否展示"好友排行"入口（开放数据域，meta 提案 §3） | ✅ 展示但 MVP 置灰"即将开放" |
