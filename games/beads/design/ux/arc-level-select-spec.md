## 1. 设计原则（沿用 `ux-spec §1` 四条，本文只给本页读法）

1. **首屏即玩 → 进关 ≤2 次交互**：本页是「第 1 次交互的落点、第 2 次交互的发起点」，见 §6 复核。
2. **拇指可达**：墙格占页面中下部（`y∈[252,822]`，y 向上），`back` 在页底拇指区（`y∈[116,204]`）⇒ 选关与退出同手（v1.6 整页几何）。
3. **反馈即语言 · 0 文字教学**：格状态靠**描边 + 星带 + 锁形**三通道表达（未解锁 = 灰图 + 小锁 + 无星；越界空槽 = 同未解锁，2026-10-17 改裁合形、虚线已退场，见 §8.2），**不新增教学文字**；页标题与钮标签读 `COPY_TOKENS`（`btn_levels_label` = `选关`，`copy-tokens.ts:35`），不属教学文字。
4. **随时可走**：本页 `back` 一次即回主菜单；进关后的退出仍走暂停次钮（`ux-spec §2`）。

## 2. 界面流程（Screen Flow）

```
点击小程序图标
   │ BOOT（读档分流；非法/越界 → 安全降级 L1，绝不中断 —— ux-spec §4 BOOT 行 / §6.3）
   ▼
主菜单（shell 屏 · 启动落地页，v1.14 反转）
   │  走马灯大关页 T（◀▶ 或滑动翻页；吸附 180ms = MENU_CAROUSEL.snapMs）
   │  空橱窗页（THEME_LEVEL_MAX 之后那页）= 「敬请期待」⇒ **无选关腿**（不可点进列表）
   │  ① 点橱窗图（热区 = bossBox，`open-levels`；松手位移 ≤ MENU_CAROUSEL.tapPx ⇒ 判为点按）
   │  门票未达成的大关页（= 下一大关）：橱窗三态**逐字不变** + 其上叠加一枚只读「累计星进度件」（§4.1）；点图**仍进该章列表**（⛔ 新增拦截）
   ▼
大关选关页（整页路由 `levels` · 列表集合 = THEMES[T].levelRefs ∩ 解锁闸门）
   │ ② 点作品格 pick-level
   │    ├ 未解锁 / 越界槽 → **零事件、不消费**（留本页；闸门见 §4 注 A）
   │    │    └ 含「因本大关门票未达成而整体锁住」的章 ⇒ **同一判据**（§4.1-2）；格层 ⛔ 不加新形（责任在章层不在 9 个格）
   │    ├ 已解锁未通关（推关中）→ 扣 1 心 → 玩法·该关
   │    └ 已通关（starsByLevel[idx] > 0）→ **直接开新局**、扣 1 心 → 玩法·该关（Q7）

   ▼
玩法·普通（S1 六状态；LEVEL_CLEAR / GAME_OVER 结算照 ux-spec §4）
   │ 暂停次钮「回主菜单」/ 局内退回
   ▼
主菜单（**弃本局棋盘**，Q7-b = 甲；关卡解锁与各关最高星不受影响）
```
