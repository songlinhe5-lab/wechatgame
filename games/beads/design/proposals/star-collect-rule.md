## 1. 规则总览（玩家视角一圈）

第一次进一关，倒计时是宽松的「1★ 线」时长；在倒计时内拼完，**用时越短星级越高**——
快到连 3★ 线都赢就当场给 3 星。拖着拼完或超时看广告续时才完成，只拿本次档位对应的保底星。
**下次再主动进这关，倒计时收紧一档**（上次 1★ → 本次 2★ 档时钟；2★ → 3★ 档），
3★ 档重玩守住 3★。每关的历史最好星加进**总星数**，显示在主界面；总星数以后换珠面皮肤。
**一个大关里所有小关都打到 3★，才获准推下一个大关。**

## 2. 细则 R1–R8

| # | 规则 | 依据/映射 |
|---|---|---|
| R1 | **三条时间线共用一套数**：1★ 线 = 关卡 `time`（现状真源）；2★ 线 = `time × 0.85`；3★ 线 = `time × 0.70` | 直接复用冻结值 `STAR_TIER_K=[1.00,0.85,0.70]`（§3.7）与 `tierSecondsFor`——**零新增数值** |
| R2 | **本局倒计时 = 进场档位的线长**：1★ 档进场给 1★ 线时长，2★ 档给 2★ 线，3★ 档给 3★ 线 | 现码已如此（`beads-game.ts:2237`） |
| R3 | **倒计时内完成 → 按实际用时判星**：用时 ≤3★ 线 ⇒ 3★；≤2★ 线 ⇒ 2★；其余（倒计时内）⇒ 1★。含用户句「超过 3★ 水平直接给 3 星过关」——在 1★ 档进场也能当场跳 3★ | ⚠ **改判定点**：现行「选档即定星」（过档=档星，与用时无关）改为档内看用时评星 |
| R4 | **超时 → 失败面板 → 看广告续时（+180s，`REVIVE_BONUS_SEC`）：续时后完成 = 拿本次进场档位的保底星（1★ 档续时=拿 1★，3★ 档续时=拿 3★），不再看用时、不可能跳档** | ✅ **Q1 已裁（1★ 档续时给 1★）**；⚠ 部分回退现行 v1.50「续时不封顶」裁定，背书请求见 §4-C2 |
| R5 | **下一次主动进场档位 = 本关历史最高星 +1**（封顶 3★ 档）；3★ 档重玩守住即可，无更高档 | 现行 `nextTierFor` 条件 (a) 同语义；**条件 (b)「上一关同档已过」与首关豁免整条退役**（用户版只看本关自己）⚠ 改判定点，见 §4-C1 |
| R6 | **总星数 = Σ 各关历史最高星**（`starsByLevel` 存档零改动）；重玩刷出不比历史更高的星 ⇒ 总数不涨，防无限肝 | ✅ **Q2 已裁**；⚠ 用户同时点出隐忧：**后期星星供应量是否撑得起皮肤价目**（demo 单大关容量 = 9 关 × 3★ = 27★）⇒ 登记数值体检待办 §6-T3 |
| R7 | **大关推进门票 = 本大关全部小关 3★**；大关**内**小关解锁仍是线性"过一开一"不变 | ⚠ 与 §3.7「星级不做关卡门槛」（指小关）不冲突；但**推翻 Q16=甲**的大关通关口径，见 §4-C3 |
| R8 | **主界面显示总星数**（建议 `★ 12/27` 形：当前大关容量做分母 `[待拍板]`）；皮肤兑换价目以总星数为货币，阈值 `[待 playtest]`（沿用 §3.7 v1.23 在册语义「累计★ 解锁基础主题、高级走激励视频」） | 新增 UI 位（顶栏或橱窗角），归 UX 批 |

## 3. 与现状代码的关系（落码影响面预览，只登记不施工）

- 已落码且**直接可用**：三档时钟派生（R1/R2）、档=最高+1 的进档推导（R5 之半）、`starsByLevel` 存档（R6/R7 判据源）。

- 测试面：星级判定四臂（档内三判星线 + 续时保底）可全在纯 Node 单测（引擎无关，L3/L4 铁律不破）。
