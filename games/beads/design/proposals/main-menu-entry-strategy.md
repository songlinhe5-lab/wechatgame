## 2. 竞品入口 → 五类归档（我们怎么取）

| 类 | 竞品入口 | 判定 | 理由 |
|---|---|---|---|
| 进度 | 第N关胶囊 / 关卡地图 / 每日一关 / 任务 | **已有**（走马灯木牌 + 选关 overlay；每日见 P3） | 第 4 个进度入口只增读屏成本 |
| 商业化 | 金币·体力·倒计时 / 广告 / 福利礼包 | **只读已有**（门楣 ❤/🪙 已落码）；购买/广告**不做** | 无广告资质；非「卖货小铺」叙事 |
| 社交 | 分享 / 游戏圈 / 排行榜 / 联机 | **不做** | concept Won't；「一个人的小铺」 |
| 收集 | 图鉴 / 装扮 / 皮肤 / 拼豆星球 | **可加**（P2 货架角只读；皮肤见 T-346 §3） | 收集是小铺母语；主题解锁链现零入口 |
| 活动 | 7日签到 / 订阅 / 剩余4天 / 新玩法 | 签到**该修**（P1）；订阅与限时飘带**不做** | 焦虑语言 + 无运营人力 |

## 3. 三条建议（优先级序）

### P1 · 营业章 = 签到（**信封实装**，用户已裁）

- **位置**：顶栏右上「信箱」位（`MENU_TOPBAR_X.mail = 648`，现禁用空圆）；
- **交互**：点一次开**既有** `signin` overlay（面板语义，零玩法事件）；
- **前置（硬）**：信箱图标切图（B2/B3）——未就绪前保持禁用空圆，⛔ 不自造程序化信封（头注禁令）；
- **验收**：热区注册 + 可达 `signin` overlay；未读态提示 = 至多 1 处「麻绳结」式小标（不铺红点）；
- **为什么排第一**：T-346 已把它列为 P0；零新机制，只补死链。

### P2 · 货架角 = 只读陈列

- **位置**：玻璃窗（橱窗）右下角一小格；
- **内容**：最近 1 件成品缩略 + 「已上架 N」（复用 `drawLevelThumb` 同族缩略能力）；
- **交互**：**零热区**（不注册任何 action）——守住「主钮 + 走马灯卡 = 唯二入口」；
- **验收**：`hitTestMeta` 在该格返回 null；
- **叙事**：通关一件，货架满一分（收集感回流首屏）。

### P3 · 今日订单 = 每日关（暂缓）

- **位置**：木牌板第二行槽位（与 `★ n/门槛` 天然互斥：仅门票未达成时出现）；
- **交互**：小票标签直进今日固定关，1 次交互，扣 1 ❤ 照 §3.14；
- **前置**：`daily-challenge.md` 提案立项 + §3 变更单（新常量/新机制）；
- **红线**：标签面积 ≤ 主钮 1/3，⛔ 不做第二枚大钮、不做红点铺屏、限时只写「本周」不写天数。

## 4. 元素手法（竞品 → 暖纸语言）

| 竞品做法 | 我们怎么改 |
|---|---|
| 居中大卡 + 高光 + 难度角标预览 | 玻璃窗框**不动**，只换玻璃内内容；完成度画成纸上「已拼格/留白格」，不做百分比数字 |
| 紫/黄高饱和飘带标签 | 换**红泥印章**（「今日订单」「新到」）；`danger` 系既有 token，零新 hex；字号守 E1 地板 28，对比 ≥4.5:1 |
| 全入口红点 + 红色 03:56 倒计时 | 全局同时至多 1 处「麻绳结」提示（只给签到）；❤ 未满只加小沙漏符号；**禁红色倒计时与闪烁**（≤3Hz 红线） |

## 5. 风险

- **稀释单主钮**：可点目标 >3 且视觉权重接近 ⇒ 首屏从「点哪」退化成「读什么」。本文三条里两条是只读/复活，今日订单一律小票形态；
- **图标自造风险**：信封切图未到位前若强行程序化，会破坏「零新画法」与切图规格权威——保持禁用空圆是正确稳态；
- **与 T-346 重叠**：签到/金币/每日均已被 T-346 覆盖，本文只补**入口形态与位置**，不重复定义数值。
