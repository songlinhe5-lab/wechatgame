## 2. 冻结面变更清单（依赖顺序，主理人执行）

1. **§3.4 托盘**（先行，被 2/4 依赖）：
   - `TRAY_BASE_SLOTS` 12→**6**；`TRAY_EXPAND_SLOTS` 12→**6**（对本 concept 附录 A1 拍板的二次变更，登记 §6）。
   - 几何常量（`TRAY_COLS`/`TRAY_SLOT`/`btn_expand` 热区）**不动**，只改容量语义；托盘面板视觉是否随 6 槽收窄归美术规格（WXG-T-131 一并考虑）。
2. **§3.5 时间**：
   - 新增关卡级 `timeOverride = clamp(k × 45 s, 120, 420)`（k = 该关错位对数，levels JSON 载入）；`LEVEL_TIME_DEFAULT` 保留为无 override 兜底。
   - 合法区间 [180,420] → **[120,420]**。失败条件（唯一 = 归零）与续时机制（§3.11）**不变**——timeOverride 让失败页与续时位重新有出场机会。
   - `STAR3_RATIO`/`STAR2_RATIO` **先不动**，随 timeOverride 落地后 playtest 再校（预期现值偏松）。
3. **§3.7 星级语义（正式变更申请）**：
   - 「星级只记录不做门槛」→ 星级新增**主题解锁货币**语义（累计★达标解锁基础珠材质主题；高级主题走激励视频）。demo 阶段只落解锁判定 + 一套换肤占位。走 §6 登记。
4. **§3.10 冲刺**：新增 `SPRINT_K_CURVE(stage) = min(2 + ⌊stage/2⌋, MISPLACED_PAIRS_MAX)`，**`[待 playtest]`**（判据形态照抄 §3.13 先例：冻结区间、解冻逐关值）；连击窗口与托盘规则随 §3.4 结论联动。
5. **§3.13 错位参数增补**：新增**环长分布建议值**进 levels JSON（`cycleProfile`：前期偏 2-环短对、后期偏长环），验收仍只锁 k 区间，环长分布不冻结。
6. **input-control（S2 GDD）**：写明「板→板直接对调」为**非法输入路径**（选择锚裁决不收录该路径），与 Q2 裁定一致。
7. **concept.md**：§3 支柱 2 表述改写——「槽位压力下的轻策略」→「托盘工作台的手感与环谜题」（供料已死，原文已失真）；§7 范围分层随 Q15 更新。

## 4. 图案生成器规格要点（样张已验证）

- **管线**：印章库（手排 ASCII 像素画，`BEAD_CHARSET` 字符集）→ 对称镜像（只画半边）→ 尺寸/色数适配关卡预算 → `swaps` 错位构造（含 `cycleProfile` 环长偏好）→ 输出**必须过 §3.13 BOOT 校验**（坐标可填 / 每对珠色不同 / 对数 ∈ 冻结区间）。
- **定位**：**工具链优先**（离线产关卡 JSON），运行时生成留给 daily challenge 立项。
- **印章库扩充**：AI 批量产 ASCII 印章 + 人工筛选，质量门槛 = 样张水平。
- 样张脚本：`/tmp/beads-gen-demo.mjs`（四张：印章库爱心/小猫、镜像管线、swaps 错位构造 k=3）。

## 5. 诚实修正存档（供后人引用）

- 「托盘砍到 ≈ 错位珠数会造出环长谜题」**经复算不成立**：托盘 2 槽即可滚窗解任意置换（取 c1、取 c2、放 b1→c2、取 c3、放 b2→c3……）。托盘容量是**手感/工作记忆旋钮**，不是难度闸门；谜题深度来自 k（对数）与环长分布。Q9 的 6 槽提案据此定位为「手感」决策而非「难度」决策。
