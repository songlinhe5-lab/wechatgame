## 3. 可玩性判据化论证 + 实算证据

脚本：`temp/beads-1619/probe.mjs`（只读）；完整输出：`temp/beads-1619/out.txt`。

### 3.1 判据（四条，全部可机检）

- **K1 撞档判据（鸽笼）**：若风格把 N 个 colorIdx 映到 M 个不同渲染值且 M < N ⇒ 必存在**异色珠渲染后 RGB 全等**。触发即「该动哪颗」在数学上无解。
- **K2 谜面判据**：逐色算 **ΔE76(珠主体, 本格 B0 base)**，以现成预算 **ΔE ≤ 12** 为代理阈。超阈色数 > 0 ⇒ 该类就位珠会被读作错位；若关卡实际用到的色几乎全超 ⇒ 满盘皆错位 ⇒ 无「待动珠」读数 ⇒ **核心循环无输入**。
- **K3 归位判据**：玩家若改用「就近色」策略（argmin ΔE76 over base 十色），统计错配数。K2 与 K3 **同时不满足** ⇒ 两条自然策略互相矛盾，不存在一致解。
- **K4 通道判据**：渲染后色相角跨度 / 色度 C* 变化 ⇒ 量化「A1 色相通道被摧毁到什么程度」。

### 3.2 实算结果

**A. 基线（复核 a11y A3 ①）** — 十色 luma×255 降序：奶白 246.6 → 柠黄 206.7 → 活力橙 168.2 → 草绿 143.2 → 丁香紫 132.4 → 玫红 120.9 → 湖蓝 118.4 → 赭棕 113.6 → 深棕 71.8 → 炭黑 52.1。

### 3.3 结构定理（本提案的核心可复用结论）

> **L0 定理（纸面，可升为 §12 判据）**：谜面 = 「珠体 **L0 主体** vs 本格 **B0 底色**」的同色判据；而 ① B0 侧被 §12 **S4** 钉死为「全风格共享」、② 「色相识别由 **L0 主体**承担」是 `assets-spec §1.9.2:1296` 的既有身份（L0 列名即 `base`，端点表 1299-1310）。
> **∴ 任何风格成员的 L0 主体必须恒等于本格 base；派生层（L+/L−/Lpit/刻面/描边/孔）可增可减，但不得替换 L0。**
> 由此一次性判定：**16(a) ✅ · 18 ✅ · 复刻四棱/13/06 ✅（只叠派生层）· 16(b) ❌ · 16(b′) ❌ · 19-乙 ❌ · 19-甲 ⚠ 需破 S4 才能 ✅**。
> 该定理的价值：它把 §1.9.7 纪律①「base 锁死」从**art 品味纪律**升格为**可玩性推论**——违 ① 不再只是"不合规"，而是"这一档不可玩"。**（是否采纳为 §12 判据由主理人裁；本文不自立纪律。）**

### 3.4 新发现的 spike 伪像（单独就足以否决「样张看着能玩」这条证据）

`styles.mjs:32` 的 `plate()` 用 `mix(ep(ti).base, 0.72)` 画底图，而 189 行的 `valueRow` 把整行 `ci`（含传给 `plate` 的 `ti`）强制成 **4** ⇒ **spike 第 16 行的背景格也被一起锁成草绿系**。
⇒ 样张上「阶梯一目了然」的观感，依赖一个 **S4 明确不允许的状态（B0 随风格变）**；把它当「16(b) 可行」的证据 = 拿伪像当真值（K-035 族）。同理，189 行也让样张**永远画不出异色珠**，所以 K1 撞档在 spike 里不可见。**任何后续复现都不应以 `styles.mjs` 第 16 行为准。**

## 6. 回答 §12.8-⑦：16 该归系数型 / 图元型 / 色板型哪一类

**结论（按读法分岔，不接受「一个答案糊过去」）**：

1. **16 不可能是图元型。** 实测 4 珠体命令 / 0 真 α（§12.6 表 418 行）**低于**默认基线 6（416 行），`styles.mjs:121-125` 的四枚图元（主体圆角方 + 亮带 + 暗带 + 孔）**没有一枚是新图元** ⇒ 图元型义务（C7 逐风格 §6 差分复算）**没有对象可复算**。§12.3-① 旧列「图元型（含 16）」划掉是正确处置；`assets-spec 7.10 ①`（1458 行）与 7.2 表 1393 行的「归属待定」在这一点上**可由本文给出消歧依据**。
2. **若采 (a) 或 (b′) ⇒ 归系数型。** 它动的量（珠内明暗端点间隔 / 沿黑白轴的 mix 系数）与 §1.9.7 纪律④ 的三系数同类，**零新图元**；系数归 `tuning.ts`（C4，不进 `systems-index §3`）。⚠ 但 (b′) 另有一个 7.2/7.3 未覆盖的性质：**它运行时替换 L0 主体值**（虽不新增 hex）⇒ 严格说它既不是「只改系数」、也不是「只加几何」⇒ **本文建议 (b′) 不入任一通道**（连带 16-丙 一起出局）。
3. **若采 (b) ⇒ 它是「色板型」，而色板型不在现有通道内。** `assets-spec 7.2` 末行 1396 明写「**双通道是穷举面，不存在第三条**」⇒「16 属色板型」这一归类**本身就与 7.2 冲突**。真实含义不是「找到第三格」，而是：**该成员不在换肤系统的合法面内**，须按 §1.9.7① + `1375` 未推翻句 + **ADR-0019 §5-5** 走**另立 ADR + 重开 A1 / §1.9.2** 的通路。19-乙 同理。
4. **推荐给 §12 的表述骨架（由主理人落笔，本文不改真源）**：
 「16 = **系数型**（当且仅当语义钉为 (a)）；跨色压明度轴的读法 (b) **否决**（实算见调研提案 §3.2-B/D），该否决一并适用于 19 的『仅珠去色』读法。**不新增『色板型』通道**——任何重排／替换 base 呈现的成员均不入池，改走 ADR-0019 §5-5 通路。」
