## 1. 问题定义：星级现在到底哪里有、哪里断

现行星级机制（§3.7 v1.50「三档时钟·选档即定星」，已落码 `tuning.nextTierFor/tierSecondsFor`）下，
玩家打出的星实际只有四条去处，逐条弱在：

| # | 现状用途 | 为什么"感觉没用" |
|---|---|---|
| ① | **档级门票**：本关 1★ 过 → 才可选 2★ 档；上一关同档过 → 才开下一关该档 | 单档推图玩家（只打 1★）全程无感；档级选择 UI 被裁「无需选档 UI、由存档推导」⇒ 玩家甚至不知道自己"解锁"了什么 |
| ② | 结算面板 + 墙格星带**显示** | 纯装饰，无后果 |
| ③ | 橱窗三态判定 `stars>0 = 已通关` | 只用到"有没有星"，**用不到 1★/2★/3★ 的差别** |
| ④ | 存档记历史最高 | 没有任何系统来读它 |
| ⑤ | **累计★ = 皮肤解锁货币**（§3.7 v1.23 正式裁定） | ⚠ **已裁未落地**：阈值 `[待 playtest]`，代码零消费（grep 证实 src 无解锁判定）⇒ 这是"星级应该有作用"的正主，悬空着 |

结论：星级唯一有牙齿的作用（⑤ 换肤）没做，剩下的都不要求玩家"打得更好"，只要求"打完"。

## 2. 候选消费场景（六个，含一个补票）

### A. 把已裁的「累计★ 解锁珠面皮肤」做实 【补票项，非新增】
- 体验一句话：星星攒够了 → 解锁一套新珠面材质，重玩旧关换新皮再拼一遍。
- 为什么会多打一星：累计值 = Σ 各关历史最高星 ⇒ 3★ 比 1★ 多挣两倍，差一套皮肤时玩家会回去补星。
- 接口：存档零改动（`starsByLevel` 已够）；新增 = 解锁判定 + 皮肤选择 UI（`pause-settings §2.2` 珠面档位入口已在）+ 阈值表 `[待 playtest]`。
- 红线相容：✅ 本就是现行裁定；不违 Q5（发的是"外观"，不是关卡门票也不是数值奖励）；不碰 v1.50 拆线。
- 体量 **M**（demo 可做）；变现关系：自然（高级主题走激励视频已是 §3.7 在册语义）。

### B. 星级总星数 = 新大关（arc）的推门门票
- 体验一句话：大关之间设一道星槛——第一大关攒不够 ★ 就开不了第二大关。
- 为什么会多打一星：卡关时玩家的第一反应就是回头补星，星级立刻有"第二货币"地位。
- 接口：大关表（EP13-S1 的 `ARCS`）加一列 `entryStars [待拍板]`；选关页三态加"星级不足"变体。
- ⚠ 红线辨析：§3.7「星级不做**关卡**门槛」是白纸黑字裁定；本项把它扩张到**大关**粒度——字面不冲突（关卡 ≠ 大关），精神有摩擦，**须用户明确改判或确认边界**才可推进。
- 体量 **S**（依赖 EP13-S1/S2 先落地）；变现关系：中性。

### C. Boss 关星级 = 限定图纸/图鉴收藏
- 体验一句话：L9 boss 拿满 3★ 才点亮"金框图纸"，进个人图鉴册（纯收藏，可截图分享）。
- 为什么会多打一星：收集癖 + 展示欲；boss 关天然值得一个仪式感奖励。
- 接口：图鉴页新增（meta-ui §2.2 完成度列的延伸）；存档加一个 bit 集合。
- 红线相容：✅ 与 Q5 = A 同向（"星级为图鉴/完成度唯一判据"正好接住它）；不发数值奖励、不做门槛。
- 体量 **S**；变现关系：弱（可日后挂"分享"不挂广告）。

### D. 每日挑战的星级倍率/修饰符
- 体验一句话：今日挑战按昨日最好星级给一个小变化（如 3★ 玩家今日时限 −10%，或开局多一个辅助托盘）。
- 接口：`daily-challenge.md`（未立项，Could 层）本体的顺带字段；挑战存档。
- ⚠ 摩擦：−时限会重新触碰 v1.50 拆线红线（效率奖励与失败压力焊回一只时钟）——须做成**增益不做惩罚**（多辅助=正向）才相容。
- 体量 **L**（前提是每日挑战先立项）；变现关系：不直接。

### E. 好友/全服星级排行
- ⛔ **demo 阶段不可行**：concept §7 Won't 已砍社交 + 无服务端（`daily-challenge.md` 头注同口径）。登记为发布后再议，不进推荐组合。

### F. 激励视频「保星」位（失败掉星时花广告保住的星）
- ⛔ **不建议**：现行制星级=档位、过了就记历史最高，本就无"掉星"事件；硬造掉星再卖保住 = 把 v1.50 刚拆开的压力线焊回去，且撞 §3.11 变现 Won't。登记否决理由，防后续复提。
