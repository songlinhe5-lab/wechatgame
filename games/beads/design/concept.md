# 《拼豆填色消除》一页纸概念

- 项目：`games/beads` · 任务号 WXG-T-007（P0）· 版本 v1.0
- 引擎：Cocos Creator 3.8 LTS ｜ 平台：微信小游戏 ｜ 分辨率：750 × 1334 FIXED_WIDTH（已裁定，与 breakout 一致）
- **定位：忠实复刻参考玩法的休闲填色消除 demo，不做创新变体。**
- 数值纪律：所有常量集中于 `design/gdd/systems-index.md` §3（冻结令），本文只引用常量名。
- 标注约定：`[待确认]` = 需用户/主理人拍板后才冻结；未标注的设计本文可定稿。

---

## 1. 一句话定位

**在倒计时耗尽前，从底部托盘选取珠子、按颜色填满像素图案的休闲填色消除游戏**——手作拼豆的治愈感 × 托盘槽位管理带来的轻策略压力。

## 2. 为什么是它（Demo 验证价值）

1. **验证框架的事件驱动能力**：填色/消除/道具全是事件串接（`bead:placed` / `tray:full` / `powerup:used`），比打砖块的连续物理更考验事件总线解耦质量。
2. **验证数据驱动关卡的另一种形态**：打砖块是"行字符串砖阵"，拼豆是"图案矩阵 + 色板索引"，两种数据形态共用同一套关卡加载思想，检验框架 config 层的通用性。
3. **验证激励视频位的最小接入**：3 道具 + 托盘扩展共 4 个激励视频位（MVP 全部只做占位/标 `[待用户确认]`），为矩阵后续产品商业化探路。
4. **验证同框架双品类**：街机（breakout）+ 消除（beads）共用 `@wxg/framework`，是"框架复用"主张的最小实证。

## 3. 设计支柱（≤3，后续决策对照）

1. **一眼读懂的治愈**：进游戏 3 秒内看懂"把珠子填进图案"；节奏轻、软，反馈即时但不激烈（与打砖块的街机爆点刻意区分）。
2. **槽位压力下的轻策略**：托盘容量有限、供料不停，玩家需取舍"先放哪颗、何时清槽"——压力来自时间与空间，不来自操作难度。
3. **复刻优先，不加戏**：忠实参考图玩法；任何参考图中不存在的机制一律进 Should/Could，不进 MVP。

## 4. MDA 分析

- **Mechanics（机制）**：托盘定时供料 → 玩家选珠 → 点网格空位 → 颜色匹配则落座、不匹配则拒绝 → 图案填满则过关、倒计时归零则失败；3 道具清除托盘珠；激励视频扩展托盘。
- **Dynamics（动态）**：玩家自发形成"槽位管理策略"——优先消耗稀有色/大色块，把杂色珠留给道具；托盘将满时紧张感上升，主动用清槽道具腾位；最后关头加速点击形成收尾冲刺。
- **Aesthetics（美学）**：**治愈（图案逐步成形）+ 秩序感（杂乱→整齐）+ 轻紧张（倒计时与满槽告警）**。三者在"最后一格填上、全图点亮"的瞬间汇合为完成满足感。

## 5. 目标玩家（Bartle）

- **主：成就型**——填满图案、拿 3 星、逐关解锁是核心驱动；进度与星级走本地存档。
- **次：探索型**——每关一个像素图案（demo 8 关 8 个图案），"下一张是什么图"驱动通关。
- **砍：社交型 / 杀手型**——无排行、无对抗、无分享（demo 阶段，见 §7 Won't）。

## 6. 心流与难度曲线思路

- **张力双源**：时间（`LEVEL_TIME_DEFAULT`=300s，关卡可覆盖）× 空间（托盘 `TRAY_BASE_SLOTS`=12 槽）。
- **难度三旋钮**（按关递增，具体参数表由 levels-spec 给出）：① 图案尺寸（约 6×5 → 13×12 格）② 颜色数（3 → 8 色）③ 供料间隔（6.0s → 2.5s，越快杂色挤占越狠）。
- **心流保护**：单关时长恒定 ~5 分钟（与参考图 04:55 对齐）；失败即整关重开但**读秒从头、图案清空**，无永久惩罚；锁定格（X 纹）承担"视觉减负"，减少无效搜索面积。
- **不设**：实时分数、连击、倍率——消除品类的爽点在"完成"而非"数字膨胀"（决策记录 D6）。

## 7. 范围分层

| 层 | 内容 | 说明 |
|---|---|---|
| **MVP（验收线）** | 8 关；图案矩阵填色核心玩法；托盘 12 槽 + 供料；倒计时 + 告急；3 道具（区域消除/槽位清空/随机消除，均带激励视频角标**占位**）；托盘扩展行（激励视频**占位**）；暂停/设置面板（音乐/音效开关）；本地存档（进度+星级+设置）；通关画面 | demo 验收线，缺一不可 |
| **Should** | 每关 3 道具各 1 次免费次数（超出走视频）；左侧悬浮音乐开关；结算页"下一关/重玩/分享"三按钮 | 参考图可见但非核心循环 |
| **Could** | 图案库扩充与每日图案；结局分享卡片；音效细化（落座/溶解音色区分） | 时间富余再做 |
| **Won't（明确砍掉）** | 排行榜/好友对抗；账号与云存档；道具内购；玩法创新变体（如消除连击、双图案混合）；实时分数系统 | 理由：支柱 3"复刻优先" + demo 范围纪律 |

> 激励视频位纪律（主理人已定）：MVP **保留角标与入口**，实际拉起视频与发奖逻辑标 `[待用户确认]` 后接入。

## 8. 视觉锚点（一句话，交美术方向）

糖果质感的 3D 拼豆：淡紫灰静底上，圆角方块珠子以顶面高光与四边倒角拼出像素图案，低饱和背景衬托高饱和珠子——**已由 `games/beads/art/art-bible.md` v1.0 定稿，本文不重复定义**。
