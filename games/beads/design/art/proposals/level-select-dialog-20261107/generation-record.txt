# 大关内小关选关弹窗 UI 原型 · 生成记录（2026-11-07）

任务：某大关（chapter，如「曼陀罗」）内的小关选关对话框——玩家从主菜单进入某章后弹出，展示该章下所有小关（level，通常 3×3 网格），三态（已通关 / 当前 / 未解锁）。

## 模型与通道

- **模型**：`qwen-image-3.0-pro`
- **通道**：Token Plan（Credits 计量）
- **模式**：i2i（`--ref` 主界面原型做风格锚定）
- **参考图**：`games/beads/design/art/final/prototypes/menu-design-baseline-cat-topbar-final-slotbar-20261102.png`
- **尺寸**：1152*2048；**seed：42 / 7**（铁规① 双 seed 改判门槛）

## 执行命令（照抄可用）

```bash
REF="games/beads/design/art/final/prototypes/menu-design-baseline-cat-topbar-final-slotbar-20261102.png"
for s in 42 7; do
  python3 games/beads/design/ai-workflows/dashscope-generate.py \
    --profile token-plan --model qwen-image-3.0-pro --size '1152*2048' \
    --seed $s --ref "$REF" --text "<prompt>"
  mv temp/dashscope-out/custom/qwen_image_30_pro.png \
    "games/beads/design/art/proposals/level-select-dialog-20261107/select-v3-ref-s${s}.png"
done
```

## prompt 核心锚点（判据锚点，必须逐字含）

```
严格参考图（图一）的所有容器风格与材质：
厚木纹面板 + 顶缘一圈浅米黄色高光条 + 底缘一圈深棕阴影线
+ 四角各一颗圆形金属铆钉 + 招牌绳挂 + 橱窗暖黄灯光
+ 米黄格纹桌布一角 + 米白色立体粗体字 + 暖橙深红粉紫小色块点缀
```

版面结构（自上而下）：
1. 招牌（绳挂 + 厚木纹 + 顶缘高光 + 底缘阴影 + 铆钉 + 米白立体字「曼陀罗 选关」）
2. 横向细木板进度条（两端铆钉）+ 九枚星位占位（前 N 实心金星 / 当前半透明空星厚框 / 后 N 灰空圆未解锁）
3. 厚木框网格（橱窗框架）+ 三行三列九枚方形圆角木板卡（每枚两端铆钉）

## V2.5f · 标题槽砍半 + 九格不同图案（定稿，4 次浪费后 2 次全绿）

- 触发：用户 2026-11-07 令「标题字减到 50%，招牌减到 50%，背景可以左右伸缩」
