## 0. 本次用户裁定（三项已定）

1. **美术自由提案 20 个互不重复的大关主题**——题材域分散（自然 / 动物 / 器物 / 节庆 / 食物 / 建筑 / 天文 / 幻想等），全原创剪影，禁第三方 IP。
2. **只做甄选清单 + 预览，不落关卡真源、不入关**——产出止于本目录，选定后由工程侧按内容管线转成真源。
3. **每大关 = 一个宽题材，9 个小关 = 9 个不同子图案，第 9 关（P9）为该题材代表 boss**。

目标规模：**20 大关 × 9 小关 = 180 个图案选题**。

## 1. 题材分散说明

20 个大关落在 **20 个互不重复的题材域**：花卉植物、森林走兽、海洋生物、鸟类、昆虫、甜点美食、鲜果、文具器物、建筑、节庆符号、乐器、交通载具、宇宙星空、史前恐龙、幻想生物、天气气象、运动玩具、家居生活、山水风景、宝石矿物。

分散原则：
- **题材域不重复**：每关一个独立 domain，避免「动物连开三关」的题材疲劳。
- **节奏交替**：生物类（花/兽/鱼/鸟/虫）与生活器物类（食/文具/建筑/家居）、宇宙幻想类穿插排布；前 10 关偏具象易拼，后 10 关逐步引入抽象与幻想题材。
- **boss 语义贴合**：每关 P9 是该题材的「王 / 后 / 代表物」，与 chapter schema「每章恰 1 个 boss 且为末项」一致。

## 2. 与 art-bible 视觉身份的对齐声明

- **风格锚点服从 `art-bible` §1–§2**：预览取色于 `art-bible §3.2` 十色珠板（奶白/柠黄/橙/草绿/玫红/丁香紫/湖蓝/赭棕/深棕/炭黑），冷紫灰静底（`#EDEAF2`）承「冷调静底上唯一高饱和暖珠」；珠子以实心圆 + 高光点程序化绘制，承「手工艺 × 糖果质感」。
- **三重编码不妥协**：本清单只甄选题材与建议主色数，不涉及最终「色→符号」绑定；入关时仍需按 `art-bible §3.3` 给每色配唯一矢量符号（颜色 + 符号 + 明度），本任务不改写该约束。
- **原创红线**：全部剪影为几何图元程序化拼合的原创示意，未引用任何第三方 IP 形象（「凤凰/巨龙/美人鱼/独角兽」等均为公共领域泛化母题，非特定作品角色）。符合 `levels-spec §2`（图案全部原创、禁第三方 IP）与 `§7`（异形靠 `.` 空位塑形，`x` 仅收边）。

## 3. 字段口径（与 candidates.json 对齐）

| 字段 | 含义 | 取值 |
|---|---|---|
| `arcId` / `title` / `domain` | 大关编号 / 玩家可见名（≤6 字）/ 题材域 | A01–A20 / 2–3 字 / 见总表 |
| `patterns[].id` | 图案序号 | P1–P9 |
| `patterns[].name` / `desc` | 图案名 / 一句话形态描述 | 中文 |
| `patterns[].suggestedColors` | 建议主色数 | 2–6（以 3–5 为主；2 色为极简图案，入关可按管线调整） |
| `patterns[].legibility` | 辨识度自评（按 `pattern-legibility` T1–T7 直觉，**非精确指标、非门禁**） | 好拼 / 中等 / 偏难 |
| `patterns[].isBoss` | 是否 boss | 仅 P9 为 true |

> **难度序口径**：若入关需排 9 关顺序，按 `level-difficulty.md §1.2` 的 `DI`（只管章内难度序、不管定价）；本清单的 `legibility` 是「好不好看清」，与 `DI`（难不难）是两把不同的尺子，勿混用。
>
> **辨识度经验线**（`pattern-legibility §2`）：3–4 色建议 ≥12×12、5–6 色 ≥15×15、7–8 色 ≥17×17。本清单主色数集中在 3–5，入关盘面按此反推；`偏难` 的 6 个图案（玫瑰/月饼/星座/晨雾/湖/玛瑙）建议 studio 侧二次优化或降色。

## 6. 已知风险与缓解

| 风险 | 说明 | 缓解 |
|---|---|---|
| 个别题材辨识度偏低 | 玫瑰/月饼/星座/晨雾/湖/玛瑙等 6 个标 `偏难`：或纹理密、或轮廓细长、或形态抽象 | 已给降色/二次优化建议；入关前由 studio `legibilityFix()` 处理，必要时换子图案 |
| 剪影精度有限 | `preview/` 是几何图元程序化示意，用于评审题材方向，非最终 pattern；个别图案（如吉他、自行车、风）较抽象 | 以本清单文字描述为准；选定后按 `level-content-pipeline` 走真源美术管线重制 |
| 与现有「曼陀罗 / 照片冒烟」风格衔接 | 现池 boss 为曼陀罗、部分关为照片转拼豆；本批为原创对称剪影，风格同源（程序化、冷底暖珠）但题材从抽象几何扩到具象题材 | 二者同为「原创剪影 + 十色珠板」，可共存；建议把本批作为新章扩池，老章不改动，避免动存档 |
| 题材跨域重复观感 | 花/果/甜点同属「植物/食物」大类，鸟/兽/虫同属「动物」大类 | 已用 domain 分散与前后段节奏交替缓解；评审时若觉得近似，可整关替换（改 JSON + 重生成即可） |
| 包体预算 | 本任务零外部美术文件，预览 PNG 仅在 proposal 目录供评审、**不进包** | 对主包 ≤4MB 零影响；真入关时图集/分包按 `assets-spec` 与 §3 冻结预算执行 |

## 7. 如何修改与重生成（预留可改结构）

- **改文字/选题**：编辑 `candidates.json`（表格 + JSON 双份便于改；JSON 为单一真源）。
- **改剪影形状**：编辑 `sketches.py` 中对应 `<arcId>-<pid>` 的图元串（DSL 见文件头）。
- **重生成**：`python3 gen_readme.py` 重建本文与两份逐关明细分册、`python3 gen_preview.py` 重建 20 张预览。
- 用户裁定后，由工程侧按 `level-content-pipeline` 把选定条目转成 `design/levels/chapters/**` 真源并跑 `levels:sync`；本目录产物不直接入关。
