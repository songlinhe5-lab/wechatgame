## V4 · 用户反馈修改版（定稿，全落实）

- 触发：用户对 V3 提出 5 条修改意见（2026-11-07 晚）
- 修改点：
  1. 招牌改轻 + 不要绳挂 → 轻量薄木色横条 + 顶缘极细高光 + 底缘极细阴影 + 四角小铆钉点缀
  2. 缺关卡名 → 招牌下新增深棕色小字「曼陀罗 · 第5关」
  3. 关卡图案外框+灯光简化 → 简单木框卡片（薄木色描边 + 浅阴影），**无橱窗/暖黄点灯光效**
  4. 三星文字简化 → 每行只放星星图标，**星下面不写任何文字**（阈值文字全部去掉）
  5. 去掉右下角桌布 → 背景纯深木纹墙面，无米黄格纹桌布角
- 通道/模型：同 V3（Token Plan / qwen-image-3.0-pro / i2i --ref）
- seed：42 / 7 各一发
- 产物：detail-dialog-v4-ref-s42.png / detail-dialog-v4-ref-s7.png
- 判据：**两 seed 一致全绿**——5 条修改全部落实，厚木纹容器语言（主面板顶缘高光+底缘深棕阴影+四角铆钉 / CTA 木棕胶囊 / 徽章钉在面板上）完整保留，中文逐字对（关卡详情 / 曼陀罗·第5关 / 开始），无手机壳无实物道具。零浪费。
- 用量：调用 2 / 出图 2 / 留档 2，费用量级 0.18×2=0.36 元
