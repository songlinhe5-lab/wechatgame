# 通用对话框壳 Dialog Shell · 生成记录（2026-11-07）

任务：将关卡详情弹窗的容器语言提炼成**通用对话框壳（Dialog Shell）**——标题槽、面板背景、底部按钮槽三个部位通用化，中间内容区完全开放，任何场景都能套用（关卡详情、关卡选择、确认框、提示框、奖励弹窗、设置弹窗…）。

## 模型与通道

- **模型**：`qwen-image-3.0-pro`
- **通道**：Token Plan（Credits 计量）
- **模式**：i2i（`--ref` 主界面原型做风格锚定）
- **参考图**：`games/beads/design/art/final/prototypes/menu-design-baseline-cat-topbar-final-slotbar-20261102.png`
- **尺寸**：1152*2048；**seed：42 / 7**（铁规① 双 seed 改判门槛）

## 执行命令

```bash
REF="games/beads/design/art/final/prototypes/menu-design-baseline-cat-topbar-final-slotbar-20261102.png"
python3 games/beads/design/ai-workflows/dashscope-generate.py \
  --profile token-plan --model qwen-image-3.0-pro --size '1152*2048' \
  --seed 42 --ref "$REF" --text "<prompt>"
python3 games/beads/design/ai-workflows/dashscope-generate.py \
  --profile token-plan --model qwen-image-3.0-pro --size '1152*2048' \
  --seed 7 --ref "$REF" --text "<prompt>"
```

## 三个通用槽位规格（最终敲定）

| 槽位 | 规格 | 可替换 |
|---|---|---|
| **① 面板背景** | 厚木纹主体 + 顶缘一圈浅米黄色高光条 + 底缘一圈深棕阴影线 + 四角各一颗圆形金属铆钉。背景纯深木纹墙面，无桌布装饰 | 不可换（全局风格锚定） |
| **② 标题槽** | 轻量横向薄木色横条（**无绳挂**）+ 顶缘一圈极细浅米黄色高光 + 底缘一圈极细深棕阴影 + 四角各一颗小铆钉点缀 + 条上米白色立体粗体大字。标题槽下方一行深藏青色细体小字（**可选次级标题**，可空） | ✅ 文字可换（关卡详情 / 确认 / 提示…） |
| **③ 内容区槽** | 面板中部大区域，只给极浅内部容器边界（薄描边或近乎无），**不放具体装饰**，让任何内容都能放 | ✅ 完全开放 |
| **④ 底部按钮槽** | 面板**最底部固定位置**，按钮数量支持单胶囊（主操作）或双胶囊（主+次）。当前示例：宽厚木棕胶囊 + 顶缘高光 + 底缘深棕阴影 + 米白立体字 + 四角铆钉 | ✅ 按钮数量/文字可换（单/双、确认/取消/开始/关闭…） |
