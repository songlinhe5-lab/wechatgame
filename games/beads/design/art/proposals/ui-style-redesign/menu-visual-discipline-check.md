## 2. 唯一口径歧义：场景化 v2 下的「容器唯一」

- **字面纪律**（竞品图3 推导）：一屏一种容器语言。
- **本项目现实**：v2 场景化把「橱窗 + 价目牌 + 木牌板」当作小铺**场景件族**（同木/纸材质、同描边/斜面语言），不是三套任意矩形。
- **裁定建议**：纪律应表述为「**一屏只有一族容器语言（木/纸场景件），不得引入第二套材质或第二种边框语法**」——按此口径，现状 ✅；若按字面「只允许一个容器」解读，则资源条/木牌板都算违规，会把 v2 场景化设计整体否掉（不可取）。
- 本文按**族口径**判定，待 art 在回写 §9 时用一句正式措辞钉死。
