■ 怎么转成矢量（本机无 potrace / cv2 / skimage，全部自实现）
| 步骤 | 做法 |
|---|---|
| ① 预处理 | 裁墨迹 bbox → 缩到 480 → Otsu 二值 → 装进正方形画布（留 6% 边） |
| ② 去对角 | 把「仅对角相接」的像素补成 4 连通，消除边界顶点的多出边（否则环会被串成开链） |
| ③ 追踪 | **crack following**：沿像素边界收集有向边，按顶点链接成闭合环 |
| ④ 平滑剪枝 | **先 Chaikin(2) 平滑密集折线，再 Douglas-Peucker(0.9) 剪枝**（顺序不可反，见坑 1） |
| ⑤ 归一 | 按**外接圆**归一（最大顶点半径压到 40），不是按外接方形——圆牌上按方形会从斜角溢出 |
| ⑥ 输出 | SVG（`fill-rule="evenodd"` 单 path）+ 扫描线 even-odd 栅格化成 80 / 160 / 320 |

■ 线宽怎么定的（不是猜的）
模型画的线在 1024 图上只占 ~1.7%，80px 档会细到看不清，故做**膨胀加粗**：
`先定尺寸、再膨胀`（每膨胀 1 次 ≈ +1px/边 @480 ⇒ +0.17px @80），档位 0 / 4 / 8 / 12 各出一版对照
（`weight-ab.png`）。**定档 +8**：形状还保得住且线够粗；+12 起齿轮齿槽、奖杯把手与杯身开始粘连。

■ 踩过的四个坑（都已修，写进代码注释）
1. **Chaikin 作用在稀疏多边形上**会把长直边的角点切掉约 1/4 边长 → 方角变 45° 大斜口。
   必须先平滑密集折线、再 RDP 剪枝。日历右上角那块楔形填色即此。
2. **给 RDP 传 `loop + [loop[0]]`**：首尾同点令基线退化成零向量，判据变成「按到起点距离取点」，闭合环被切出大斜口。
3. **按环面积的正负号填/挖**：追踪出的环绕向不一致，会把孔洞填死。必须用扫描线 **even-odd**。
4. **膨胀后再按墨迹重装框**：膨胀与归一化互相抵消，按墨量搜膨胀量永远打不到目标（+12 仍只到 15%）。
   改为先定尺寸再膨胀、并按目视定档。

■ 已知限制
1. **线宽仍略轻于 T-540 手绘版**（80px 墨量 12.3–20.2% vs 手绘 18.0–26.1%）。再往上加就粘连，属底图线宽的物理上限。
2. **齿轮齿形被平滑成圆角**：Chaikin(2) 对 8 齿的尖角有约 1px 圆化，320px 以上可见，80/160 档不可见。
3. **线端仍是方头**（PIL 只圆化折点）。要圆头须换 SVG 渲染或逐段加端帽。
4. **图标语义完全来自模型**：T恤版不含衣架（模型没画），与参考件 `ui_icon_skin.png` 有差异。
