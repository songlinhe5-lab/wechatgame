【顶栏三钮图标】云端 qwen-image-3.0 与 3.0-pro 横比　落盘 2026-11-02

■ 它是什么
用户令「image 3.0 和 image 3.0 pro 各生成三个矢量图对比」。同一套提示词、同一 seed（11）、同 1024²，
两模型各出榜单 / 每日签到 / 换肤三张，再走**与本地版完全相同**的追踪参数（`FIT_R` 35.0 / 膨胀 +10），
得到可直接对比的矢量成品。**这是横比批，不替换任何已采用件**（当前采用仍是 `../btn-topbar-traced-v2-20261102/`）。

■ 结论（三条）
1. **3.0 与 3.0-pro 之间没有可判别的质量差**：外框长边完全相同（57.5 / 57.5 / 62.5），墨量差 ≤0.7 个点，
   IoU 互有胜负（0.991 vs 0.991、0.995 vs 0.989、0.981 vs 0.985）。pro 单价高 39%（0.25 vs 0.18）却买不到质量。
   这与 `model-matrix.md` §3 已记的「四个方向全量对照，无一构成改判依据」一致。
2. **云端两版的外框都比本地 2.1 小**：好友榜 57.5 < 62.5、换肤 62.5 < 67.5（差 8%）。原因是云端把造型画得更"规整"，
   但也更保守、更方，外接圆归一后主体就小一档。**尺寸上本地版更贴合「核心一致」的目标**。
3. **云端唯一明确胜出的点**：图中描摹保真度更高（每日签到 0.995 vs 0.986，好友榜 0.991 vs 0.986），
   线条更平滑、折角更少；且云端日历自带**表头横线**，比本地版更像日历（本地版框内只有对勾）。

⇒ 建议**维持本地 2.1 版**（`btn-topbar-traced-v2-20261102/`）。若要为了保真度换云端，选 3.0 即可，⛔ 不必付 pro 的价。

■ 复现配方
```bash
python3 games/beads/design/ai-workflows/dashscope-generate.py \
  --model qwen-image-3.0 --size "1024*1024" --seed 11 --text "<见下方提示词>"
python3 games/beads/design/ai-workflows/dashscope-generate.py \
  --model qwen-image-3.0-pro --size "1024*1024" --seed 11 --text "<同一条>"
python3 temp/m9-trace.py      # 追踪 → SVG；temp/ 不入库，参数见脚本头常量
```
提示词（三条共用同一句尾：`线条明显偏粗、粗细均匀一致、笔画简洁有力、转角圆滑；纯白色背景，没有阴影、没有渐变、没有反光、没有文字、没有其他任何元素`）：
- 好友榜：`单个图标居中，完整位于画面内、四周留出少量空白：深棕色粗线条绘制的奖杯图标，杯口宽、杯身自上而下收窄，左右两个把手短小、紧贴杯壁不外伸，下部短杯脚与一块扁平底座；整体外轮廓接近方形、没有细长外伸部件。`
- 每日签到：`单个图标居中，完整位于画面内、四周留出少量空白：深棕色粗线条绘制的日历图标，接近正方形的圆角外框，顶部两个低矮的小装订环紧贴框顶、几乎不向外突出，框内一个大对勾；整体外轮廓接近方形。`
- 换肤：`单个图标居中，完整位于画面内、四周留出少量空白：深棕色粗线条绘制的短袖T恤图标，衣身宽大接近方形、整体宽度略大于高度，两只袖子很短、贴着衣身向下收拢、完全不向外张开，领口是一个小圆领开口；整体外轮廓紧凑接近方形。`

■ 已知限制
1. 单 seed（11）横比，未做 ≥2 seed 复测 ⇒ 结论只用于「两模型是否可判别」这类量级判断，不作为改判唯一依据（判据铁规见 `wxgame-image-gen` §0）。本轮实测差异远小于抽样噪声量级，故结论稳。
2. 云端出图不带 alpha（`qwen-image-3.0-pro` 已知会把透明棋盘格画进 RGB，见 `production/qa/pro30-edit-cut-20261101.md`），本批只要白底线稿，不影响。
3. 追踪参数未按模型单独调优（一律 `FIT_R` 35.0 / +10），云端两版若单独定档可能再提升 1–2 个点，但会破坏「同口径对比」。
