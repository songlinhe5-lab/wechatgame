【分层版】顶栏钮 = 共用底托 + 图标覆盖层　落盘 2026-11-02

■ 它是什么
把 `btn-topbar-20261102/` 的四张「图标烧进木牌」整图，重构为**一张共用底托 + 四枚独立木刻图标覆盖层**。
视觉与已定稿单张版基本一致（`compare-layered-vs-single.png` 上下两行对照），但换来三项工程收益：

1. **新增同族按钮不再出图**：只要有一枚图标（画/抽/现有 PNG），叠底托即可；
2. **四钮底托严格同一张**：木纹、倒角、光向不可能出现批次差异；
3. **改底托材质一次生效**：换色/加深/换倒角强度只重做 `btn-base-*`，四钮同步。

■ 文件清单
| 文件 | 用途 |
|---|---|
| `btn-base-1x-80.png` / `btn-base-2x-160.png` | **共用底托**（无图标），`TOPBAR_D = 80` |
| `icon-{settings,rank,calendar,skin}-1x-80.png` | 图标覆盖层，80px，透明底 |
| `icon-{...}-2x-160.png` | 图标覆盖层，160px |
| `icon-{...}-master-320.png` | 图标母版（4×），供再导出其他尺寸 |
| `btn-{...}-layered-1x-80.png` | 合成结果（预合成件，可直接当整图用） |
| `layers-explained.png` | 底托 + 图标 = 合成 的图解（图标层加棋盘底证明透明） |
| `compare-layered-vs-single.png` | 与已定稿「单张生成版」四钮逐列对照 |

■ 底托怎么来的
新跑一次生成（本地 ComfyUI `http://192.168.1.16:8188`，`Qwen_image_2.1`，**同 seed 11 / steps 25 / cfg 1.0 / euler-simple / 1024²**），
提示词与四钮模板逐字相同，**仅把图标从句替换为「不画任何图形」**：

```
… 圆片表面保持纯净的浅暖色木纹，没有任何图形、图案、文字或装饰。纯白色背景，画面里只有这一个圆片，别无他物
```

随后走与 T-537/T-538 **完全相同的后处理**（校色 strength 1.00 对齐招牌 + 方向光倒角 + `α<12` 归零，8× 超采样）。
⛔ 没有采用「擦除现有图标取底托」——刻痕有投影与套色，擦除易留痕，且无法保证四钮共用同一张。

■ 图标怎么抽的
从**已定稿的四张圆片**里按亮度抽线条，不另画：

| 步骤 | 做法 |
|---|---|
| 定位 | 取圆片内切正方形，只处理 `r < 0.78R` 的核心区（避开外圈暗环） |
| 阈值 | 对校色后的亮度做 **Otsu** 二值化，实测阈值 75–79 |
| 软边 | `α = clip((t+7 − L) / 14, 0, 1)`，保留 1–2px 过渡，缩放不出锯齿 |
| 颜色 | **保留原像素 RGB**（含刻痕投影与套色），不重新上色 |
| 线条占比 | settings 5.54% / rank 4.96% / calendar 5.69% / skin 4.23% |

■ 校验读数
| 项 | 读数 |
|---|---|
| 合成 alpha 覆盖（四枚） | 均 **80.1%**（与单张版一致；理论 π/4 = 78.5%，余量为抗锯齿） |
| 与单张版目视对照 | 图标位置、尺寸、刻痕阴影一致，木纹走向不同（见限制 1） |
| 批次体积 | 560 KB（含对照图与母版） |

■ 已知限制（4 条）
1. **底托木纹与单张版不同**：底托是另一次生成的，横向纹路走向与四张原图不一样。若要求「与已定稿逐像素一致」，只能用原图当底托——但那样就不共用了。
2. **线宽继承原图**：图标是从成品图里抽出来的，粗细等于各自原生成结果（齿轮最粗、T恤最细）。要统一线宽得重绘矢量图标，不能再靠抽。
3. **线条色偏黑**：校色把深线压到 `RGB ≈ (5–17, 1–3, 0)`，接近黑褐而非参考木牌的暖褐暗部。若要更「木刻」，可把图标层 RGB 整体替换为木牌暗部值（如 `#5C3418`）再叠，代价是丢掉刻痕阴影。
4. **四钮共用一张底托 ⇒ 木纹完全相同**，排列在顶栏上会出现明显重复感。若要每钮不同纹，需出 2–4 张底托轮换。

■ 运行时接法（二选一）
- **预合成**：直接用 `btn-{key}-layered-1x-80.png`，一张 sprite，零改动；
- **运行时合成**：底托 1 张 + 图标 N 张，图标换装/新增不用重新打图，代价是多一次 alpha 叠加（同尺寸 80²，开销可忽略）。
