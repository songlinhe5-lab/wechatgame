【定稿】顶栏 2×2 钮 · 3D 木质圆牌四件套　落盘 2026-11-02　·　Qwen_image_2.1 · seed 11

■ 它是什么
主菜单顶栏四钮（`MENU_TOPBAR_X` 2×2 排布）的 3D 木质圆牌版本：**设置（齿轮）/ 好友榜（奖杯）/ 打卡（日历+勾）/ 换肤（T恤）**。
取代原有「平涂圆底 `ui_btn_circle_normal.png` + 单色线图标 `ui_icon_*.png`」的组合，
把四个图标烧进同一块木牌的倒角圆片里。图标语义与既有 `ui_icon_*.png` 一一对应，不另立新义。

提示词模板（**只有 `{icon}` 这一段变**，其余逐字相同，保证四枚材质一致）：
```
单个圆形木质圆片居中：正面是完全平的圆板，边缘只有极轻微的倒角，不要凸起、不要球面、不要厚度感；
表面是浅暖色木纹（与游戏界面里木牌招牌同色同亮度），木纹细腻清晰；外圈一道很细的深棕色描边；
画面采用均匀平光，不要强高光、不要大面积亮斑、不要明显投影、不要玻璃反光。
圆片正中是深棕色的木刻线条{icon}图标，线条粗细均匀、简洁。纯白色背景，画面里只有这一个圆片，别无他物
```
`{icon}` 取值：`奖杯（两侧提耳、圆柱底座）` / `日历（顶部两个装订圆环、页面上一个大对勾）` / `挂在衣架上的T恤`

■ 后处理链（纯程序化，`temp/m4-finalize.py`，8× 超采样）
与齿轮钮定稿**逐参数相同**（判据见 K-207 / K-208）：

| 层 | 参数 |
|---|---|
| 颜色迁移 | Reinhard mean/std 匹配招牌木牌 `crop(110,150,650,186)`，`strength=1.00`，只作用于 `mean<245` 的本体像素 |
| 外轮廓 | 最外 2.2% 半径 × 0.45 |
| 外环方向光 | `gain = 0.62 × facing × sin(0.62π·t)`，facing = 光向（左上）与法线点积 |
| 内斜面 | 同上台阶，系数 0.26 |
| 漆面高光 | 左上椭圆软斑，α 46，blur 6% N |
| 投影 | alpha 下移 2px + blur 2.1 + α 0.46 |
| 边缘 | 1.5px 线性抗锯齿；缩放后 `α<12` 归零（去 LANCZOS 振铃） |

■ 已知限制
1. **木纹弱**：母版为弱纹理平涂，无参考木牌那样清晰的横向木纹（与齿轮钮同）。
2. **比周边木框浅**：亮度按招牌校色（≈136），明显浅于基准图里的木框与招牌本体；
   若要与木框同深，把 `MU_T/SD_T` 取样改到木框区域即可。
3. **图标为木刻线条**，非实体浮雕；与既有平涂线性图标同语义但笔触更粗，视觉权重更高。
4. `in-situ` 只验证尺寸与位置，**不证明**与最终背景的材质契合——基准图顶栏区域本是墙面，非产品底图。
