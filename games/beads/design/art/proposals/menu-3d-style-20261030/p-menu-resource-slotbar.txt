■ 它是什么（用户令演进）
底图 = `menu-design-baseline-cat-topbar-final-20261102.png`（顶栏四钮定稿件）。
1. 「在橱窗顶部设计星数豆数的显示，要融合在外框上」⇒ 双槽版（WXG-T-553/555）。
2. 「中间心型去掉，拉成一条整体凹槽，水平放置，图标放置两端，数字样式需要设计」⇒ 抹心形 + 单槽 + 两端图标。
3. 「凹槽不完全嵌入框边，再下移一点，缩短一点，两端图标先出设计再贴进去」⇒ 398×36 → 356×34、下移 8px。
4. 「凹槽一周有阴影不贴合 / 白字不搭 / 图标是白色形状要纹理」⇒ 去外圈阴影、换字色、图标改珠面。
5. 「删除槽阴影试试 / 文字用 logo 色可否 / 星和珠图标再走一轮」⇒ 试无阴影三态、取样 logo 色、出星珠比稿。
6. 「**左边应该是心图案（能量消耗）；底槽用 bbox 做，底色不要透明**」+ 拍板「槽底色取木纹暗色 / 圆角药丸 / 心用体力红 / 珠用奶白」
   ⇒ 本稿当前状态。

■ 定稿参数（这张基准图的 1:1 设计 px）
| 项 | 值 | 运行时映射 |
|---|---|---|
| 槽 bbox | **x 202..558（356）· y 358..392（34）** | 一条 `RectCommand` 的 x/y/w/h |
| 圆角 | **r = 17（药丸，= h/2）** | `RectCommand.radius` |
| 底色 | **`#65331D`（不透明）** | `RectCommand.fill`。取值 = 梁面自身亮度 **5% 分位暗色**（实测；梁面 12%/25%/50% 分位 = `#663622`/`#7B3D1A`/`#8A4620`） |
| 描边 | **1px `#4A2415`** | `RectCommand.stroke` + `lineWidth: 1` |
| 阴影/渐变/透明度 | **全无** | ⛔ 刻意不做：`RectCommand` 只有单色 fill + stroke，渐变与半透明叠色运行时装不出 |
| 左图标 | 心 26px（能量消耗），体力红 `#F7381B` 珠面 | `blit` 位图 |
| 右图标 | 拼豆圆片 26px，奶白 `#F2D9AC` 珠面 | `blit` 位图 |
| 数值 | `#F7C384`（logo 珠面实测中位色）bold 27px，无描边无投影 | `TextCommand`（fill/font 两项即可） |
| 数值摆位 | 左「12/20」贴图标右 11px；右「480」贴图标左 11px；中段整段留空 | — |

**对比度实测**：槽底 L=0.0522 / 字 L=0.6047 ⇒ **6.40:1**（AA 正文门 4.5，接近 AAA 7）。

- 入册：`resource-icons-20261102/ui_icon_{heart,bead}_slot.svg` + `.png`（160² 母版）
- 生成器：`design/ai-workflows/gen-resource-icons.py`（`_svg_slot()`；心用独立 `url(#h)` 体力红渐变）
- 材质：竖向渐变 + **深棕勾边 `#562104`**（logo 暗部同值）+ 内亮缘 + 圆片孔位 `evenodd` **真镂空**；
  出稿脚本另加 1px 贴附投影，让它读成「贴在牌面上的东西」而不是浮着。
- 心 = `#FFB49A → #F7381B → #B32410`（体力红取自现役 `asset-icon-stamina` 实测主体色 `#F7381B`）
- 珠 = `#FFF6E4 → #F2D9AC → #CFA470`

■ 已试并否（避免重复）
| 方案 | 否因 |
|---|---|
| 双槽（各 190×48、±5°） | 用户：「这个设计不行」 |
| 槽体渐变 + 内阴影 + 外圈接触影 | 「一周有阴影，与版面不贴合」 |
| 槽体半透明叠木纹 / 近黑底 | 「底色不要透明」；近黑则读成贴片 |
| 冷白字 `#FFF1D6` | 「文字白色色调不搭」 |
| 冷白平涂图标 | 「图标是白色形状，要纹理」 |
| **星**形图标（含 STAR_GOLD 金） | 「左边应该是心图案，作为能量消耗」 |
| 木刻浮雕图标（深棕刻线 + 下缘亮边） | 26px 下在暗槽上几乎读不出 |
| 无阴影纯填充 / 1px 硬刻线 | bbox 口径下不需要（圆角药丸 + 1px 描边已够定位） |

■ ⛔ 与运行时的关系
1. 槽体已是 **bbox 口径**（一条 rect + fill/radius/stroke）⇒ 运行时可 1:1 还原，**不再需要 9-slice**。
2. **槽高 34 本图 px vs 现役运行时资源条 46px** 仍互斥：本图约 1.48×（招牌 548 vs 落地单 370），46 运行时 ≈ 68 本图 px，
   而拱梁两端梁面只有 ≈44px 高。接入须择一：改矮运行时资源条，或把槽加高并相应缩短。
3. 左项语义 = **能量消耗（心）**，与现役体力一致 ✓；右项 = 豆数（现役 coins 改称）⇒ 文案属数据项改动，另走裁定。
4. 图标为位图自带勾边/渐变/贴附影 ⇒ `blit` 零成本；数值纯色 ⇒ `TextCommand` 的 fill/font 即可。
5. 坐标 ⛔ 直接照抄（本图非 1:1 版面）；真源 = `tuning/layout.ts` + `meta-menu.ts`。
