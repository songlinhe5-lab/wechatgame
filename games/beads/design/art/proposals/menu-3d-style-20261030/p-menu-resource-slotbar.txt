■ 修订：三否 → 三改（2026-11-02 末轮）
| 否 | 改 | 判据 |

| ① 凹槽一周有阴影 | **删掉外侧接触影 + 两端内壁暗角**，只保留「内壁上沿吃光」与「内壁下沿受光」两条 | 整圈暗影会把凹槽读成贴上去的药丸；真凹槽只有内壁两条受光/背光边 |

⛔ **描边/投影为何去掉（实测，不是审美取舍）**
- `packages/framework/src/core/render/render-model.ts` 的 `TextCommand` 只有 `fill / font / align / baseline / alpha`
  —— **没有 stroke、没有 shadow**；`adapters/canvas2d/canvas2d-renderer.ts` 文字分支只调 `ctx.fillText()`。
- 全仓 `strokeText` / `shadowBlur` / `LabelOutline` / `LabelShadow` 命中数 **0**。
- 加描边只能改框架（`TextCommand` 扩字段 + canvas2d 与 Cocos 两条 adapter + 测试），属框架级新单。
- 运行时字体亦全是 `sans-serif`（`view/ui-theme.ts` 的 `UI_FONT`），**无 SF Pro Rounded**；本稿按 bold sans-serif 出，可 1:1 还原。

■ ⛔ 与运行时的关系（接入前置条件）
1. **槽高 34 本图 px vs 现役运行时资源条 46px 互斥**：本图约 1.48× 运行时（招牌 548 vs 落地单 370），
   46 运行时 ≈ 68 本图 px，而拱梁两端梁面只有 ≈44px 高，水平直槽装不下 ⇒ 接入须择一。
2. 槽体**渐变/内阴影/下沿反光** `RectCommand` 表达不了（只有单色 fill + stroke）⇒ 真接入须做 **9-slice 凹槽贴图**。
3. **珠面图标的勾边/渐变/贴附影是位图自带**，走 `blit` 即可，运行时零成本。
4. 坐标 ⛔ 直接照抄（本图非 1:1 版面）；真源 = `tuning/layout.ts` + `meta-menu.ts`。
5. 右项语义 = coins 改叫「豆数」，属文案/数据项改动，须另走裁定。
