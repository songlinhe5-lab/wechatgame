■ 它是什么
菜单「圆形图标按钮」的定稿形态：不透明白底生成 → 校色对齐上方招牌木牌 → 程序化倒角。
主题为齿轮（设置入口）。同族已有左右箭头木牌（基准图 `(66,663)` / 直径 ≈95），本件为其可复用规格示范。

■ 规格
- 直径 92px（1x）／184px（2x），圆形，`alpha` 边缘抗锯齿后**低 α (<12) 已归零**，无 LANCZOS 振铃光晕
- 圆面积占比理论 78.5%，实测 alpha 覆盖 **79.8%**（余量为抗锯齿边，正常）
- 母版：ComfyUI 本地 t2i，`seed=11`，产出 1024×1024 白底圆片（`temp/comfyui-out/m3-t2i-s11/`）
- 校色目标 = 招牌下缘木纹带 `crop(110,150,650,186)`

■ 分层构成（全部程序化，`temp/m3-finalize.py`，8× 超采样）
| 层 | 参数 |
|---|---|
| 颜色迁移 | Reinhard mean/std 匹配，`strength=1.00`（仅作用于圆片本体 `mean<245` 的像素） |
| 外轮廓 | 最外 2.2% 半径 × 0.45 压暗 |
| 外环方向光 | `gain = 0.62 × facing × sin(0.62π·t)`，facing = 光向（左上）与法线点积 |
| 内斜面 | 同上台阶，系数 0.26 |
| 漆面高光 | 左上椭圆软斑，α 46，blur 6% N |
| 投影 | alpha 下移 2px + blur 2.4 + α 0.46 |
| 边缘 | 半径 1.5px 线性渐变抗锯齿 |

■ 为什么环带不是深棕描边
采样基准图左箭头木牌（`(66,663)` / 直径 95）后发现：「外环」与「牌面」**是同一种木材**——
环均值 `157/84.5/39`、牌面 `152/80/37`，亮侧 `228/156/90`。
即参考件靠**方向光**塑造立体，不是靠深色描边。故采用「同色木材 × 方向光增益 + 极细暗轮廓」，
而非「塑料圆盘 + 橙圈」；这样木纹不被覆盖。

■ 复现
```
python3 temp/m3-finalize.py     # 依赖 temp/dashscope-out/custom/m3-raw-s11.png
```
改 seed 只需改脚本内 `SEED`（原始候选 `m3-raw-s{11,222,333}.png` 齐备）。

■ 已知限制（不视为缺陷，定稿时已确认接受）
1. **木纹弱**：母版本身是弱纹理平涂，无参考件那样清晰的横向木纹。如需纹理须另加程序化条纹层。
2. **比左右箭头浅**：本件亮度 136.5，箭头牌面亮度 ≈91。因为校色目标是**招牌**（亮度 132.9）不是箭头，
   二者属不同材质层级。若要向箭头看齐，把 `MU_T/SD_T` 取样改到箭头牌面即可。
3. **位置 `(57,272)` 为样式验证位**，非最终布局位；正式入切图时应重新指定锚点。
