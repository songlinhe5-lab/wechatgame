■ 它是什么（用户 2026-11-02 令 + 拍板）
底图 = `menu-design-baseline-cat-topbar-final-20261102.png`（顶栏四钮定稿件，本稿不动它一个像素）。
在其橱窗拱形顶梁上嵌两块**放数值的槽板**：
- 左槽 = **心数（体力值）**：红心图标 + `12/20`（占位读数）
- 右槽 = **豆数（获取奖励分）**：金币图标 + `480`（占位读数）
- 槽板随拱弧各带 ±5° 倾角，中央心形装饰保留。

■ 方法与三步流程（用户拍板「PIL 定位 + 云端补质感」）
| 步 | 命令 | 产物 |
|---|---|---|
| 1. PIL 定位 | `python3 games/beads/design/ai-workflows/menu-resource-slot.py --y 324 --h 48 --w 190 --left 168 --right 424 --tilt 5` | 定位稿（深色胶囊槽 + 图标数字） |
| 2. 空槽参考底 | 同上 + `--empty` → `temp/dashscope-out/custom/slot-empty-src.png` | 无字空槽（给云端当参考） |
| 3. 云端重绘 | `dashscope-generate.py --profile token-plan --model wan2.7-image --ref <空槽版> --bbox 130,295,645,400 --size "752*1344" --text "<槽板质感指令>"` → 产物 mv 留档 `slot-cloud-v1.png` | 云图（**只有 wan2.7 线认 bbox**） |
| 4. 贴回 + 叠字 | `menu-resource-slot.py … --cloud temp/dashscope-out/custom/slot-cloud-v1.png --bbox 130,295,645,400` | **本定稿件** |

取证（2026-11-02 实测）：
- 云图原始输出框外 meanΔ 11.1（wan2.7 全图轻微漂移，与 `model-matrix.md` §5 已知行为一致）⇒ 必须贴回。
- 贴回实现 =「框外硬保定位稿原像素 + 羽化只向内 3px（blur 后与硬边 mask 相乘）」。
- **框外 maxΔ = 0**（逐字节校验通过）；框内 meanΔ 33.2（槽板质感 + 图标 + 数字，应有改动）。

■ 已知取舍（评审时勿当缺陷重报）
1. **图标是现成件复用**（红心 `asset-icon-stamina`、金币 `asset-icon-coin`）。用户要求「图标单独设计」
   ⇒ 图标重设计是**下一单**（可走「模型出图 → 位图追踪」同顶栏图标链），本稿先验证槽板与排版。
2. 数值是占位读数（12/20、480），实际接运行时数据时由 UI 渲染。
3. 云端只重绘框内且形状锁死，但槽沿细节由模型自由发挥 ⇒ 重跑同一命令产物会略不同（云图无 seed 复现保证
   时），定稿件以本文件所指 PNG 为准，重出需走 git。
