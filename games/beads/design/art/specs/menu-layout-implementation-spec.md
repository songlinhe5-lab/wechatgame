## 1. 坐标系与锚（全部设计 px = 750 宽基准，与 `DESIGN_W` 同域）

- **k = 750 / windowWidth(dp)**（`getWindowInfo().windowWidth`）。微信 `rpx` 即本系，可直填。
- **纵向四锚（逐机唯一变化的量，全部走接口，fallback 只在接口无效时生效）**：

| 锚 | 定义（设计 px） | 接口源 | 无接口 fallback |
|---|---|---|---|
| `st` | safeTop 换算 | `safeArea.top × k` | `SAFE_TOP_H = 120` |
| `cap` | 胶囊底换算 | `getMenuButtonBoundingClientRect().bottom × k` | `SAFE_TOP_H = 120` |
| `sb` | 底部 inset 换算 | `(windowH − safeArea.bottom) × k`（**窗口底基准** · WXG-T-447） | `SAFE_BOTTOM_H = 68` |
| `H` | 系高 | `windowHeight × k`（与 `Viewport` 同源，窗口底基准） | `DESIGN_H = 1334` |

- ⚠ **接口优先语义沿用 v1.75**（`safeEdgeInset` 判例 K-124）：接口 > 0 就只信接口，⛔ 不 `max` 静态宏。现函数带 `SAFE_EDGE_MARGIN=4` 加数，本链隙值（16/32/4）**已含边距语义** ⇒ 落码二选一：裸换算（`round(dp×k)`）或复用函数后把隙值各减 4，**不许双重加 4**。
- ⚠ 现 `DESIGN_H = 1334` 假设 SE 档，本规范下**系高逐机变**（五档实测 1625~1630 不等）⇒ 底锚计算禁用 `DESIGN_H` 常量，走 `H` 锚。

## 2. 纵向链（自顶，全常量恒定，逐机只随锚平移）

```
bow0   = max(st + 16, 61)           # 蝴蝶结顶：安全区下固定 16；无刘海不低于 61（加长前绳长，绳子完整露出）
board0 = bow0 + 42                  # 招牌板顶（结/板画面交叠 30 ⇒ 视觉链 180）
sign1  = bow0 + 165                 # 招牌板底（v3.7：图内结顶 y159 → 板底 y586，等比 370/960 后链高 ≈165）
cta1   = H − sb − 32                # CTA 底锚（底隙 32）
cta0   = cta1 − CTA_H
zone   = cta0 − sign1               # 板底↔CTA顶 自由区
G      = 871                        # **橱窗组**（v3.6：资源条嵌在橱窗顶部覆盖楣上 46 px，不再占堆叠高度；v3.4 的 917 作废）
gap_top = (zone − G) / 3            # 组隙 上:下 = 1:2（下隙 = 2×gap_top；v3.3 裁定迁到整组口径）
case0  = sign1 + gap_top             # 橱窗顶（v3.6）
bar0   = case0                       # 资源条顶 = 橱窗顶（条向下覆盖 46 px；Δ12 只作下限，五档 gap_top 39~130 ✓）
bar1   = bar0 + 46
case0  = bar1                       # 橱窗顶（**与条一体，缝 0**，v3.4）
case1  = case0 + 871                # 橱窗底（**恒定不拉伸**，v3.3 裁定）
bt     = cap + 4                    # 顶栏钮顶（对齐胶囊底，不占布局预算）
```

- 橱窗**不拉伸**（v3.2 三段式拉伸案被否留史：立柱纹理实测可拉 0.17 平移不变，但观感「太长」）。
- **v3.4 条窗一体**：旧链「条钉招牌下 Δ12 + 窗在条底另分隙」作废（五档图上条窗拉开 106~213 ⇒ 与底图实物相接矛盾）；现整组（917）在自由区内按 1:2 分隙，组内零间隙。
- **v3.9 SE 档自洽**：st=40 但结顶下限 61（高于 st+16=56）⇒ 招牌链 165 后 zone = 984，减组 871 得 113 ⇒ gap_top ≈ 37.7（≥Δ12 下限 ✓）、gap_bot ≈ 75.3。v3.7 在结顶 = 56 时是 39.3/78.7。
- 常量表（v3.9）：顶隙 16 · 结顶下限 61 · 底隙 32 · Δ12（只作组隙下限）· 招牌链 165 · 招牌图框 370×298 @x190（bowYOff 119 · boardCyOff 216；图 960×772，绳在 v3.7 的 622 上加长 150px）· 条 46（嵌窗顶） · 窗（含楣）871 · **组 871** · 钮行 bt=cap+4。v3.7 的图框 370×240（bowYOff 61）作废；v3.4 的「组 917 = 条 46 + 缝 0 + 窗 871」、v3.6 之前的招牌 474×180 与 v3.6 的 480×311 @x135 口径作废。

## 8. 走马灯（v3.8 补 · 用户 2026-10-16 裁）

**结论**：橱窗是店里的家具，不动；关卡是展品，只在玻璃里换。整窗滑动不采用：资源条嵌在橱窗顶（`bar0 == case0`）会被一起带走；橱窗宽 544，滑到一半会同时露出两个框体并压到 ◀▶。

**分层（自下而上）**：

| 层 | 内容 | 动不动 |
|---|---|---|
| 固定底层 | 墙、橱窗框体位图（含白板、顶灯）、资源条 | 固定 |
| 滑动层 | Boss 豆画 + 本项的三态盖章（大锁 / 沙漏 / 通关飘带） | 水平平移，裁到 §3「走马灯裁切区」361×527（白底） |
| 固定上层 | 玻璃高光（若单独成层）、木牌板、◀▶、顶栏、CTA | 固定；高光压在滑动层上，内容才显得在玻璃后面换 |
| 木牌文字 | 「第 N 关 / 关名」 | 不平移，**先淡出后淡入**：进度 0→50% 旧字透明度 1→0，50%→100% 新字 0→1，两段不重叠（重叠时两行字叠在一起看不清，原型已验） |

- **盖章一律跟内容走**：三态盖章画在滑动层里、坐标相对本项，所以必须整枚落在裁切区内。大锁 / 沙漏本来就以花心为圆心居中，不受影响；通关飘带由图位右上角挂出改为裁切区右上角内缩 12（§3）。
- **相邻项间距 = 裁切区宽 361**：滑动偏移 `dx` 时，当前项画在 `dx`、相邻项画在 `dx ± 361`，都裁到白底；原型示意帧 = 通关项向左滑出 35%、进行中项从右侧滑入。

**交互参数**（`tuning.ts` `MENU_CAROUSEL`；快甩 / 阻尼 / 吸附是临时值，真机验收后改这一处）：

| 项 | 值 | 说明 |
|---|---|---|
| 点按 / 拖动分界 | 位移 ≤ 10 设计 px 算点按 | 点按 = 进选关（`open-levels`，热区 Boss 图位）；超过即进入拖动，松手不触发点按 |
| 翻页阈值 | 拖过裁切区宽 30%（≈127 px） | 不到阈值松手回弹到原项 |
| 快甩 | 松手速度 ≥ 0.6 设计 px/ms 也翻页 | 临时值。优先于距离 |
| 两端 | 回弹，不循环 | 陈列序 = 下一未通关在前、已通关反序在后 |
| 两端拖动阻尼 | 越界方向只跟 0.35 | 临时值 |
| 吸附动画 | 180ms，三次缓出 | 临时值 |
| ◀▶ | 同一次翻页动画 | 到头不响应（不另做置灰） |
| `reduceMotion` | 不平移。位图按进度交叉淡变；程序化豆画在进度 0.5 处切换 | 木牌文字仍是两段淡变 |

**架构约束**：滑动偏移是 shell / VM 的状态，view 只读（L5）；热路径不新建集合（拖动中每帧只改一个数值）。
