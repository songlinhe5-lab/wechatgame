> ⛔ 不改：图案本体（boss / 陈列关豆画）、背板烘图、橱窗框体、射灯、层板、圆台、木牌、金章、走马灯滑动与裁切。

## 0. 为什么不是「画框 + 卡纸 + 玻璃反光」原样三件套

v2 生产档自 `[WXG-T-585]`（2026-11-07 切生产）起，背板 `ui_menu_backdrop`（750×1334）**已烘**「橱窗木框 / 玻璃 / 射灯 / 层板 / 圆台 / 空木牌」⇒ 再叠程序化框、灯、座会出**双框双灯**（正本 `menu-layout-implementation-spec.md §12.1`「落地影 / 窗框 / 层板木托 / 射灯光晕 / 木牌本体 **整批退场**」）。

因此本规格把原三件套收敛为：

| 原设 | 收敛为 | 理由 |
|---|---|---|
| 画框 | ⛔ 不新增 | 背板已烘框体；重画即双框 |
| 整张内衬卡纸 | **M3 压边内框**（art 框外 8px 双线） | 不缩可见面积、不与背板白板形成「两层纸」 |
| 投影 | **M1 暗角 + M2 接触影** | 拆成「背衬压暗」与「落地接触」两件事，各司其职 |
| 玻璃反光斜条 | **M5 默认关（备选）** | 背板已烘顶灯与玻璃高光；双高光读作污渍（`menu-layout-implementation-spec.md §9.5`「玻璃高光不另出图」） |

| 件 | x / y / w / h | 出处 |
|---|---|---|
| 展品框 `MENU_V2.art` | **212 / 530 / 325 / 314** | `tuning/menu.ts` |
| 玻璃裁切 `MENU_V2.clip` | **150 / 470 / 450 / 434** | 同上 |
| 通关章 `MENU_V2.seal` | **545 / 405 / 90 / 90** | 同上 |
| 展品可用高 `avail` | **374**（clip 顶 ↔ 圆台面 = 框底） | `meta-menu.ts` `[WXG-T-601]` |

**推导读数（本规格的判据基准）**：

- 展品中心 `x = 374.5 ≈ 375`（屏中 375，差 0.5 可忽略）。
- **实际绘制包围盒（两条腿共用）**：高 = 玻璃顶 ↔ 台面 = **374**；宽 ≈ 374（位图腿按内容 bbox `182/180 × 374 ≈ 378`、程序化腿 `area = avail = 374`）⇒ 本规格取 **`avail` 见方**（x 187.5 / 底 490 / 374×374，y-up）。
- ⚠ 名义 `MENU_V2.art`（325×314）**不是可见范围**：它只是 `drawLevelThumb` 的 `w` 形参 / 旧框；两条腿都会越出它（位图 ±26 宽 + 顶 60，程序化 ±24.5）⇒ 装裱层若按名义框画，暗角与压边会落进珠面 26–60px（§9-3 实测反例）。
- boss 阵 **30×30**（`levels-data.ts` `L00009` 曼陀罗）/ 32×32（`L00010`）⇒ 实际珠径 = 374/30 ≈ **12.5**、374/32 ≈ **11.7**（名义框读数 10.8 / 10.2 偏小，作废）。
- **装裱层所有边宽上限 = 10px**（不得 ≥ 珠径 11.7，否则暗角横跨整颗珠，边缘读成脏色）。
- M3 压边线右缘 = 374.5 + 187 + 8 = **569.5**；金章左缘 545 ⇒ 金章压住框右上角 **24.5px**（金章后画，物理上在玻璃前）—— 预期，不为避让收窄（见 §3.3）。

## 2. 层序与插入点

```
L0 背板 blit（已烘框 / 玻璃 / 射灯 / 层板 / 圆台）
L1 clip（450×434）
     展品豆画 + M2 接触影（随 dx 平移）+ 三态盖章 / 珠圈 / 锁形
   unclip
L2 固定装裱层：M1 暗角 → M3 压边内框 → M4 上缘受光线
L3 木牌字 / ◀▶ / 顶栏 / CTA
```

**两条硬约束**：

1. **M2 必须进 clip 内**：接触影是「展品在台面上的投影」，必须与展品同 `dx` 平移；画在固定层会出现「展品滑走、影留在原地」的穿帮。进 clip 同时获得自动裁切，相邻页的影不会漏到裁切区外。
2. **M1/M3/M4 必须画在 unclip 之后**：它们是「框内衬纸」，属于固定上层（`menu-layout-implementation-spec.md §8` 分层表「固定上层压在滑动层上，内容才显得在玻璃后面换」）。若画在 clip 内，相邻展品会滑过并盖住压边线，读作「框会跟着内容跑」。

## 3. 逐件规格

> 所有 α / 边宽为**提案值**，真机目检后回填（§8）。落码坐标以 y-up 换算（`DESIGN_H 1334`），本表给 y-down 便于对照 `MENU_V2`。

### 3.1 M1 背衬暗角（vignette）

| 项 | 值 |
|---|---|
| 位置 | **实际绘制包围盒**四边向内（y-up x 187.5 / 底 490 / 374×374；y-down 顶 470 ↔ 底 844） |
| 形态 | 四边各一条向内渐暗带，中心完全透明；四角**不叠**（上下通条 + 左右短条，避让角部 α 叠加） |
| 色 | `shadowInk` `#3D2E1E` |
| 三档叠层 | 外圈宽 **10** α **3%** / 中圈宽 **6** α **4%** / 内圈宽 **2** α **5%** ⇒ 峰值累计 **12%** |
| 圆角 | r **8**（`[待实测]`：随背板白卡内角，若白卡为直角则改 0） |
| 作用 | 把背板白板压暗一圈，让珠面（画面唯一高饱和）浮出；同时遮住白卡与展品的接缝 |
| 命令数 | 4 边 × 3 档 = **12** 条 `rect` |
| 状态 | 有图态才画（§4） |

**为什么不用名义框**：装裱层要压的是「珠面最外缘」，不是 `art` 框；名义框左右各缩进约 26、顶部缩进 60，按它画会把暗角横在珠面内部（§9-3 实测反例）。

**α 上限判据**：峰值 12% 压在珠面最外 2px 上，明度下降 ≤ 3%，不跨任何可读阈；若真机目检读作「脏边」，先降内圈 α（5% → 3%），⛔ 不加宽边带。

### 3.2 M2 底缘接触影

| 项 | 值 |
|---|---|
| 位置 | 展品底缘（y-down `art.y + art.h` = 844）；影带向上 +2 压住珠面底行、向下 −12 落台面 |
| 形态 | 横条三档叠层（高圆角矩形近似椭圆化，本项目 `builder` 无椭圆图元） |
| 宽 | **展品实际绘制宽 × 0.92 = `avail × 0.92` ≈ 344**，中心 x = 374.5（见下「宽基准」） |
| 色 | `shadowInk` `#3D2E1E` |
| 三档 | 贴地 **6** α **14%** / 中段 **10** α **8%** / 外圈 **14** α **3%** ⇒ 贴地累计 **25%** |
| 圆角 | r **6** |
| 作用 | 珠面「坐」在圆台上，而不是浮贴白板 —— 这是装裱层里唯一提供「实物厚度」的一件 |
| 命令数 | **3** 条 `rect` |
| 状态 | 有图态才画（§4） |

**宽基准（两腿同取 `avail`，⛔ 写死 325 / 450）**：

| 腿 | 实际绘制宽 | 依据 |
|---|---|---|
| 位图腿（**2026-11-20 退场**） | 内容 bbox `182/180 × avail` ≈ **378** | `MENU_ARC_ART_CONTENT`；`min(size, clip.w) = 450` 是 **blit 框**（含透明边），不是珠面宽 |
| 珠面腿（**2026-11-20 起现役**） | `area = avail` = **374** | `drawBeadFace(⋯, anchor='bottom')` 的槽高（主菜单展品改 boss 关珠面缩略，用户令「取消纹理展示」） |

两腿差 ≤4（≈1%），统一取 `avail`（374）⇒ 影宽 344。⛔ 取 450 会让影比珠面宽 36（左右各 18），读作「一团脏雾」；取 325 会窄 49，读作「悬浮」。

**落码（y-up）**：`top = art.y + 2`，三条同顶：h 6 / 10 / 14 ⇒ 底缘 486 / 482 / 478；最低 478 仍在 clip 内（clip 底 430）。

### 3.3 M3 压边内框

| 项 | 值 |
|---|---|
| 位置 | **实际绘制包围盒**四边外扩 8 ⇒ y-up x 179.5 / 底 482 / 390×390；**上缘夹到玻璃顶 864**（展品顶 = clip 顶，外扩会压到烘好的窗框）⇒ 实高 **382** |
| 外线 | `panelBorder` `#E6DAC3`，**1px**，r **6** |
| 内线 | `panel` `#FFFCF6`，**1px**，内缩 1px，r **5** |
| 作用 | 把展品区从白板上「切」出来，形成纸边压痕；替代整张卡纸，不缩可见面积 |
| 命令数 | **2** 条 `rect`（描边） |
| 状态 | ✅ **恒画**（空框 / 锁态也画，作为「待陈列槽位」的边界） |

**金章压角**：右缘 **569.5** 与金章（x 545..635，y-down 405..495）重叠 **24.5px**，金章后画 ⇒ 压住框右上角，属**预期**（物理上金章在玻璃前）；⛔ 不为避让收窄（会导致左右边距不对称，肉眼可辨）。

### 3.4 M4 上缘受光线

| 项 | 值 |
|---|---|
| 位置 | 压边内框上缘内 1px（外线内侧；落码 y-up = 框顶 − 2、高 1，横跨内宽 −2） |
| 形态 | **1px** 线 |
| 色 | `plaqueBevel` `#F7CD9D`（门楣梁顶实测值，同 `wood_sheen` 语义） |
| 作用 | 光向统一（顶灯在上）；与 T3「上 sheen / 下 edge」容器语言同源 |
| 命令数 | **1** 条 `rect` |
| 状态 | ✅ **恒画** |

⛔ 下缘不另加暗线：`panelBorder` 已提供分隔；再加 `woodEdge` 会读成「木框」，与「纸压边」语义冲突。

### 3.5 M5 玻璃斜光条（默认关 · 备选）

| 项 | 值 |
|---|---|
| 位置 | `MENU_V2.clip` 区内，左下 → 右上 **24°** |
| 形态 | 宽带 **56**，α **5%**，`panel` `#FFFCF6` |
| 启用条件 | **仅当**真机目检证实背板顶灯高光不足 |
| 默认 | ⛔ **关**（背板已烘玻璃 / 射灯 / 顶灯，双高光读作污渍） |
| 待实测 | 高屏档 `ui_menu_backdrop_expanded`（750×1750 @0,−208）整图缩放下，顶灯位置是否偏移 |

| 态 | M1 暗角 | M2 接触影 | M3 压边 | M4 受光 |
|---|---|---|---|---|

| 进行中（陈列关豆画） | ✅ | ✅ | ✅ | ✅ |
| 已通关（boss 成品） | ✅ | ✅ | ✅ | ✅ |
| 满星（+ 珠圈框） | ✅ | ✅ | ✅ | ✅ |

**锁定 / 空态不画 M1、M2 的判据**：锁形是**符号不是实物**（`meta-menu.ts` `[WXG-T-917]` 明令「不坐台面 —— 锁是符号不是实物」）；给符号加接触影会读成「柜里放着一把真锁」，与语义冲突。空态同理：没有展品就没有「被衬纸压暗的背板」。

| 用途 | token | 值 | 出处 |

## 8. 验收判据（可实测）

1. 展品框外 **8px** 处存在 1px `panelBorder` 闭环，四角 r6（截图取色）。
2. 压边内框**上缘**存在 1px `plaqueBevel` 亮线；下缘无暗线。
3. 有图态展品底缘存在 ≤14px 高软影，贴地段（4px 内）α ≥ 18%。
4. `locked` / `comingSoon` / 无 `level` 三态**无** M1 / M2。
5. 菜单帧命令增量 **≤ 18 条 `rect`**（K-6 装置出数）。
6. **零新增 hex**（色表锁 46 条不变）。
7. 包体 **0 KB** 增量。

**实装读数（2026-11-15）**：`main-menu` 金样本 1117 → **1135**（+18），逐 kind 仅 `rect` +18、其余 0 漂移；`settings` / `signin` / `level-select` 因共用菜单底页同样 +18。两条腿的判定与宽度按 §1/§3.2 实际包围盒落码，⛔ 未按名义 `art` 框。
