## 0. 要解决什么

品牌色板（15 板 2104 色）里存在大量在**刻面渲染**下不可分辨或不可显示的配色：
近白族互撞、近黑族元素消失、同族色阶被明暗带吞掉。选色若无门，产出的图纸玩家读不出目标色。

## 1. 三道门（正交并列）

### 1.1 门 A · 全深宪法（渲染侧约束，已生效）

珠体派生元素**恒比原色深**：底图 `mix(base,−0.30)`、框色/孔深 `mix(base,−0.44)`、
孔线 B14 影墨 `#1E2033`。

- **裁决记录**：条件描边律（深色珠换亮边）曾出七色三臂图例对比（2026-09-27 上午），
  被用户以「深珠×浅底错珠时亮边撞浅底」否决——边框职责 = 同时拉开珠体与背景，
  全深规则只在「深珠×深底」一格退化，且该格多数配对已被门 C 预先互斥（证据 §4-③）。

### 1.2 门 B · 单色下限（绝对门，逐色）

```
selectable(c) ⟺ ΔE76( c, mix(c, −0.44) ) ≥ PIT_VISIBLE_MIN(=8)
```

框色/孔深是最深派生元素，它与珠体的距离决定"三件套是否还存在"。向黑混合是乘法收缩，
`#000000` 处全等（ΔE=0）⇒ 黑珠在门 A 下**不可选是宪法的明确代价**，图纸要"黑"用
最暗深蓝/深棕（luma≈0.15 档）顶替。

**剔除名单（全量 2104 色仅 6 色）**：

| 板 | 色号 | hex | ΔE(base,pit) |
|---|---|---|---|
| artkal-m | MH7 | `#000000` | 0.0 |
| mard | H7 | `#000000` | 0.0 |
| yant | Y011 | `#000000` | 0.0 |
| hama-maxi/midi/mini | H18 | `#141315` | 3.2 |
| diamond-dotz | 8001 | `#1F1F24` | 7.0 |

其余 12 板 0 剔除。**注册表不剔色**（`palettes-data.ts` = 品牌实物镜像，studio 照片
映射需全量查色）；剔除只发生在选色交互层。

### 1.3 门 C · 近似族（相对门，两两，仅同品牌内）

```
confusable(A, B) ⟺  bandΔE76(A,B) < NEARFAM_BAND_MAX(=10)
                 ∧  baseΔE76(A,B) < NEARFAM_BASE_MAX(=22)
band(c) = { mix(c,−0.30), c, mix(c,+0.38) }   // edge/base/lit 三点带
```

- **选色规则**：选中 c ⇒ 同品牌内所有与 c confusable 的色置灰；等价实现 = 候选色与
  **每一个已选色**逐对判据。**不传递、不聚类**——连通块口径在 τ=12 时把 dotz 461 色并成
  一块 428 色，灾难性过锁，实证作废。
- **跨品牌不设限**（用户 2026-09-27 裁）：不同品牌同色号/同色值互不干涉。
- **为什么是双阈值合取**：纯色带最小距判据会误杀「淡黄 `#FFFBAA` ↔ 橄榄 `#8CA12A`」
  （band=12.0 但 base=40.4，肉眼可分）——band 门抓"刻面吞色"，base 门防"异色相误伤"。
- **τ_band=10（2026-11-17 Spike 定标）**：S37 浅青↔S72 青蓝 bandΔE=10.0，用户目测两刻面豆
  分不开 ⇒ τ=10 刚好卡线；S67 粉杏↔S129 粉紫 bandΔE=15.0，用户目测分得开 ⇒ τ=10 放它过。
  旧值 15 是 2026-09-27 黄对 `#F9F55D`↔`#E6C61E`（band=13.3）钉的，钉点实际在 10–15 之间
  （该对 band 在 10 左右时视觉也模糊）；收紧到 10 后 Spike 全量复核通过。
- **τ_band=10 不取 12 的硬理由**：bandΔE=12 在 Artkal S 约有 168 对，bandΔE=10 约 89 对；
  10 到 12 段约 79 对是"半可分"——用户 Spike 反馈 band=10 那个档位正好分不开，
  τ=12 会拦不住它们。τ=10 锁色规模仍在可控（§2 可换性验证）。

**四对代表性复核**（τ=10 判据全过）：

| 色对 | band | base | τ=10 判定 | τ=15 判定 |
|---|---|---|---|---|
| S37↔S72 浅青↔青蓝（用户 Spike） | 10.0 | 13.4 | 🔒 锁 ✓ | 锁 |
| 截图两黄 `#F9F55D`↔`#E6C61E` | 13.3 | 20.2 | ✅ 放 | 锁 |
| 淡黄↔橄榄 `#FFFBAA`↔`#8CA12A` | 12.0 | 40.4 | ✅ 放 ✓ | 放 |
| S67↔S129 粉杏↔粉紫（用户 Spike） | 15.0 | 19.5 | ✅ 放 ✓ | 锁 |

用户 Spike 定标：S37/S72（band=10.0）两刻面豆**分不开** → 锁；
S67/S129（band=15.0）两刻面豆**分得开** → 放。τ=10 刚好卡视觉边界。

## 2. 定标数据（2026-11-17，τ=10 收紧后，全量 15 板）

- 逐板最近带距分位：密集板（artkal-*/mard/dotz/yant）p50 = 2.4–6.5，稀疏板（hama/perler/nabbi）p50 ≥ 6.5（τ=10 收紧后，每板"近距族"数量减半）；

- **可用性验证（贪心独立集 = 互分色上限）**：artkal-s 约 150+、mard 60+、artkal-m 47、

## 5. Studio 实现方式 **[TODO·未裁]**

门在 studio 生成/选色时执行，**烘焙 vs 程序化待用户确认**：

| 方案 | 内容 | 代价 |
|---|---|---|
| 烘焙 | 生成期预计算逐品牌邻接表（色号→近似族名单 + 下限标记）随 `palettes-data` 或独立 JSON 出，运行时查表 | 数据量：2104 色邻接表（dotz 461 色最密）；色板更新须重烘 |
| 程序化 | 选色事件现算 ΔE（Lab 转换 ~20 行，O(已选数)，≤35 色） | 无预计算物；studio server 与游戏侧若共用需一份公共实现 |

判据计算量极小且只在选色事件触发（非热路径，无 C2 顾虑），两案皆可；
差异点 = **色板漂移时邻接表失效**要不要防（烘焙案需把 `sync-palettes` 门接上，程序化案天然免疫）。

### 5.1 分布质量（软约束，2026-11-17 用户提）

> **问题**：贪心选色可把 8 颗全选在 bandΔE=10–15 的"边界附近"，虽然两两通过门 C，但全色系
> 观感趋同（集中在某色相簇或某明度带）。**不是硬门**（不过不挡），是选色策略优先级优化。

行业最佳实践（BeadPattern / ArtPatt / 十字绣行业）：

| 策略 | 说明 | 适用场景 |
|---|---|---|
| **Hue 扇区覆盖** | HSL 色相环分 8 扇区（每扇区 45°），选 N 色时**至少覆盖 ⌈N/2⌉ 扇区** | 通用 |
| **明度跨度** | 选色集 luma max - luma min **≥ 40**（0-100 标度），防全在亮域或全在暗域 | 有背景色时（深底需亮色对比，浅底需暗色对比） |
| **最大-最小距** | 每新选色与已选集的**最小 bandΔE ≥ 15**（比门 C 的锁线 10 再松一档），防所有对刚卡线 | 高多样性需求关卡（30+ 色） |

**落地方式**：Studio 侧选色时，每候选色给两个 score：
1. `hard = 0` 若与任一已选 confusable（门 C）→ **挡**
2. `soft = hue扇区加分 + luma跨度加分 + min-bandΔE加分` → **排序优先级**

不是独立门，是门 C 之后的**选色排序器**。贪心独立集的实现可以直接在候选列表按 `soft` desc 迭代。

### 5.2 量化管线（照片 → 选色）

行业标准（Median Cut + Dominant Color / ArtPatt 口径）：

```
照片 → Median Cut (k-medoid 量化到 N 色，N=关卡上限 35)
     → 每 cluster 取 Dominant Color（众数，不取均值——均值生灰浊感）
     → 映射到品牌色板（ΔE76/OKLab 最近邻）
     → 门 A/B/C 过滤（深珠剔除 / 单色下限 / 近似族互斥）
     → 分布质量评分排序 → 最终选色
```

**落码位置**：`tools/scripts/palette-quantize.mjs`（零依赖 Node，JSON/PPM 像素输入 → 选色报告 + HTML 预览）。
项目已覆盖品牌色板 + 门 B/C，缺的只剩**量化算法替换**（Median Cut → K-means 精修，§6 已知限制 1 提及）。

## 6. 诚实声明

1. ΔE76 在蓝色区略钝（已知非均匀性）——真机复核若蓝族误放，升级 CIEDE2000 重定标；
2. 三点带（edge/base/lit）是四刻面（含 −0.16 右面）的近似，误差在阈值余量内；
3. 「深珠×深底」残余风险以示意 PNG 判定，真机错珠场景（含 L0a 接触影、珠间隙）待 T-215 归位后复核；
4. 定标用的七色测试板（黑白橙绿蓝青紫）非生产十色，结论以本文 §2 全量数据为准；
5. 本文初稿落 `design/art/`（用户指定），同日正式合并至 `games/beads/design/art/specs/`（用户裁「合并」），与 art-bible / assets-spec 等姊妹文档同层；`design/art/` 目录已删；
6. **2026-11-17 Spike 变更**：`NEARFAM_BAND_MAX` 从 15 收紧到 10（用户目测 S37/S72 band=10.0 刻面豆分不开，S67/S129 band=15.0 分得开）；新增 §5.1 分布质量（Hue 扇区 / 明度跨度 / max-min 距）和 §5.2 量化管线（Median Cut + Dominant Color）。
