# GDD · S9 暂停与设置（Pause & Settings）· beads

- 项目：`games/beads` · 版本 v1.2 · 任务号 WXG-T-015
- 数值纪律：冻结常量只引用 `systems-index §3`（§3.1 布局带/避让、§3.5 重置与告急、§3.8 热区）；面板动效毫秒归 `ux/ux-spec.md`，本篇不自写。
- 依赖锚点：`core-loop.md` §2.1（PAUSED 状态与「重玩本关」）、`timer-gameover.md` §2.3（冻结语义）、`tray-spawner.md` §6（心跳冻结）、`architecture-beads.md` §2（bgm/sfx 双通道 setMuted）。

## 1. 目标

提供"随时可走、一键暂停"的唯一通道（左上设置齿轮），冻结全部关内计时与供料；承载音乐/音效开关与「重玩本关」，并保证恢复后世界从暂停值无缝续算。

## 2. 机制

### 2.1 入口（单通道原则）

- **唯一入口**：`HUD_BAND` 左侧设置齿轮（§3.1 布局带；热区 88×88，`TOUCH_MIN` UI 控件口径 §3.8）。**无独立设置页、无第二个入口**（wxgame-ux-spec §2 纪律：避免双入口状态不一致）。
- 齿轮点击 → S2 路由优先级 1（input-control §2.1 路由表最高位）→ S1 切 `PAUSED`。
- 可暂停状态：仅 `PLAYING`。其余状态点齿轮 = 忽略（PAUSED 面板本身只响应面板按钮）。
- 双模式一致：普通/冲刺共用同一齿轮、同一面板（冲刺模式下「重玩本关」文案变「重新冲刺」，行为 = 整关重置语义；P1 已冻结：2026-09-12 用户拍板，重置连带冲刺连击态归零）。

### 2.2 暂停面板（内容清单，冻结范围）

| 元素 | 行为 | 备注 |
|---|---|---|
| 继续 | `game:resumed` → S1 回 PLAYING | 主按钮 |
| 重玩本关 | 整关重置五项（§3.5，S5 §2.4）→ PLAYING | 沿 core-loop §2.1 面板能力 |
| 音乐开关 | `settings.bgmMuted` 取反 + 即写 S8 | S9 设置直连 |
| 音效开关 | `settings.sfxMuted` 取反 + 即写 S8 | 双通道独立（architecture §2） |
| 减弱动效（D1） | `settings.reduceMotion` 取反 + 即写 S8 | **副按钮样式**，与「去冲刺」共用面板行3（WXG-T-088）；仅写设置不切相位；开关经 snapshot 回显给 view，恢复后即时生效（关停清单见 accessibility §2 D1） |
| 大字号（E2） | `settings.largeText` 取反 + 即写 S8 | **副按钮样式**；仅放大正文/说明类字号（×1.25），数字/标题/按钮不变；弹窗自适应延后 v1.1（accessibility §5.2 用户拍板基础版） |
| 去冲刺（冲刺入口） | 切到冲刺模式（接 `startSprint()`） | **副按钮样式**，不抢「继续」的主按钮位；**冲刺模式下隐藏**（已在冲刺中，入口无意义）；依据 `ux-spec §8` U1（2026-09-12 冻结：冲刺入口三处都放——结算过关页 / 通关画面 / 暂停面板） |
| （冲刺模式）重新冲刺 | 同「重玩本关」 | **P1 已冻结**（2026-09-12 用户拍板） |

- 面板背后**半透明遮罩**盖住棋盘与托盘（防误触 + 防偷看，遮罩参数归 ux-spec §3）。
- 面板**不含**：退出游戏（交微信胶囊/系统返回——有意为之非遗漏）、排行榜/签到等 meta 入口（提案层，见 `proposals/meta-framework.md`，冻结前不进面板）。

### 2.3 冻结语义（复用 ADR-0007 单点裁决）

- 进入 PAUSED：S5 计时冻结（含告急判定与连击窗口的 sprint 扩展）、S4 供料心跳冻结；**表现层不冻结**（脉冲动画帧可续跑，但被遮罩遮挡不产生误导——timer-gameover §2.3 同款口径）。
- 恢复：所有冻结计时从**暂停保存值**续算（S5 §8-5 判据）；不追溯、不补发暂停期间跳过的供料（S4 §6）。
- 同帧裁决：暂停请求与归零/落子同帧 → **门禁先切 PAUSED**，玩法事件作废（input-control §6 同款；**实现口径见 §6 帧内序定义**——本文 §6 与 S5 `timer-gameover.md` §6 曾表述不一致，**已于 WXG-T-031 统一：timer-gameover §6 已对齐本文 §6 帧内序**（输入 → 连击窗 → 供料 → 计时））。

## 6. 边界条件

**极端值**
- PAUSED 中再次点齿轮区：被遮罩拦截，零响应（面板按钮是唯一出口）。
- 告急脉冲激活时暂停：danger 态保留在 HUD，恢复后按剩余时间重新判定是否仍告急（不强制常亮）。
- 重玩本关时扩展已解锁 / 道具已用 / 连击在冲刺模式进行中：全部随五项重置清零（S7 连击态一并归零；P1 已冻结，2026-09-12 用户拍板）。
- 面板打开瞬间 `level:cleared` 同帧：**同帧暂停优先**（判定基准 = 输入段内序「状态指令 → 玩法事件」，与 §2.3、§8-6 同基准）——暂停生效，`level:cleared` **缓存至恢复后处理**；若 `level:cleared` 已在**此前帧**生效（已进 LEVEL_CLEAR），则齿轮请求走门禁忽略（非 PLAYING 入口）。依据：① 齿轮属状态指令、`level:cleared` 属玩法事件，段内序已定前者先；② 与 §2.3「暂停 vs 落子同帧 → 暂停优先」自洽；③ 与 WXG-T-030 实现一致（齿轮路由前置于 phase 路由）；④ 该 outcome 对玩家**零损失**——通关只是延后展示，不丢。
  - **注**：core-loop §6「cleared 优先」判例的适用范围是 `level:cleared` vs `level:failed`，**不含** cleared vs 暂停，本条与其**不构成冲突**（S1 最终裁决归属不变）。

**并发 / 竞态**
- 齿轮点击 vs 归零同帧：**同帧暂停优先**（2026-09-12 裁定，WXG-T-030 实现确认）。**帧内序固定为：输入（段内序：状态指令 → 玩法事件）→ 连击窗 → 供料 → 计时**——由该序推出两条 outcome：（⚠️ WXG-T-061 起，本序的**规范定义归口 `core-loop §2.2.2`**，本条改为对齐引用——两处各自复述正是此前漂移的成因）
  - 归零**已生效**（此前帧已借此切进 GAME_OVER）之后到达的齿轮请求 → GAME_OVER 生效、**无暂停**（非 PLAYING 状态入口走门禁忽略，见「非法输入」第一条）；
  - 与归零**同帧**到达的齿轮请求 → 输入在计时之前处理 ⇒ **暂停生效、本帧不判负**（计时冻结、dt 不累计、归零不触发）。
  - 裁定理由：① 单线程固定步长下"同帧到达序"不可定义（一帧内没有先后事件，只有代码执行序），唯一可实现的确定性解是显式帧内序；② §2.3 是更具体的规则，优先于本节原先的抽象表述；③ "偏向玩家"与 core-loop §6「cleared 优先」的通关 generosity 精神同向。两条路径均无"暂停后又失败"的叠加态。
- 开关切换 vs 结算写档同帧：合并一次整档写（S8 §2.5 幂等）。
- 连续快速 齿轮→继续→齿轮：每帧至多 1 条状态指令（S2 §6 指令洪泛上限），状态机单向流转无抖动。

**非法输入**
- 非 PLAYING 状态收到暂停请求：忽略（BOOT/LEVEL_CLEAR/GAME_OVER/FINISH 无可暂停物）。
- PAUSED 中收到玩法事件（落子/供料/道具）：源系统已被冻结，防御层再拦（零副作用）。
- 重复 `game:paused`（已暂停再暂停）：幂等，不重置 S5 保存值（S5 §6）。

## 7. 依赖

- **上游**：S1（状态机 PAUSED 节点）、S2（齿轮与面板按钮路由）、S8（设置读写）。
- **下游**：S5（计时冻结）、S4（心跳冻结）、S7（连击窗口冻结，提案事件消费）、音频层（bgm/sfx 通道静音）、视觉层（遮罩与面板）。
- **明确边界**：不新增状态（PAUSED 复用 core-loop §2.1 既有节点）；不做退出/账号/meta 入口；双通道音频用框架现成 `setMuted`（architecture §2，无框架改动）。

## 8. 验收标准（可测试硬判据，QA 直接造用例）

1. PLAYING 点齿轮 → `game:paused` 恰 1 次、S1=PAUSED、面板可见、遮罩覆盖棋盘与托盘；PAUSED 中点击遮罩/棋盘/托盘/道具卡全部零响应。
2. PAUSED 300s 后继续 → remaining 与暂停前一致（≤1 帧 dt），首个供料不早于"暂停剩余间隔 +1 帧"（联合 S5§8-5 / S4§8-8）。
3. 「重玩本关」→ 五项重置逐一断言（倒计时回满/图案清空/托盘清空/扩展重置/道具次数回初值），S1 直接回 PLAYING 无 GAME_OVER 中转。
4. 音乐/音效开关各切 2 次：`settings.*` 即档、重启回显一致、BGM 与 SFX 互不影响（关音乐仍有音效，反之亦然）。
5. 齿轮热区 ≥88×88 且不侵入 `CAPSULE_AVOID`；面板任何元素不与胶囊重叠（布局断言）。
6. 归零 vs 齿轮两组用例（判定基准 = **帧内序：输入（段内序：状态指令 → 玩法事件）→ 连击窗 → 供料 → 计时**，齿轮属输入、先于计时处理）：**同帧**（归零与齿轮同帧到达）→ 暂停生效、本帧 dt 不再累计、恢复前不判负；**跨帧**（此前帧已借归零切进 GAME_OVER）→ GAME_OVER 生效、无暂停。注：「事件到达序」在单线程固定步长循环内不可观测，判据基准以帧内序为准——本条结论与改前一一对应，**仅换判定基准、非改判据**。
7. 非 PLAYING 五状态（BOOT/LEVEL_CLEAR/GAME_OVER/FINISH/PAUSED）注入齿轮请求 → 零事件零状态变化。
8. 重复暂停幂等：PAUSED 中注入 `game:paused` → S5 保存值不变（恢复后 remaining 正确）。
9. sprint 模式暂停：连击窗口计时冻结（恢复后从暂停值续算，不追溯断连）。
10. 面板**入** ≤ 200ms / **出** ≤ 150ms 量级（动效参数以 ux-spec §5 为准做帧检，红线 ≤3Hz 闪烁）。

> 第 3 条可测性注记（2026-09-12，WXG-T-030）：五项重置中的**第五项「道具免费次数回初值（`POWERUP_FREE_USES`）」依赖 S6 道具系统**——S6 落地前仓库无道具状态，该项**不可测**，用例应注记为"待 S6"的真空项，**不得发明伪状态充数**；S6 落地后自动转为可断言。前四项不受此限。
