# GDD · S4 供料与槽位托盘（Tray Spawner）· beads

- 项目：`games/beads` · 版本 v1.1 · 任务号 WXG-T-009（§2.4 出口表完整性缺口登记：WXG-T-081）
- 数值纪律：只引用 `systems-index §3` 常量名（本篇主要 §3.4，颜色加权 §3.2）。
- 依赖锚点：`core-loop.md` §2.2 第 1/2 步（供料心跳与选珠）。

---

## 1. 目标

按节律向有限槽位持续供料，制造"空间压力"；管理 12+12 槽的占用、选中与扩展，并 向 S3/S7 提供珠子持有与颜色的唯一事实。

## 2. 机制

### 2.1 托盘模型

- 槽位数组，容量 = `TRAY_BASE_SLOTS`（1 行实线）；扩展后 +`TRAY_EXPAND_SLOTS`（1 行虚线）。
- 每槽 ∈ `free | holding(colorIdx) | selected`；`selected` 至多 1 槽（换选即转移，不叠选）。
- 绘制参数：`tray_panel/tray_slot/tray_slot_dashed/btn_expand` 见 `art/assets-spec.md` §1.3；`selected` 态视觉见 §1.2。

### 2.2 供料节律（PLAYING 驱动）

1. S5/S1 心跳累计 dt ≥ 当前 `SPAWN_INTERVAL`（默认 `SPAWN_INTERVAL_DEFAULT`，关卡可覆盖，区间 [2.0, 6.0]）→ 触发 1 次供料。
2. 抽色：按 §3.2 加权——从"仍需颜色集合"（S3 可填格中未填的颜色，经事件同步）以 `NEEDED_WEIGHT` 抽取；杂色以 `DECOY_WEIGHT` 抽取（杂色数 ≤ `DECOY_COLORS_MAX`，由关卡数据声明）。
3. 落槽：**随机空闲槽**放入 1 颗，广播 `tray:spawned {slot, colorIdx}`。
4. 无空闲槽 → **跳过本次供料**（不排队、不补发）并广播 `tray:full`（A2 已确认）。

### 2.3 扩展行

- 入口 `btn_expand`（激励视频位，MVP 仅角标占位；拉起逻辑 `[待用户确认]`，`AD_PLACEMENTS` 见 §3.6）。
- 解锁后本关内永久生效；**重开/换关重置为未扩展**（A1 已确认不跨关保留）。
- 解锁成功广播 `tray:expanded`；扩容瞬间已持有的珠不动，仅新增空槽。

### 2.4 珠子离槽（三个现有出口 + 拟新增行）

| 出口 | 触发 | 槽位去向 |
|---|---|---|
| 落子成功 | S3 `bead:placed` 回执含 slot | 置 `free`，若为 selected 同时清除选中 |
| 道具清除 | S6 `powerup:used {affectedSlots}` | 置 `free` |
| 整关重置 | S1（失败重试/重玩/换关） | 全清 + 扩展重置 |
| **[拟新增·待用户拍板]** 主动丢弃（泄压阀方案 B） | 玩家丢弃手势——S2 路由 `[待定]`（现 `input-control` §2.1「单指点击、无拖拽/长按」需破例，或新增一个按钮位） | 置 `free`；无惩罚（同 A4 气质）；**事件名 `tray:discarded {slot, colorIdx}`**（S4 → S6 只读镜像 / S7 统计 / 视觉层）；若设冷却或次数上限，**必须先在 `systems-index` §3 冻结 `DISCARD_*` 常量**，本文不私定 |
| **[拟新增·待用户拍板]** 满槽自动清除（泄压阀方案 C） | S4 供料 tick 检出 `freeCount === 0` | 置 `free`（仅目标槽）；**不得复用 `powerup:used`**——那会污染 S6 语义（§2.5 免费次数扣减、S7 结算 `powerupsUsed` 会被非玩家行为计入，连带扣 `SETTLE_SCORE`）；若选 C 须新造 **`tray:relieved {affectedSlots}`**（S4 → S6 镜像 / 视觉层 / 音频层），并额外依赖 GAP-04 VFX + GAP-05 音效才能让玩家看懂「珠为何消失」 |

**出口表完整性缺口（GAP-06，WXG-T-081 登记）**

1. 上述前三个出口是**现状描述，不是完整性声明**——它们**不足以**保证「玩家不会卡死」（`ux-spec` §4 尾注的绝对承诺已同步改写为条件式）。
2. **两类不可落子珠（死珠）**：
   - **杂色珠**：与图案色强制 disjoint（`levels-spec` §2 硬约束 + `src/config/levels.ts` 校验强制）⇒ 永不能走「落子成功」出口；
   - **过度供给珠**（本次新查到的第二根因，L7/L8 零杂色也中招）：§2.2 第 2 步的抽色只按「网格仍需数」加权（实现：`Spawner._drawColor` 读 `tray.neededCount(c)`），**不扣「托盘已持有同色数」**⇒ 某色 `needed` 归零后仍可能持有该色珠，这些珠同样永不落子。
3. **棘轮效应**：两类死珠在托盘内**不可逆累积**（无丢弃出口；道具仅 3 次免费且 `powerups` §2.6 自认无第 2 次效果与扩展解锁路径）⇒ 触顶 `TRAY_BASE_SLOTS` 后 `_feedOnce` 永久跳过供料（`tray:full` 去重后连告警也不再发）⇒ **死局凝固**，实战只剩「整关重置」一条路。失败页续时（§3.11）只加时间、不清托盘，**不能解此局**。
4. **四方案与本表的关系**：A（供料侧不抽死珠）/ A′（严格化：维持 `held ≤ demand` 不变量）/ D（`DECOY_COLORS_MAX`=0）**治供料侧，本表三行不变**（不新增出口）；B / C 需按上表两行补入。推荐与影响面见 `ux-spec` §8 U8（**待用户拍板**）。
5. **未拍板前的纪律**：不得改 `systems-index` §3 常量；上表两个拟新增行**仅作为拍板时的对照草案**，不得当作已生效设计（不得据此落码、不得写进 QA 判据、不得进 S2 路由表）；不得把「整关重置」当作兜底机制写进任何验收口径。
6. **关联待补记**（本单 Output Path 限定只改 §2.4，下列补记经主理人转后续单落笔；权威条文暂见 `ux-spec` §6.2）：§2.2 需补「**首供**：进入 PLAYING 第 1 帧的供料段立即执行 1 次（`reset()` → `interval` → `_acc = interval`，顺序不可颠倒）」与「抽色入池条件 = `needed − held > 0`；demand 全 0 → 跳过本次供料且**不广播 `tray:full`**（与满槽跳过语义区分）」两条规则。受影响的 §8 判据（交 QA 同步）：§8.1 由 15 颗改 **16 颗**（1 首供 + 15 周期；旧 ±1 容差会恰好吞掉此变更 = 假绿）、§8.3（3:1 抽色）在 A′/D 下**作废或重写**、§8.9（0 杂色关卡）在 D 下变为全关卡平凡真、§8.4（满槽跳过）在 A′ 下仍成立但需补「满槽后必可恢复」断言。

## 6. 边界条件

**极端值**
- 关卡"仍需颜色集合"为空（只剩杂色可抽）：仍按 3:1 权重退化——所需色抽不到时全部抽杂色；理论上此局面意味可填格已满（cleared 已触发），仅作防御。
- 供料间隔被关卡压到区间下限且托盘长期满：连续跳过供料，`tray:full` 允许去重（满槽期间不重复广播，恢复空闲后再次触发才重播）。
- 扩展解锁瞬间正处满槽：解锁后下一 tick 恢复供料，**不补发**满槽期间跳过的次数。

**并发 / 竞态**
- 供料与换选**同帧**：选珠属**输入段**、供料属**供料段** ⇒ 按 `core-loop §2.2.2` 帧内序，先结算选中转移、再落新珠（新珠落 selected 槽则落其他空闲槽——随机槽避让选中槽）。结论与旧表述一致，基准改为帧内序（WXG-T-061 归口）。
- 供料与道具清除**同帧**：两者分属**输入段**（道具）与**供料段** ⇒ 按帧内序**输入段恒先**：道具先结算，其清出的槽**可作本帧供料目标**。（原表述「事件按到达序串行；清除先到则…供料先到则…」的「到达序」基准**作废**——单线程固定步长下不可观测；「供料先到」那半句在本序下**不可能发生**。）
- 落子回执与换选争**同一槽**：两者同属**输入段**，而每帧最多 1 条输入指令（`input-control §2.4`）⇒ **不可能同帧发生**（原「以先到为准」基准作废）。跨帧时后到者按槽位最新状态重新解释（free 则选中失效，holding 则重选）。
- PAUSED 帧内 dt 累计：暂停期间 dt 不累计（冻结语义对齐 S5），恢复后从原累计值继续。

**非法输入**
- 选中不存在的槽 / 双击同槽：幂等——保持该槽选中，不重复广播 `tray:selected`（core-loop §6）。
- 对 `free` 槽发起"落子到网格"：S2 层拦截（无选中珠），不达 S4。

## 8. 验收标准（可测试硬判据，QA 直接造用例）

1. `SPAWN_INTERVAL` 未覆盖时，PLAYING 60 秒内 `tray:spawned` 恰 **16 次（±0）** = 首供 1（进入 PLAYING 第 1 帧，GAP-02/WXG-T-086）+ 周期 15（每次间隔 4.0s ±0.1s）；旧 ±1 容差会恰好吞掉首供带来的 +1 变更（BD-25 假绿，WXG-T-091 收紧为 ±0）。
2. 每次供料的落槽为 uniformly 随机空闲槽（统计 200 次供料，任一槽被选中频次做**卡方拟合优度检验**，α=0.05 下不拒绝均匀分布；判例同 `powerups §8-4` WXG-T-062）——旧 ±20% 容差在 n=200/12 槽下约半数概率误报（BD-22，WXG-T-091 弃用）。
3. 抽色权重：构造"仍需 1 色 + 1 杂色"关卡，100 次供料中所需色占比 ≈ 75%（3:1，允许 ±10 个百分点）。
4. 托盘满时供料被跳过：`tray:full` 广播 1 次且满槽期间不重复；腾出 1 槽后 ≤1 个间隔内恢复供料。
5. 扩展后槽位数 = `TRAY_BASE_SLOTS` + `TRAY_EXPAND_SLOTS`；失败重试后回到基线容量且扩展需重新解锁。
6. 换选：同帧两次点击不同槽，最终仅 1 槽处于 `selected`；双击同槽只广播 1 次 `tray:selected`。
7. 落子成功回执后对应槽变 `free`；用 `bead:placed` 计数与 `free` 槽增量做 1:1 断言。
8. PAUSED 期间零 `tray:spawned`；恢复后首个供料不早于"暂停剩余间隔 + 1 帧"。
9. 关卡仅声明 0 杂色时，供料 100% 为仍需颜色（无 `DECOY_WEIGHT` 参与的统计断言）。
10. 道具清除 6 槽（含选中槽）后：选中态清除、6 槽全 `free`、`powerup:used` payload 的 affectedSlots 与实际清空槽一致。
