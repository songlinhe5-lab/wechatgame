# GDD · S3 挡板与球物理（Paddle & Ball Physics）

> 版本 v1.0 · 依赖：无（被 S1 编排）· 被依赖：S2, S4, S5, S6

---

## 1. 目标
实现"跟手、可预测、有技巧上限"的弹球手感：挡板平滑跟随，球以**落点决定出射角**的规则反弹，从根本上避免"贴地横飞"与"垂直死循环"两种破坏手感的经典 bug。

## 2. 机制

### 2.1 挡板跟随（指数平滑）
挡板不瞬移到目标，而是以时间常数趋近：

```
paddle.x += (targetX − paddle.x) * (1 − exp(−dt / PADDLE_FOLLOW_TAU))
```
- `PADDLE_FOLLOW_TAU = 0.06s`：手感"跟手但有一点重量"。
- 该写法与帧率无关（dt 变化时结果一致），优于 `lerp(a,b,0.2)`。

### 2.2 球运动
- 球以**恒定速率**沿方向向量 `(dx, dy)`（单位向量）运动：`pos += dir * speed * dt`。
- 速度不会因反弹衰减（保持可预测）；球速只在**关卡切换**与**道具（减速）**时改变。
- 采用**子步进**（见 S1 §5）防穿模。

### 2.3 反弹规则

**墙（左右/顶）**：镜面反射，先修正位置再翻转分量。
```
左墙  : if x − r < WALL_LEFT_X  → x = WALL_LEFT_X + r;  dir.x = |dir.x|
右墙  : if x + r > WALL_RIGHT_X → x = WALL_RIGHT_X − r; dir.x = −|dir.x|
顶墙  : if y + r > CEILING_Y    → y = CEILING_Y − r;    dir.y = −|dir.y|
```

**挡板（核心技巧点）**：出射角由**球心相对挡板中心的偏移**决定，而非镜面反射。
```
t = clamp((ball.x − paddle.x) / (PADDLE_W / 2), −1, 1)   // 归一化落点，−1 最左 / +1 最右
θ = t * BALL_MAX_BOUNCE_ANGLE                            // θ 为相对竖直向上的夹角，单位：度
dir = ( sin(θ), cos(θ) )                                 // 保证向上
// 防"贴地横飞"：若 |dir.y| < BALL_MIN_VERTICAL_RATIO，则按比例回正
if |dir.y| < 0.25: 重新归一化使 dir.y = 0.25 方向
```
- `BALL_MAX_BOUNCE_ANGLE = 60°`：打到挡板边缘 → 大角度斜射（制造角度控制）；打到中心 → 接近垂直。
- 撞挡板后球 y 立即置于 `PADDLE_Y + PADDLE_H/2 + r`，避免同帧二次触发。

**砖块**：由 S4 处理（圆-矩形检测 + 轴向最小穿透反弹）。

### 2.4 反弹后防退化（Anti-Degenerate）
| 问题 | 触发条件 | 处理 |
|---|---|---|
| 近水平死循环 | `|dir.y| < 0.25` | 归一回正到 `dir.y = 0.25` |
| 近垂直卡砖缝 | `|dir.x| < 0.1` 且持续 > 3s | 微调 `dir.x` 至 0.1（保底水平分量） |
| 数值漂移 | 每帧结束后 | `dir` 重新归一化为单位向量 |

## 3. 输入
- `paddle.setTargetX(x)`（来自 S2）。
- `setBallSpeed(v)`（来自关卡加载 / S7 减速道具）。
- `launchBall(angleDeg)`（来自 S2 发球）。

## 4. 输出与反馈
- 挡板撞球：挡板 40ms 纵向挤压（squash 0.9）+ 球体 60ms 闪光。
- 撞墙：墙体内壁 80ms 高亮。
- 输出事件：`ball:hitPaddle`、`ball:lost`（y < DEATH_Y）。
- 球贴图旋转 = `atan2(dir.y, dir.x)`，让球有滚动感。

## 5. 数值
| 参数 | 值 | 来源 |
|---|---|---|
| `PADDLE_W` | 140 px | 全局 |
| `PADDLE_H` | 24 px | 全局 |
| `PADDLE_FOLLOW_TAU` | 0.06 s | 全局 |
| `BALL_R` | 12 px | 全局 |
| `BALL_SPEED_BASE` | 480 px/s | 关卡可覆盖 |
| `BALL_SPEED_MAX` | 720 px/s | 全局硬上限 |
| `BALL_MAX_BOUNCE_ANGLE` | 60° | 全局 |
| `BALL_MIN_VERTICAL_RATIO` | 0.25 | 全局 |
| `BALL_MIN_HORIZONTAL_RATIO` | 0.10 | 全局 |
| 发球角抖动 | ±10° | S2 |

**球速成长**：`speed = min(BALL_SPEED_MAX, level.ballSpeed)`；同关内不自动加速（保持可预测），仅道具可临时改变。

## 6. 边界条件
1. **球心与挡板同帧多次碰撞**：用"上一次位置在挡板上方 / 本次在下方"的方向判据，一帧只反弹一次。
2. **球恰好打在挡板顶点**：`t` 取 ±1 → θ=±60°，永不出现"垂直弹回"。
3. **挡板瞬移到球上方**（快速拖动）：挡板仍是矩形，碰撞用连续检测（上一帧挡板矩形与当前帧之间做 sweep），避免"漏接"。
4. **球与左右墙 + 挡板同帧**：按 S1 固定顺序（墙→挡板→砖）逐一结算。
5. **多球同时失球**：每颗球独立判 `DEATH_Y`，逐个派发 `ball:lost`；S6 决定是否扣命（见 S6 边界）。
6. **速度趋近 0**（被道具叠乘）：设下限 `BALL_SPEED_MIN = 240 px/s`，防止卡死。

## 7. 依赖
- **上游**：关卡数据（`BALL_SPEED_BASE` 覆盖值）。
- **下游**：S2（驱动）、S4（提供球圆信息）、S5（撞板事件重置连击）、S6（失球）。
- **框架假设**：向量/数学工具（Vec2）、`update(dt)`。

## 8. 验收标准
- [ ] 挡板跟手，快速来回拖动无抖动、无过冲。
- [ ] 球打挡板左右边缘能以最大 ~60° 斜射，打中心近似垂直。
- [ ] 出现"贴地横飞"（`|dir.y|<0.25`）时能在 1 帧内被自动纠正。
- [ ] 球速 720px/s 且 dt=0.05s 时，球不穿透墙、挡板、砖块。
- [ ] 球速被道具连续叠乘后不低于 240px/s。
- [ ] 方向向量全程保持单位长度（无加速/减速漂移）。
