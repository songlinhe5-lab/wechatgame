# GDD · S7 道具系统（Power-ups）

> 版本 v1.0 · 依赖：S4（砖块破碎事件）· 被依赖：S3 / S5 / S6

---

## 1. 目标
用**低频、高辨识、即时生效**的道具打破节奏、制造惊喜与决策点。道具必须"一眼看懂、捡了就有效"，不允许需要阅读说明。

## 2. 机制

### 2.1 掉落
```
brick:destroyed
  → roll = random()
  → if roll < level.powerupDropRate: 掉落一个道具
       type = 按 weightedTable 随机
       道具从砖块位置以 POWERUP_FALL_SPEED 下落
```
- 同一时刻**场上道具上限 = 3**（超出则不再掉落，防视觉混乱与失控）。

### 2.2 道具表
| ID | 名称 | 效果 | 持续时间 | 权重 | 层级 |
|---|---|---|---|---|---|
| `expand` | 加宽挡板 | `PADDLE_W × 1.4`（140→196） | 15 s | 30 | MVP |
| `multi` | 三球 | 每颗在场球分裂为 3 颗（方向 ±25°） | 即时 | 25 | MVP |
| `life` | 加命 | `lives +1`（上限 5，超上限转 +500 分） | 即时 | 8 | MVP |
| `slow` | 减速球 | 球速 ×0.75（下限 240 px/s） | 10 s | 20 | 应有 |
| `sticky` | 磁吸挡板 | 球撞挡板后吸附，点击后释放 | 12 s | 10 | 应有 |
| `laser` | 激光挡板 | 挡板可发射激光击碎砖块，冷却 0.5s | 10 s | 7 | 可选 |

> **MVP 实装集合 `IMPLEMENTED_POWERUPS = ['expand','multi','life']`**（权威常量，见 `systems-index §3.6`）。
> **掉落候选规则**：实际抽取 = `level.powerupPool ∩ IMPLEMENTED_POWERUPS`。关卡白名单里**未实装的 ID 一律静默忽略、不报错**，权重在**剩余候选中重新归一化**。
> 因此 L3/L4 的 `powerupPool` 虽含 `slow`、L5 含 `sticky`，**MVP 阶段它们不会掉落**（数据保留以支持后续实装，无需改 JSON）。其余类型同理。

### 2.3 拾取
- 拾取判定：道具矩形与挡板矩形 **AABB 相交**即拾取（比较面积判定即可，不必精确）。
- 未接住：道具下落至 `y < POWERUP_MISS_Y(100)` 消失，无惩罚。

### 2.4 叠加与计时
- **同时长类道具（expand / slow / sticky / laser）**：同类重复拾取**刷新计时**（不叠加数值），避免挡板无限变宽。
- **瞬时类（multi / life）**：立即结算。
- 计时器为**可暂停计时器**（READY / PAUSED 时冻结）。

## 3. 输入
- `brick:destroyed`（S4）→ 掉落判定。
- 拾取碰撞（本系统内部）。
- 磁吸状态下的点击（S2）→ 释放球。

## 4. 输出与反馈
| 时机 | 表现 |
|---|---|
| 道具出现 | 落地飘浮图标（64×64），带上下浮动 0.6s 周期 + 柔光 |
| 拾取 | 图标放大淡出 200ms + 屏幕对应区域泛光 + 浮动文字标签（如"挡板加宽!"）800ms |
| 到期前 3s | 图标/效果提示闪烁（避免"效果突然消失"的困惑） |
| 三球触发 | 球体分裂粒子 + 三球各自拖尾 |
| 加命 | HUD 生命点 +1 弹出动画 |
| 超上限加命 | 显示"+500"金色飘字 |

## 5. 数值
| 参数 | 值 |
|---|---|
| `POWERUP_DROP_BASE` | 0.12（关卡可覆盖） |
| 金砖掉落倍率 | ×3 |
| 场上道具上限 | 3 |
| `POWERUP_FALL_SPEED` | 260 px/s |
| `POWERUP_MISS_Y` | 100 |
| expand 倍率 / 时长 | ×1.4 / 15 s |
| slow 倍率 / 时长 | ×0.75 / 10 s（下限 240 px/s） |
| sticky 时长 | 12 s |
| laser 冷却 / 时长 | 0.5 s / 10 s |
| multi 分裂角 | ±25° |
| 三球并发上限 | 9 颗（多球叠加保护） |

## 6. 边界条件
1. **多球上限**：场上球数达 9 时，`multi` 不再分裂（防止性能与视觉雪崩）。
2. **挡板加宽到接近墙**：`PADDLE_W×1.4=196` 时左右 clamp 仍取 `PADDLE_W/2`，不会穿墙。
3. **道具落点为屏幕外/砖块层**：道具只在 `y ∈ [POWERUP_MISS_Y, CEILING_Y]` 有效，越界即销毁。
4. **拾取同帧多道具**：逐个结算，`life` 先于 `expand`（顺序无强约束，但需确定后写死并测试）。
5. **暂停时道具下落**：冻结（与 S1 一致），不出现"暂停后道具还掉下去"。
6. **减速与球速下限**：多次 slow 只刷新，不叠乘；与关卡基础球速共同受 `BALL_SPEED_MIN(240)` 约束。
7. **磁吸 + 三球**：磁吸状态下每颗球各自吸附/释放，互不干扰。
8. **道具图标与砖块重叠**：道具渲染层级高于砖块，低于 HUD。

## 7. 依赖
- **上游**：S4（掉落触发）。
- **下游**：S3（改变球/挡板参数）、S5（超上限加命转分）、S6（加命）、S2（磁吸点击）。

## 8. 验收标准
- [ ] 道具只在破碎砖块处按概率掉落，掉落率可被关卡覆盖。
- [ ] 三种 MVP 道具效果正确且可验证（挡板变 196、球变 3 颗、生命 +1）。
- [ ] 场上道具数不超过 3，球数不超过 9。
- [ ] 加命超上限正确转 +500 分。
- [ ] 暂停时道具与计时器全部冻结。
- [ ] 同类道具重复拾取只刷新计时、不叠加数值。
