# GDD · S9 暂停与设置（Pause & Settings）

> 版本 v1.0 · 依赖：S1（状态机）、S8（设置持久化）· 被依赖：无

---

## 1. 目标
提供随时可用的暂停与最小设置集合，保证"随时能走"。暂停必须**彻底冻结**游戏逻辑（含道具计时、慢放、飘字），不出现"暂停后世界还在动"。

## 2. 机制

### 2.1 暂停
- 触发：HUD 右上角暂停按钮（点击）。
- 进入 PAUSED：冻结 `update(dt)` 中所有**游戏逻辑**（球、挡板、道具、计时器）。
- 表现层：弹出半透明遮罩（阻挡输入）+ 暂停面板（继续 / 重玩本关 / 重玩第 1 关 / 设置）。
- 恢复：点击"继续" → 回到进入暂停前的子状态（PLAYING 或 READY）。**注意**：不重置 READY 的自动发球计时（原样恢复）。
- **无「返回菜单」**：主菜单已移除（用户裁定，见 `ux/ux-spec.md` §2）；退出小游戏由微信胶囊 / 系统返回承担。

### 2.2 自动暂停
- 微信 `onHide`（切后台、来电、息屏）→ 自动进入 PAUSED。
- `onShow` → 停留在 PAUSED，需玩家手动继续（防丢命）。

### 2.3 设置项（最小集）
| 设置 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 音效 | 开关 | 开 | 碰撞/道具音效 |
| 音乐 | 开关 | 开 | 背景音乐 |
| 震动 | 开关 | 开 | 碰撞震动反馈（走 `wx.vibrateShort`） |
| 拖拽模式 | 单选 | 绝对跟随 | 绝对跟随 / 相对拖动（可访问性） |

- 设置变更**立即生效**并写入存档（S8）。
- **入口**：设置面板的**唯一入口是暂停面板**（主菜单已移除，见 `ux/ux-spec.md` §2 / §6）。返回后仍在 PAUSED，不误触恢复游戏。
- **重玩本关 / 重玩第 1 关**：两个独立按钮。「重玩本关」= 重置本关；「重玩第 1 关」= 丢弃本局、从第 1 关重来（承担"想从头玩"的路径，取代原主菜单的"新游戏"）。

## 3. 输入
- 暂停按钮点击 → PAUSED。
- 面板按钮点击 → 继续 / 重玩本关 / 重玩第 1 关 / 设置。
- 设置开关切换。
- 生命周期事件 `onHide` / `onShow`。

## 4. 输出与反馈
| 时机 | 表现 |
|---|---|
| 进入暂停 | 遮罩淡入 150ms + 面板缩放弹入 200ms（0.9→1.0，ease-out） |
| 继续 | 面板缩放淡出 150ms + 3-2-1 倒计时？ **否**，直接恢复（低摩擦） |
| 开关切换 | 开关滑块 120ms 滑动 + 音效试听（音效开关打开时播放一声） |
| onHide 自动暂停 | 与手动暂停一致，无特殊提示 |

## 5. 数值
| 参数 | 值 |
|---|---|
| 遮罩淡入 | 150 ms |
| 面板弹入 | 200 ms，scale 0.9→1.0，ease-out |
| 面板淡出 | 150 ms |
| 遮罩不透明度 | 0.65 |
| 暂停按钮热区 | ≥ 88×88 px（微信触控推荐最小 88px） |
| 震动时长 | `vibrateShort`（系统默认） |

## 6. 边界条件
1. **暂停中再次暂停**：忽略（暂停按钮在 PAUSED 状态禁用/被遮罩覆盖）。
2. **READY 状态暂停**：允许；恢复后自动发球计时从剩余时间继续。
3. **终局慢放中暂停**：慢放冻结，恢复后继续走完。
4. **从暂停点「重玩第 1 关」**：本局进度丢弃（分数清零、回到第 1 关），但**已解锁关卡与最高分保留**；**不二次确认**（低摩擦）。若本局分数 > 0，可在 v2 加轻确认——MVP 从简。**注**：不存在「返回菜单」，故无"回菜单丢进度"路径。
5. **设置面板从暂停进入/退出**：返回后仍在 PAUSED，不误触恢复游戏。
6. **onShow 后立即 onHide**：连续生命周期事件不产生多次暂停面板叠层（幂等）。
7. **音效开关关闭**：所有 SFX 静音，但**不**静音系统级震动/音乐（音乐由独立开关控制）。

## 7. 依赖
- **上游**：S1（状态机）、S8（设置读写）。
- **下游**：无。
- **框架假设**：生命周期钩子、`Storage`、`Audio`、`wx.vibrateShort` 封装。

## 8. 验收标准
- [ ] 暂停后球、挡板、道具、计时器、飘字全部静止。
- [ ] 切后台自动暂停，切回不自动继续。
- [ ] 恢复后游戏状态与暂停前完全一致（含 READY 剩余计时）。
- [ ] 四个设置项均可切换、立即生效、重启后保持。
- [ ] 暂停面板含「继续 / 重玩本关 / 重玩第 1 关 / 设置」四项，**无「返回菜单」**。
- [ ] 「重玩第 1 关」能从任意关卡回到第 1 关，且最高分与解锁进度不被清除。
- [ ] 暂停按钮热区 ≥ 88×88 px。
- [ ] 连续 onShow/onHide 不产生叠层面板。
