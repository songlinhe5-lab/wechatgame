# UX 规格（UX Spec）

- 项目：`breakout` · 版本 v1.0 · 作者：文策渊
- 平台：微信小游戏（竖屏，单手，触摸）· 设计分辨率 750×1334，`FIXED_WIDTH`
- 关联：`design/gdd/systems-index.md`（常量）、`design/gdd/*`（系统行为）

---

## 1. 设计原则（UX）

1. **首屏即玩**：`点击 → 开始 → 发球` 不超过 2 次交互，全程无需登录/授权。
2. **拇指可达**：核心交互（拖拽挡板）位于屏幕下 1/3，控制区低、信息区高。
3. **反馈即语言**：用动效与音效替代文字说明，0 文字教学。
4. **随时可走**：任意状态都能 1 次操作暂停；进度自动保存，**下次启动直接续进**上次关卡（无菜单、无点击）。

## 2. 界面流程（Screen Flow）

> **主菜单已移除**（用户裁定）：启动即进入游戏，全流程**只有 2 条路径**（直接进入 / 通关画面），不再有菜单层，也不再维护 Menu 状态。

```
[BOOT 加载]（读存档 → 决定入口，目标 ≤1.5s）
   ├─ stats.runs == 0（首次）  ──► [PLAYING · 第 1 关 READY]
   ├─ 有未完成进度             ──► [PLAYING · 续进「上次未通关的那一关」READY]
   └─ 5 关全部通关             ──► [FINISH 通关画面]（总得分 + 重新挑战）

[PLAYING（含 READY 子状态）]
   ├─「暂停」──► [暂停面板 PAUSED]
   │                 ├ 继续        → 回到 PLAYING / READY（原样恢复）
   │                 ├ 重玩本关     → PLAYING(本关 READY)
   │                 ├ 重玩第 1 关  → PLAYING(第 1 关 READY)
   │                 └ 设置 ⚙      → [设置面板]（返回后仍在 PAUSED）
   ├─ 清关 ──► [过关 LEVEL_CLEAR] ──► 下一关（1.2s 自动）；末关后 → [FINISH 通关画面]
   └─ 命尽 ──► [GAME_OVER 结算] ──►「重新挑战」→ PLAYING(第 1 关 READY)

[FINISH 通关画面] ──「重新挑战」──► PLAYING(第 1 关 READY)
```

> **设置入口仅一条通道**：**暂停面板**（任意游戏时刻可达）。主菜单已移除，**不再有第二入口**。
> **退出小游戏**由微信胶囊按钮 / 系统返回承担；游戏内**不设「返回菜单」**。
> **「想从第 1 关重玩」**的路径由暂停面板的「重玩第 1 关」承担（与「重玩本关」并列）。
> **BOOT 降级规则**：存档越界/非法、或版本高于当前支持版本/无法识别时，BOOT **安全降级为"首次"（进 L1）**，**降级优先于报错**，绝不中断启动 —— 细则见 `gdd/save-progress.md` §6.3 / §6.8 / §6.9 与 §8 验收。

## 4. 状态流转与输入响应矩阵

| 当前状态 | 可用输入 | 响应 | 下一状态 |
|---|---|---|---|
| BOOT | 无（自动读存档） | 首次→第1关；有进度→续进未通关关；全通关→FINISH | PLAYING(READY) 或 FINISH |
| READY | 触摸下方区域 | 发球 | PLAYING |
| READY | 触摸并拖动 | 移动挡板 + 发球 | PLAYING |
| READY | 1.5s 无操作 | 自动发球 | PLAYING |
| PLAYING | 拖拽 | 移动挡板 | PLAYING |
| PLAYING | 点暂停 / onHide | 冻结 | PAUSED |
| PAUSED | 继续 | 恢复 | PLAYING/READY |
| PAUSED | 重玩本关 | 重置本关 | PLAYING(本关 READY) |
| PAUSED | 重玩第 1 关 | 丢弃本局、回第 1 关 | PLAYING(第1关 READY) |
| PAUSED | 设置 ⚙ | 打开设置面板 | PAUSED(设置层) |
| LEVEL_CLEAR | 点击下一关 / 1.2s | 加载下一关 | PLAYING |
| LEVEL_CLEAR | 末关清关 | 结算 | FINISH |
| GAME_OVER | 重新挑战 | 重置本局 | PLAYING(第1关) |
| FINISH | 重新挑战 | 重置本局 | PLAYING(第1关) |

> **已移除的行**：`MENU` 状态的全部输入（点击开始/继续、点击设置）。**无任何状态返回 MENU**。

## 5. 交互反馈与动效时长建议

> 统一缓动：进入用 `ease-out`，退出用 `ease-in`。时长精确到毫秒，供美术/程序直接落值。

| 事件 | 视觉 | 音效 | 时长 |
|---|---|---|---|
| 按钮按下 | 缩放 0.95 | 轻"嗒" | 80 ms |
| 按钮释放 | 回弹 1.0 | — | 120 ms |
| 通关画面标题 | 霓虹呼吸（光晕强弱循环） | — | 2000 ms 循环 |
| 发球 | 球拖尾 80ms | "咻" | 80 ms |
| 球撞挡板 | 挡板纵向挤压 0.9 | 短促"咚" | 40 ms |
| 球撞砖（未破） | 白闪 + 缩放 1.06 | "咔" | 80 ms |
| 砖块破碎 | 粒子 8~12 + 缩放淡出 | "啪/叮" | 160 ms |
| 钢砖被撞 | 火花粒子 | 金属"铛" | 120 ms |
| 炸弹爆炸 | 冲击波圆环 + 屏震 | 低沉"轰" | 400 ms |
| 分数飘字 | 上浮渐隐 | — | 600 ms |
| 倍率提升 | 连击数字脉冲 1.3× | 音阶上扬 | 120 ms |
| 拾取道具 | 图标放大淡出 + 泛光 + 文字 | "叮咚" | 800 ms |
| 加命 | 生命点弹出 | 上行两音 | 300 ms |
| 失球 | 底部红线闪 + 碎裂 | 下坠音 | 300 ms |
| 终局慢放 | 0.3× 时间缩放 | — | 400 ms |
| 过关 | 彩带粒子 + 面板弹入 | 胜利音 | 800 ms / 面板 200ms |
| 面板入/出 | scale 0.9→1.0 / 淡出 | — | 200 / 150 ms |
| 暂停遮罩 | 淡入 0.65 | "咔" | 150 ms |

**动效红线**：
- 任何反馈时长 **≤ 400ms**（除过关/结算），不阻塞下一次操作。
- 关键反馈（倍率、加命）**必须同时有视觉 + 音效**，避免静音玩家失去反馈。
- 屏震（炸弹）时长 ≤ 120ms，幅度 ≤ 6px，且可在设置关闭（可访问性）。

## 6. 首屏与新手引导策略（微信首 10 秒留存）

> 微信小游戏首 10 秒决定留存。本作策略：**"零阻力进入 + 边玩边教"**。

### 6.1 首 10 秒时间轴
```
t=0.0s  点击游戏图标 → 加载（预加载目标 ≤1.5s）
t=1.5s  直接进入第 1 关 READY（**无菜单，零点击进入**）
        → 底部浮出半透明提示："拖动屏幕移动挡板"（无按钮，纯提示）
t=2.0s  提示开始上下脉动引导
t=1.5s+ 若玩家 1.5s 未操作 → 自动发球（永不卡在 READY）
t=3~4s  球开始撞砖 → 立即出现分数飘字、粒子、音效（第一次"爽"）
t≈5s    首次破砖若触发道具 → 展示道具（教学即奖励）
t≈10s   玩家已理解"拖挡板→撞砖→得分"，无需任何文字说明
```

### 6.2 新手引导原则
1. **无菜单**：主菜单已移除，启动直接进入游戏（首次→第 1 关；有进度→续进未通关关）。**0 次点击进入**。
2. **单条提示、自动消失**：只在第 1 关显示一条"拖动屏幕移动挡板"，玩家首次拖动后 1.5s 淡出，**永不重复**。
3. **无强制关卡**：不做"必须点击才能继续"的引导遮罩。
4. **失败无惩罚**：第 1 关球速最慢（480）、无硬砖，几乎不会失球 → 首局体验是"赢"。
5. **即时奖励**：第 1 关设置 10% 掉落率，让玩家在首局就有较大概率体验到道具。
6. **可跳过**：所有面板优先"继续"，把玩家推向游戏本体。

### 6.3 启动路径（仅 2 条 + 通关画面）
| 玩家 | 落地页 | 提示 |
|---|---|---|
| 首次（`stats.runs == 0`） | **直接进第 1 关 READY** | 显示拖拽提示一次 |
| 有未完成进度 | **直接续进「上次未通关的那一关」READY** | 无 |
| 5 关全部通关 | **通关画面 FINISH**（总得分 + 重新挑战） | 无 |

> 原「主菜单 / 继续游戏 / 新游戏」已随主菜单一并移除；「从头重玩」改由暂停面板的「重玩第 1 关」承担。

## 7. 可访问性（Accessibility）

| 项 | 措施 |
|---|---|
| 触控面积 | 所有可点元素 ≥ 88×88 px |
| 对比度 | 砖块/文字与背景对比度 ≥ 4.5:1 |
| 色盲友好 | 砖块类型**不止靠颜色区分**：普通=纯色、硬砖=叠加裂纹、钢砖=金属纹理、炸弹=图标、金砖=星标 |
| 动效 | 「减弱动效」开关 **demo 即实装**（关闭屏震/粒子/拖尾/过关彩带，保留核心运动轨迹）；屏震另受硬约束 ≤120ms / ≤6px（对齐 `art/accessibility.md` D1） |
| 单手持握 | 核心操作在屏幕下 1/3 |
| 视觉清晰 | 球与背景高对比描边，球速高时加拖尾辅助追踪 |
