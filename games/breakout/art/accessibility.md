---

## 1. 分级选择

采用四级制：Basic / Standard / Comprehensive / Exemplary。

| 分级 | 本 demo 目标 |
|---|---|
| Basic | ✅ 必须全部满足 |
| **Standard** | ✅ **本 demo 目标等级** |
| Comprehensive | 🔶 部分落地，其余延后（见 §3） |
| Exemplary | ⏸ 延后（依赖平台能力，微信小游戏不支持屏幕阅读器） |

> **结论：本 demo 承诺达到 Standard，并落地 Comprehensive 中成本低的若干项。**

## 2. 特性矩阵

> **机检面（WXG-T-155 / K-035）**：本表「落地」声称的代码符号锚点正本在 [`a11y-anchors.md`](./a11y-anchors.md)，由 `pnpm run check:a11y`（已挂 verify）强制；改状态列须同批改锚点表（B2 已登记文档 hex 与实现漂移，见该表首注）。

> 设计分辨率 **750 × 1334 / `FIXED_WIDTH`**；约对应 375pt 屏宽 → **1 设计 px ≈ 0.5 pt**；故 88 设计 px ≈ 44pt。

| # | 特性 | 具体要求（本 demo 具体值） | 落地状态 |
|---|---|---|---|
| A1 | **色觉障碍友好 · 砖块** | 5 种砖型用「颜色 + 几何标记 + 明度」**三重编码**：N 青纯色 / T 紫裂纹 / S 钢灰金属斜纹+铆钉 / B 橙红炸弹图标 / G 金币标记（铜钱形：深棕金圆盘+方孔）；明度错开 0.33~0.72 | ✅ **落地** |
| A2 | **受损态可辨** | 加固砖命中 1 次后亮度 −30%（`#A96BFF`→`#7649B3`）+ **裂纹加粗加深**，不靠颜色也能读出"还差一下" | ✅ **落地** |
| A3 | **色觉障碍友好 · UI/状态** | 所有状态（得分/生命/关卡/暂停/连击）**图标 + 文字**并行，绝不单以颜色区分 | ✅ **落地** |
| A4 | **道具不靠颜色区分** | 6 种道具图标**以形状为唯一识别依据**（横条/三圆/心形/沙漏/磁铁/光束），色相仅辅助 | ✅ **落地** |
| B1 | **灰度可辨** | 转黑白后 5 类砖块 100% 可区分（由 A1 几何标记 + 明度分层保证） | ✅ **落地** |
| B2 | **对比度 · 正文/图形** | 文字对背景 ≥ 4.5:1。`#FFFFFF` on `#0C0B1E` ≈ **19:1** ✅；`#A6AEC8` on `#0C0B1E` ≈ **8:1** ✅ | ✅ **落地** |
| B3 | **球的高对比追踪** | 球 Ø24 白心 + **2px 深色描边** `#0C0B1E`（与亮砖分离）+ 外发光 + 拖尾；高速时拖尾辅助追踪 | ✅ **落地** |
| B4 | **不单纯依赖颜色传达信息** | 失球除红闪外，同时有"球没入底部"+ 音效；连击/加命**视觉 + 音效并行**（静音玩家不失反馈） | ✅ **落地** |
| C1 | **触控目标尺寸** | 交互元素 ≥ 44pt → **≥ 88 × 88 设计 px**。暂停按钮 88×88，主按钮 520×120 / 240×88，均达标 | ✅ **落地** |
| C2 | **元素间距** | 相邻可点击元素中心距 ≥ 96 设计 px（≈48pt），避免误触 | ✅ **落地** |
| D1 | **动效可减弱**（demo 实装） | 设置提供「减弱动效」开关：关闭**屏震、粒子、拖尾、过关彩带、呼吸/脉冲**，保留碰撞白闪与得分飘字。**可实现级关停/保留清单见 `assets-spec.md` §6** | ✅ **落地** |
| D2 | **闪烁安全（光敏）** | 任意闪烁 < 3Hz；**禁止**全屏白闪；失球红线闪 ≤1 次/秒、持续 ≤300ms；白闪仅局部 80ms | ✅ **落地** |
| E1 | **文字可读性** | 最小字号 28 设计 px（≈14pt），正文 32px，分数 48px，标题 56px；使用系统字体，随系统字体缩放 | ✅ **落地** |
| E2 | **文本缩放开关** | 设置内「大字号」开关（正文 32 → 40px，面板自适应） | 🔶 部分（基础版落地，完整自适应延后） |
| F1 | **无时间压力 / 可暂停** | 任意状态 1 次操作可暂停/返回菜单；失球后短暂定格 | ✅ **落地** |
| F2 | **难度可选（球速/挡板）** | 提供球速档位、宽挡板等降低精度依赖的选项 | ⏸ **已裁定：本轮延后**（优先"一指可得"支柱，避免开局增加认知；日后引入放设置面板） |
| G1 | **字幕 / 语音替代** | 本 demo 无语音内容 → 不适用（N/A） | N/A |
| G2 | **屏幕阅读器 / 无障碍焦点** | 微信小游戏平台不支持 | ⏸ 延后（平台限制，非本团队可解） |
| H1 | **独立色盲模式预设** | 除默认友好的三重编码外，提供"高对比/色盲增强"预设（进一步拉开明度与纹理） | ⏸ **延后**（主理人冻结：三重编码已保证灰度可辨，独立预设属冗余） |

## 3. 落地范围小结

**本 demo 落地（14 项）**：A1 A2 A3 A4 B1 B2 B3 B4 C1 C2 D1 D2 E1 F1

**部分落地（1 项）**：E2（文本缩放基础版，完整自适应延后）

**延后（3 项）**：F2（球速/挡板难度选项，属玩法数值）、G2（屏幕阅读器，平台限制）、H1（独立色盲预设，主理人冻结：三重编码已足够）

## 4. 与 UX 规格的接口（已对齐 `ux-spec.md` §7）

UX 规格须保持以下条目（当前已满足，变更需回写）：

1. 设置页含 **「减弱动效」（demo 实装）** 与屏震开关（D1）。
2. 所有可点元素 ≥ **88 × 88 px**、间距 ≥ 96px（C1、C2）——`ux-spec.md` §3.2 暂停热区已满足。
3. 砖块类型不单靠颜色（A1）——`ux-spec.md` §7 已列明。
4. 球与背景高对比描边、高速加拖尾（B3）——`ux-spec.md` §7 已列明。
5. 不得设计 >3Hz 闪烁或全屏白闪（D2）。
