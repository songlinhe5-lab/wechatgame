## 1. 视觉锚点

> **一句话锚点（与策划定稿一致）：霓虹街机 —— 深空蓝紫底 + 高饱和发光砖块，碰撞瞬间爆出同色粒子，冷背景 × 暖爆炸的强对比。**

- 玩家 3 秒内应读到的画面：**深蓝紫空间 + 一排发光砖块 + 一条青蓝色光条（挡板）+ 一颗白点（球）**。
- 关键词：**干净、高对比、可读优先、零噪点、发光感**。
- 反面参照（明确不要）：卡通描边、拟物厚涂、多层渐变、噪点纹理、需要位图贴图才成立的效果。

**四条铁律**（贯穿所有资产决策）：
1. **可读性 > 华丽感**。任何特效不得遮挡球、挡板、砖块类型标记。
2. **砖型不靠颜色区分**。砖块类型必须同时用「颜色 + 几何纹理/图标」表达（见 §3.3、`accessibility.md` A1）。
3. **占位即规范**。demo 全部程序化绘制，但每个元素的尺寸/颜色/命名都按正式资产标准定义，未来可 1:1 替换贴图而不改布局。
4. **反馈 ≤400ms**（过关/结算除外），不阻塞下一次操作。

## 2. 情绪板（文字描述）

- **整体气质**：街机感 × 极简主义。参考 Tron / 霓虹几何 / 深夜游戏厅。
- **光照想象**：画面内无真实光源，靠**自发光纯色块 + 外发光（ADD 叠层模拟）**营造"发光物体悬浮在暗场"的观感。
- **材质想象**：哑光纯色 + 单层辉光，无金属反射、无布料、无噪点（钢砖的"金属感"用**高光斜纹**程序化模拟，非真实反射）。
- **色彩情绪**：冷调基底（深空蓝紫）承载高饱和砖块（青/紫/金/橙红）与暖色爆炸，冷暖对比提供能量感。
- **动感想象**：物体运动带轻微拖尾/残影，碰撞瞬间短促粒子爆点，节奏"利落、有弹性、不拖沓"。

### 3.2 砖块类型配色（**核心**）

**设计原则**：类型靠「颜色 + 纹理/图标 + 明度」三重区分；色相选取**避开红绿主冲突**，且各型明度错开，保证灰度/黑白下仍可辨。

| 代码 | 类型 | 色相 | HEX | 近似相对亮度 | 几何标记（**不靠颜色的主识别符**） |
|---|---|---|---|---|---|
| `N` | 普通砖（1 HP） | 青 | `#35C2F0` | ≈ 0.52 | **纯色块**，无标记 |
| `T` | 加固砖（多击破，2 击；GDD 亦称"硬砖"） | 紫 | `#A96BFF` | ≈ 0.45 | **裂纹纹理**（受损后裂纹加深） |
| `S` | 钢砖（不可破坏） | 钢灰 | `#8892A6` | ≈ 0.33 | **金属高光斜纹** + 四角铆钉 + **双层描边**（内亮 `#C6CEDD`／外深 `#4A5266`） |
| `B` | 炸弹砖（1 HP） | 橙红 | `#FF6B3D` | ≈ 0.48 | **显式炸弹图标** |
| `G` | 金砖（1 HP，高分） | 金 | `#FFCB3D` | ≈ 0.72 | **金币标记：铜钱形（外圆 Ø18 + 内方孔 8×8，深棕金 `#7A5210`）** |

**受损态（仅 `T` 加固砖，命中 1 次后）**：
- 颜色亮度 **×0.7（−30%）** → 填充由 `#A96BFF` 变为 `#7649B3`；
- **裂纹加深加粗**（裂纹线宽 1px → 2px，新增 2 条裂纹）；
- 白闪 80ms + 缩放 1.06。
> 验收：受损加固砖须"一眼看出还差一下"——**即使不靠颜色**（裂纹明显加深）也能读出。

**破碎粒子**：与砖块同色（"碰撞即爆同色粒子"），8~12 粒，160ms 内缩放淡出。金砖用金色粒子，钢砖被撞用白/黄**火花**粒子。

### 3.3 类型三重编码（色盲友好硬要求）

1. **颜色**：见 §3.2 色板。
2. **几何标记**：纯色 / 裂纹 / 金属斜纹+铆钉 / 炸弹图标 / 金币（铜钱）标记 —— 覆盖在色块上的印刷式区分。
3. **明度分层**：五型亮度错开（0.33 / 0.45 / 0.48 / 0.52 / 0.72）。

> 验收标准：**画面转黑白后，仍能 100% 正确区分 5 种砖块类型**；加固砖受损态可辨。

### 3.4 特殊砖块视觉语义锚定（对齐 `bricks.md` §2.6）

> 本节确保「视觉编码 ↔ 玩法语义」一一对应（主理人转达的复核要求）。

**`T` 加固砖 —— 实为 2 HP，仅"完好 / 受损"两态（非多档）**：
- 第 1 次命中 → 亮度 ×0.7（`#A96BFF`→`#7649B3`）+ 裂纹 1px→2px 并新增 2 条；第 2 次命中 → 破碎。
- 结论：**现有两态编码已完整对应，无需引入多档明度阶梯**。

**`S` 钢砖 —— ∞ HP / 0 分 / 免疫一切道具 / 不计通关 / 永不派发 `brick:destroyed`。语义最重，须"第一眼 = 打不碎、别浪费球"**：
- **静态识别（三线索叠加，不靠颜色）**：① 金属高光斜纹（与其他砖的哑光纯色/裂纹区分）；② 四角铆钉；③ **双层描边**（内亮 `#C6CEDD`／外深 `#4A5266`），使其在砖阵中"跳出来"。
- **命中反馈（与可破坏砖严格区隔）**：金属亮闪（用金属亮色 `#D8DEEA`，**非白闪**）120ms + 火花粒子 + **不缩放淡出、不碎裂、不飘分**；球为不衰减的镜面反弹（"弹回"感）。
- **禁止**：分数飘字（S 为 0 分）、破碎粒子。程序侧 S 只派 `hitBrick`，不派 `brick:destroyed`。

**`B` 炸弹砖 —— 爆炸半径 68px（实际仅覆盖自身 + 上下左右四邻）**：
- **特效尺寸必须与范围视觉一致**：冲击波环**半径 = 68px（直径 136px），不得放大**；避免大圆环暗示"对角也被炸"。
- 半径 68 仅覆盖正交四邻（对角距离 ≈ 79px > 68，**不被波及**）→ 建议以**实际受影响砖块同步高亮/碎裂**为准（即"十字形"共 5 块），圆环仅作点缀。
- **判定比较符（与程序必须同符）**：受影响砖块 = 中心欧氏距离 **`d ≤ EXPLODE_R(68)`（含边界）**；先按此选范围，再**排除 `S` 钢砖**（免疫）。视觉高亮范围与伤害判定**同符同范围**，不得一个含边界一个不含。
- **"不伤钢砖"的视觉体现**：冲击波波及钢砖时，钢砖**不碎裂**，改播一次金属防护闪光 + 火花（与普通砖碎裂形成对比），传达"免疫/弹开"。

**`G` 金砖 —— 高分（500），道具"非必掉"（×3 且封顶 1.0）**：
- **金币标记**（铜钱形）语义定为 **"高价值 / 高分"**（500 = 普通砖 5 倍），**不代表"必有道具"**。
- 避免"打到就一定有道具"误读：① 道具与砖块标记**无视觉绑定**，道具仅在触发掉落时才出现（统一 `assets-spec.md` §1.4 图标下落）；② 金色粒子表达**高分爆发**，不表达"掉落"。
- **形状规格**：深棕金圆盘 `#7A5210`（Ø18）+ 中央方孔 8×8（透出砖块底色 `#FFCB3D`）→ 铜钱剪影；最小特征 5px（圆盘壁 (18−8)/2），灰度/缩放下仍清晰（见 §3.4 末"小尺寸可辨性"）。
- 承 `bricks.md` §2.6 G 边界④：黑白/色盲下靠**金币标记**区分（不靠金色），与本表一致。

**小尺寸灰度可辨性复核（62×34 砖块内）**：五类标记的最小特征尺寸均 ≥ 5px——`N` 无标记、`T` 裂纹线宽 1~2px（受损 2px）、`S` 斜纹间距 ≥ 6px + 双层描边、`B` 炸弹弹体 Ø16 + 引线 2px、`G` 金币圆盘壁 5px + 方孔 8px。**结论：金币是唯一"实心盘 + 负空间方孔"型标记，其大块负空间在 50% 缩放与灰度下最抗糊；与 `B`（弹体 + 顶部引线，轮廓有凸起）剪影差异明显，不会混淆。**

## 5. 形状语言

- **基础形状**：只有三种 —— **圆（球）、圆角矩形（砖块/挡板/UI）、直线网格（背景/墙体）**。
- **圆角规范**：砖块圆角 4px；挡板圆角 = 半高（12px，胶囊形）；UI 面板圆角 16px；按钮圆角 12px。
- **描边规范**：砖块无描边（靠色块+标记对比）；挡板无描边（靠辉光）；球 2px `ball_outline`；UI 面板 2px `ui_border`。
- **比例**：砖块 62×34 ≈ 1.82:1；挡板 140×24 ≈ 5.83:1；球为完美圆形。

## 7. 动效气质（毫秒值，对齐 `ux-spec.md` §5）

> 统一缓动：进入 `ease-out`，退出 `ease-in`。

| 动效 | 时长 | 缓动 | 说明 |
|---|---|---|---|
| 按钮按下 / 释放 | 80 / 120 | ease | 缩放 0.95 → 回弹 1.0 |
| 主菜单标题呼吸 | 2000 循环 | 线性 | 光晕强弱循环 |
| 发球拖尾 | 80 | — | 球拖尾淡出 |
| 球撞挡板 | 40 | ease-out | 挡板纵向挤压 0.9 + 球 60ms 闪光 |
| 撞墙 | 80 | ease-out | 内壁高亮 |
| 球撞砖（未破，加固砖） | 80 | ease-out | 白闪 + 缩放 1.06 + 裂纹加深 |
| 砖块破碎 | 160 | ease-out | 同色粒子 8~12 粒 + 缩放淡出 |
| 钢砖被撞 | 120 | ease-out | 火花粒子，砖块不消失 |
| 炸弹爆炸 | 400 | ease-out | 冲击波圆环 + 低沉音（**屏震 120ms、幅度 ≤6px**） |
| 分数飘字 | 600 | ease-out | 上浮渐隐 |
| 倍率提升 | 120 | ease-out | 连击数字脉冲 1.3× |
| 拾取道具 | 800 | ease-out | 图标放大淡出 + 泛光 + 文字标签 |
| 加命 | 300 | ease-out | 生命点弹出 |
| 失球 | 300 | ease-in | 底部红线闪 + 碎裂 |
| 终局慢放 | 400 | — | 0.3× 时间缩放 |
| 过关 | 800 | ease-out | 彩带粒子（面板 200ms） |
| 面板入 / 出 | 200 / 150 | ease-out / ease-in | scale 0.9→1.0 / 淡出 |
| 暂停遮罩 | 150 | ease-out | 淡入 α0.65 |

- **帧率目标**：60 FPS；粒子总数 ≤ 200，单次爆点 ≤ 12 粒。
- **红线**：任何反馈 ≤400ms（过关/结算除外）；屏震 ≤120ms/≤6px 且可关闭。
- **禁用**：>3Hz 闪烁、全屏白闪（光敏安全，见可访问性）。

## 8. 材质与光照

- **无贴图材质**：所有元素为纯色填充 + 程序化辉光；辉光用**叠加（ADD）混合的放大副本**模拟，不引入模糊贴图。
- **钢砖"金属感"**：用 45° 高光斜纹（比底色亮 +20%）程序化模拟，非真实反射。
- **光照层次**（弱→强）：背景网格 → 砖块 → 墙体 → 挡板/球（最亮）。
- **禁止**：内阴影、置换贴图、法线贴图、PBR。
