## 判据

- **[判据][K-040] 判据回写轮的三个读数陷阱：改严≠回归、作废≠平凡真、文档一致≠代码一致**（来源 WXG-T-098 裁定包 + QA 改判轮，2026-09-15）
  现象：一个只改**文档判据**的轮次（无任何 `src/` 改动）跑完整轮回归，结果同时出现三种易误读的变脸：某条 PASS\*→PASS（P20，因窗口口径写定）、某条 PASS\*→**FAIL**（P4，因规格互斥被消解后旧实现不再“忠实于表”）、某条 FAIL→⛔（P26，因判据作废）。只看总数会得出一套完全错的结论。
  根因：判据本身是被测对象的一部分——它变严、变可测或作废，都会重排读数，但与实现质量无关；而“互斥的两条规格”一旦裁定，**未被选中的一条就自动变成实现落差**。
  代价：若不逐条归因，下一轮的人会拿“FAIL 数持平”判定“无变化”，或拿 P4 变红开一条**重复缺陷**（BD-29 已占号）。
  规避：① 回写轮必须**先改预期值、后实跑**，并在证据里用 mtime 硬自证顺序（设计回写时刻 < 预期值修改时刻 < 实跑时刻）；② 新读法与旧字面严格读法**并列呈报**（P20 写明“旧读法仍 15≠16”），防“数字变好看”误读；③ 比例/统计类判据在**前置不可构造**时必须判**作废（⛔ 不产绿）**，不得记“恒空⇒平凡真”（两者不等价：前者无从判定，后者判定成立但恒真）；④ 规格冲突一旦裁定，同批必开**改码单**并在判据行就地写“实现落差登记”，否则“文档已改”会被读成“已修”。
  判例引用：`production/qa/beads/g4-regression-report.md` §21（主理人逐条裁定 + 方框效应提醒）、§20.4；同族 K-035（假绿谱系）。

- **[判据][K-041] 容差写法：不得吞掉被测变更，帧量化只进时刻轴**（来源 WXG-T-098/BD-27、BD-25 判例，2026-09-15）
  现象：“60s 内恰 16 次（±0）”在离散帧时基下不可判——第 16 次实际落 60.033s（超出闭区间 2 帧），于是“±0 不允容差”= 永久 FAIL，“放 ±1s”= 又能吞掉任何变更。同时旧文的 ±1 容差恰好吞掉了“首供使 15→16”的真变更（BD-25 前瞻性假绿）。
  根因：把**次数**与**时刻**挤在同一容差里；而帧时基下“名义调度时刻”与“实际帧时刻”本来就有非负有界偏差（固定舍入）。
  代价：判据不可判时，QA 只能记 PASS\* 并上交裁定 ⇒ 一条 P2 文档缺陷挂住整条 P1 关单（BD-25 阻塞一个波次）。
  规避：① **两轴分列**：次数轴维持 ±0（缺一次/多一次均 FAIL），时刻轴单独立 `0 ≤ t_actual − 名义 ≤ N 帧`（**非负**硬要求，提前即 FAIL）；② 定窗口必写**开/闭区间**与**计数基准**（按调度**名义时刻**映射序号，而非按实际帧时刻）；③ N 帧上界必须由**具体成因**推出（如：首供分支不累计 1 帧 + 向上取整 1 帧 = 2 帧），不得取手感值；④ 「帧」的定义归**框架实现事实**（`GameLoop.fixedDt`），以真源前言的划界条目定义一次，**不在每款游戏的常量表里重复冻一个时基值**（否则一处改值两处漂移）。
  判例引用：`games/beads/design/gdd/tray-spawner.md §8-1` 现文三子条、`systems-index.md §3 前言使用约定第 4 条`；同族 K-037（统计容差偏紧会误报，卡方判例）。

- **[判据][K-044] 判定上限由「判据完备性」决定，不由实现进度决定；且不得把「缺通道」当预期写进 PASS 条件**（来源 WXG-T-097/BD-10，2026-09-15）
  现象：同一轮里连犯两个反向错误——① 旧探针把「指令签名去重种数 ≤1」当 PASS* 成立条件（即把「根本没实现」写成可通过的预期）；② 该缺失通道一落地，又顺手把整条从 PASS* 升成 PASS。
  根因：PASS/PASS\*/FAIL 的分界被当成“对实现进展的奖罚”，而不是“本条到底有多少子句可判”；后者的上限由**判据完备性**（如规格未定义 α 幅度 ⇒ 该子句无从判）和道次覆盖度锁定，与谁何时补上缺口无关。
  规避：① 每条判据写清「缺哪一道」，**不可判定子句只能产出 PASS\* 或 ⛔，不能产出 PASS**；② 部分关闭 = 改「残留描述」而不是改「整条判定」；③ 升格前必回查缺陷台账里针对**本条**的“待判据”登记（本例 BD-35）；④ 旧 PASS* 条件若本质是「缺失」，补码时必**替换取证方式**（改量真信号）而非直接删断言。
  判例引用：`production/qa/beads/g4-probe-v1.1.mjs` 修订 40① 与 P7 判定块注释（BD-35 钉住上限）、`c39ebac`→`cc8065e` 自纠两笔相邻；同族 K-040（判据变更归因）、K-035（假绿谱系）。
