### L0 底 tile 不继承 shape（WXG-T-257 · 第十八刀）：盘面「缺 -0.3 底色」的真因是底图 50.7% 透明

- 用户先问「这张 mask 槽外圈的底色是透明的吗？要求是透明底图、叠加底色」，再报「harness 托盘 ok，盘面珠格缺 -0.3 色档底色」。两条合并定位到一个根因。
- **通道口径先钉住**（免得下次又推演）：mask 编码 `R=d / G=l / B=shape`，A=255 免疫 Trim；生效件 `assets/effects/tint-mask.effect` 与 harness `compositeTintMask` **两端同式** `alpha = shape` ⇒ shape=0 就是完全不画。
- **病灶**：定稿 grid mask 的 shape = 槽口内 255 / 格外 0（v7.0），而 L0 底 tile 由 `composeMaskTile` 从**同一张源**派生 ⇒ 继承 shape ⇒ 实测合成后 **8304/16384 = 50.7% 像素 alpha=0**（格底外圈 3dp + 1.5dp 出血全透）；S5′-2 合并后盘面每格只发这一条 blit（`tilePainted` 跳了 B0 rect）⇒ 那些区直接露页面背景。托盘 ok 是因为它 `tilePainted=false`、槽自带矢量亮底。
- **口径（本批定）**：tile 形态 = 底图 ⇒ shape 恒 255（满幅不透明）；cell 形态 = 结构件 ⇒ 仍按 shape 真透。落点 = `composeMaskTile` 一处（两条出口共用一个 `SHAPE()` 闭包），两端同源不破 DEC-3。⛔ 不是改资产。
- **同批抓到的资产漂移**：`cocos/assets/textures/` 里 `grid-hole` 是 9-29 旧档（B 恒 255 ⇒ 格外也不透明）、`bead-hole` 也非定稿件；**定稿生成器重跑逐字节 ≡ `tools/mask-preview/cocos-assets/`** ⇒ 该目录才是权威正本，harness 读它、Cocos 读手抄件 = 两端不同源。四张已同步 + `check:cocos-mask` 加**定稿等值腿**（无产物也跑）。
- **教训（门盲区）**：`check:board-seam` 是静态口径门（只证 `TILE_BLEED` 外扩存在），`check:cocos-mask` 旧腿只证「文件在包里」⇒ **两条都拦不住「外扩像素其实是透明的」**。静态门守形状，像素级透明必须像素级断言（本批落在 `mask-tile.test.ts` ④）。
- **取证法可复用**：判「谁定稿」= 把生成器拷到 temp 重跑再比 md5（⛔ 不覆盖在册件）；测「合成后到底哪透」= 直接调真函数 `composeMaskTile` + `compositeTintMask` 出 ASCII alpha 地图，**零浏览器**；A/B 只切那一笔（本文件未入库 ⇒ 无 HEAD 基线，靠摘调用重建）。读数：差异 19.39% 像素，0.70 档两色 39359 → 113219（×2.88），背景色 −75702。
- 读数：framework **447**（+1 新腿）· beads **811 + 1 skipped** 未动 · mask 4/4 + 等值 4/4 · size **beads 2918.8 KB（超内部目标，存量 WARN；当时误记为 1886.0 且归给 breakout，见二次更正）** · **`verify` 21/0** 。在册 = ADR-0030 **§5.8**。
- ⛔ 未闭：格缝青/品红点阵 `(38,224,255)` **三臂同数 20609 px**（含 `tint=off`）⇒ 非本批引入、非 blit 通道，未查；用户「格底透明 + 纯色底混合」的原始口径只做到底图不透明，真透明需迁 I-5/I-6 的 0.70 判据 ⇒ 未开批；**beads** 主包 2918.8 KB 超内部目标（另案；本行原写 breakout，已二次更正）。**未 commit。**
