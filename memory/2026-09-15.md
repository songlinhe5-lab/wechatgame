## WXG-T-096：beads 音频后端落码（BD-05 / BD-05b，路线 ADR-0013）

- **架构裁定（ADR-0013 新建）**：合成引擎 `SynthAudioBackend` 住 `packages/framework/src/platform/audio-synth.ts` —— 不能进 `core/**`（L2 禁 DOM/`AudioContext`）、不能进 `games/*/src`（L3 + Node 可测）；**音色表归游戏侧** `Game.audioVoices` → `App` → `Platform.createAudioBackend({ voices })`；未登记 clip = **不发声 + 一次性 warn**（禁止引擎发明音色）；能力缺失 ⇒ `NullAudioBackend`（不谎称 iOS 能出声）。备选「引擎住游戏侧」「音色进框架」「weapp 用 InnerAudioContext 播文件」三条的否因都写进 ADR §2。
