### 甲案续：用户反馈「渐变环没有任何透明」——四变体实测（B/B2/B3/B4）

- **用户观察属实**：B 的环带 **α 恒 255（不透明）**，只有孔中心 α=0 的圆透 ⇒ 环带靠 `d` **压暗**而非透明。机制式：`α·(base·d)+(1−α)·base ≡ α=1 且 d′=1−α(1−d)` ⇒ **「透明」与「暗」是同一枚硬币的两面**。
- **四变体（合成后 R 沿半径，近白 #FDF6E9）**：
  - **B**（强·硬边）：112→137→161→186→209→234（α=255）
  - **B2**（全环 alpha 羽化 ⇒ 真半透明，D 图 α 最低 **124**）：199→195→198→205→217→236 ⇒ **阴影被洗掉约 2/3 且非单调**
  - **B3**（弱环 d 0.70→1.0）：181→193→205→218→230→243（整体减半，仍单调）
  - **B4**（**只在孔口 0.5dp 窄羽化**）：**181→137→161→186→209→234** ⇒ 仅首档淡，其余完整保留 B 的梯度 ✅ 折中解
- **结论**：要「环带透明」就必须交出暗度；要消除孔口硬边而不洗淡阴影 ⇒ 用**窄羽化（0.5dp 级）**，别做全环羽化。
- **判据自纠（第二次）**：跨度门固定 60 会把**弱环 B3（跨度 50）误判为「非渐变」** ⇒ 门的作用是排除「全等」假绿，与强度无关 ⇒ 降到 30 并注明用途。另：B4 的 `αmin` 读数 255 是**采样步长 2 跳过了 1–2 texel 的窄羽化带**（合成侧首点 181 已证明羽化生效）⇒ 窄带特征不能用疏采样取证。

### B5（2dp 环 + 偏置渐变）实测：偏置量必须远小于环宽

- **B5 参数**：环宽 **2dp**（8 texel）+ 径向渐变圆心朝**左上**偏（canvas −y = 屏幕上）⇒ 左上壁暗、右下壁亮（光从左上入洞 ⇒ 左上内壁背光，与槽「上暗下亮」同向）。
- **实测（五色同结论，取 c1 代表）**：D 图左上壁灰 **143** / 右下壁灰 **226**（Δ=83 ✅ 方向正确）；沿 +x（亮侧）192→228→255 跨度 63 ✅ 渐变仍成立；合成 R（近白）154→190→226→253。
- **⚠ 比例约束（可复用）**：偏置 **1dp / 环宽 2dp（=50%）时亮侧阴影几乎被抵消**（D 图 232→255→255，跨度 23 ⇒ 判红，环退化成半月）；降到 **0.5dp（=25%）** 才保住亮侧。⇒ **偏置量 ≲ 环宽 × 25%**，⛔ 别按"看得出来的偏置"去给值。
- **方向取向易错**：Canvas y 向下 ⇒ 要「左上暗」须把渐变圆心偏**左上**（我第一版偏右下 ⇒ 左上反而变亮，实测反证）。
- **与 B（3dp 均匀）比**：B 更深（最暗 112）但无方向；B5 有方向但整体淡一档（最暗 154）⇒ 「方向性」与「深度」也是互换的，同「透明 vs 暗度」那枚硬币。
- 若要**坑洞感**：最终候选 = **C 的暗底（pit）+ B5 的偏置环**（样张里 C 现为均匀环 + pit 底）。

### 甲(D1) 与 丙(D2) 终版实测：坑洞候选 = 甲；丙是更好的机制但需再调参

- **甲 D1 = 孔底 pit 暗底 + 偏置环（2dp, 偏置 0.5dp）**：环与 B5 完全一致（左上壁 142 / 右下壁 226，Δ=83），孔中心 α=255 填 `pit` ⇒ **有壁 + 有暗底 = 坑洞感最合适的候选**。⚠ 判据曾拿「孔中心透=α0」判它 ⇒ 判红；属**判据口径错**（D1 设计就是不透），已改为判「α=255 暗底」。
- **丙 D2 = 径向管衰减 + `screen` 叠 conic 管方向**（语义正是 ADR-0028 亮端 `out = base + l(θ)(1−base)`）：**解耦成立** —— 暗侧 l=0 ⇒ 最深处与 B5 同为 107（不被牺牲），亮侧 l>0 提亮；且径向暗区厚度可独立调（加中间 stop 0.55）。
- **调参结果**：`l_max` 0.75 ⇒ 整体被洗淡（左上 180 / 合成最暗 192）；降到 **0.45 + 径向暗区加厚** ⇒ 左上 165、合成最暗 **159**（≈B5 的 154），方向 Δ=43 ✅。⇒ **深度已追平，方向对比略弱于甲（Δ83）**；把 l_max 提到 ~0.6 配径向加厚，理论上可同时拿到「深度≈甲 + 方向≥甲」，需再一轮。
- **机制结论**：偏置(甲)与调制(丙)都成立，区别 = 偏置靠几何距离（会压缩亮侧暗度分布，受「偏置 ≲ 环宽×25%」约束）；调制靠 screen 提亮（暗侧零牺牲、参数解耦）⇒ **长期优选丙**，短期出效果用甲。

### 丙（conic 调制）终调：深度与方向**双超甲** + 环宽 2/3dp 两档

- **终参数**：径向（靠孔 55% 环宽**保持最深** 0.42，外段升到 1.0）+ `screen` 叠 conic，**有效角度收窄到右下 ±36°**（stops 0/0.4/0.5/0.6/1）、**LMAX 0.85**。
- **结果**：**D2（2dp）左上壁 142（= 甲）、右下壁 236、Δ=94（甲 83 ⇒ 方向超过甲）**；合成最暗 **106**（甲 154、B 112 ⇒ **深度也超过甲**）。**D3（3dp）**：左上 142 / 右下 231 / Δ=90，合成前 4 采样点恒定 106 ⇒ **暗壁更厚更实**。
- **关键机制（可复用）**：① 深度与方向本是一枚硬币，但**解耦后有独立旋钮** —— 暗侧由径向管（加厚即更暗）、亮侧由 conic l 管；② **必须先把 conic 角度收窄，LMAX 才敢加大**（收窄前 LMAX 0.6→0.75 会连带洗淡右侧深度；收窄后 0.85 只提亮右下，右侧 l=0 不受影响）⇒ 这是"深度与方向双超"的唯一路径。
- **环宽 2dp / 3dp**：mask 侧是纯几何（径向 `rOut−rIn`），⛔ 不受 C7 层集命令约束 ⇒ 任意 dp 可调；2dp=8texel 更精细、3dp=12texel 暗壁更厚。⚠ **屏上**：1dp=0.5 CSS px ⇒ 2dp = 1 CSS px，dpr1 仅 **0.5 物理 px**（近乎消失）⇒ 与 `cell-standard §1` 已登记的「低档机描边可读性」同类；渐变（非实色）比实色更怕窄 ⇒ **建议 3dp 起步或给 dp 地板，真机 A/B**。
