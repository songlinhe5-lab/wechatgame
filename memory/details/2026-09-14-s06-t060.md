## S6 道具系统落码：beads 最后一个未实现玩法系统归零（WXG-T-060）

- **选点依据**：侦察后确认 beads 只剩 `EP-06（S6 道具）` 未落码（`src/systems/powerups.ts` 不存在，
  实现里只有 3 张空白卡 + `ad_badge` 占位），而 `powerups.md §8` 有 **10 条冻结硬判据**且全部
  Node 可测；落地还能解锁 backlog 里被它阻塞的「到达序判据清理」。
- **落码**：`systems/powerups.ts` = 只读镜像（`tray:spawned`/`bead:placed`/`tray:expanded` + 选中锚点）
  + 三道具（region 恒长窗口/两端钳制、clearAll 全容量、random 等概率无放回走注入 Rng）
  + 三计数独立。**「点名归 S6、清槽归 S4」**：S6 只算 `affectedSlots`，清槽由 `Tray.clearSlots()` 执行，
  广播的 payload 用**实际清空**的槽（§8-1 要求 1:1），不一致即警告（镜像漂移检测）。
- **消灭双份常量**：卡片几何原先在视图与命中测试各写一份 ⇒ 收进 `tuning.ts` 的 `powerupCardRects()`，
  画出来的卡与点击落点不可能不一致；测试断言进拼图带（见下）。
- **又一个「假绿」被修**：`accessibility.md` A4 标 ✅「三道具以形状为唯一识别 + 文字标签并列」，
  而实现是 3 张**空白卡**（无图标无标签）。已按 `assets-spec §1.4` 落三图标（魔法棒/扫帚/磁铁，
  程序化 path，配色常量进 `palette.ts`），A4 改 ⚠️ 部分落地（文字标签因规格冲突未落）。
- **测试**：`tests/powerups.test.ts` 16 条（§8 十条 1:1 + 常量镜像）；beads **129 → 145**。
- **三条我自己的测试坑（写下来防复发）**：① 用**出货关卡**做供料测试——关卡 1 的
  `spawnInterval` 是 **6**（非 4.0）且首行含 `.`/`x`，`advance(4.05)` 静默无供料、`(0,0)` 是 void 格；
  ② §8-4 均匀性偏差先怀疑实现、实测 6 个 seed 后确认是**统计容差问题**；
  ③ 广告替身把 T-058 的一次性监听注册（`onRewarded/onClose/onError`）也算成「广告调用」——
  §8-8 要的是**不 `load`/不 `show``**。
- **登记（未擅自改冻结判据/规格）**：① §8-4 的「200 次 ±20%」统计上偏紧（12 槽族极大偏差期望 ≈22%，
