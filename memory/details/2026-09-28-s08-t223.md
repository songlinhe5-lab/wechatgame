## WXG-T-223：空槽凹感改「槽内一周内阴影」——删 S1 描边 + 坑底边对齐珠面（CodeBuddy 主理人会话 · 文档+代码+判据同批）

- **用户四项裁定（两轮先问后写）**：① **槽不做描边** ⇒ S1 暗缘框（`hole −0.58`、1dp stroke）**整笔删除**、不留开关（C4）；② **槽内一周内阴影**（不是分层加深、不是描边）；③ **坑底边与珠面描边对齐** ⇒ 盘面格 `relief` 退 **0**（有孔档坑外廓 21.8→**26**、无孔档 19.8→**24**；中心坑底 20/18）；④ 内阴影 = **3 层阶梯 −0.80/−0.68/−0.58**，每层 1dp（选 C 案）。去框方式选「同批替换、不留开关」。
- **关键澄清（用户以为可以只在烘焙侧做）**：DEC-4 同源纪律 ⇒ cell mask 就是直接调 `drawEmptySocket` 烘的（`bake-recipes.ts::makeCellRecipe`）⇒ **不存在「只改 mask、矢量不动」**；改 `drawEmptySocket` = 矢量臂立刻上屏 + mask 同源自动跟随（这对用户是好事：不用等 tint）。
- **落码**：`tuning.ts`（`SOCKET_CARD.innerShadeStepDp = 1`；`relief` 注释收窄为**仅托盘槽**）；`palette.ts`（新增 `SOCKET_SHADE_OUTER_MIX 0.80` / `SOCKET_SHADE_MID_MIX 0.68`，`BeadEndpoints` 增 `shadeOuter`/`shadeMid`，最内层**复用** `hole` −0.58 档省一字段）；`bead-render.ts`（4 枚同心圆角 rect **由大到小**依次 fill 造环，圆角逐层递减；S3/S4 迁到中心坑底内；**S3 墨 `pit → hole`**、`tilePainted` 分叉删除）。命令账：盘面空格 4→**6**、托盘 5→**7**。
- **两个必然连带（非新拍板，推导所得 + 已呈报）**：① **S3 墨必须改档**——墨档是相对**当时的背景**选的，两线现画在中心坑底 `pit −0.44` 内，沿用旧档会与它同色 ⇒ 暗线读作亮线、凹感方向反掉；② **托盘必须保留 relief**——`TRAY_BEAD_SIZE 44 < TRAY_SLOT 48`，坑若 = 整槽则珠盖不住坑 ⇒ 「坑底边对齐珠面」**只对有珠对照的盘面格成立**（分叉已写进文档）。
- **判据改写（⛔ 换识别子，不是放宽）**：① `bead-render` J3 的旧识别子 = **stroke-only rect**，随删框**消失** ⇒ 改「外沿相等 + 中心坑底严格 ⊂ 珠」+「槽侧零 stroke」；② `bead-style-settings` 凹槽 2 档 → **4 档等差**，且凹槽外沿档与珠体宽度**合并** ⇒ 旧 `onlyFull.length = 3` 数轴实测掉到 **1**（只改数字 = 假绿）⇒ 新识别子 = 「直方图最窄 4 档 + 枚数分解：外沿枚数 = 已填 26 + 空格 39 = 65」+ 第 5 档 418 阳性对照。**教训（可沉淀）**：视觉变更会连带杀掉判据的识别子本身，改判据前必须先验「识别子还在不在」，不是调数字。
- **诚实边界**：内阴影是**实色阶梯**（层集无渐变图元），非真渐变；`base·d` 乘法本质 ⇒ **纯黑格 CR 仍 1.00，暗端退化未解决**（换载体不修）。
