## 构建链前置补洞 + 多游戏粒度修正（WXG-T-047 / T-048，CodeBuddy 会话）

- **T-047 补两个缺失脚本**：`check-bundle-size.mjs`（阈值真源 `systems-index §3.8` 双口径：红线 4096/30720 KB、内部目标 2000 KB，**分列不混用**；分包三级回退 `game.json`→`subpackages/`→全计入主包；干净检出自动跳过）+ `check-secrets.mjs`（把 `control-manifest §10` / `ADR-0010 §4.2-5` 两条**只写在文档里、脚本却不存在**的红线机械化。关键设计：扫描面 = `git ls-files --cached --others --exclude-standard`，即「**会不会入仓**」而非「磁盘上有没有」；故不需要 `--staged` 模式。接 pre-commit **⓪ 步** / CI `arch-guard` / `verify`；`.gitignore` 补密钥段）。自测 **13 + 18** 全绿。
- **实测推翻 `ADR-0009 §3.2 P2`**：`cocos-mcp-server` **v1.5.4 不能触发构建**——`project_build_system` 仅 3 个只读 action；唯一含 `build` 的 `project_manage` 被白名单禁用，且其实现只 `Editor.message('builder','open')`，源码注释原文 *Building requires manual interaction through the build panel*。⇒ 微信构建**结构上不可自动化**，G7 只能靠「人工构建 + 回读日志 + `check:size`」。已按 ADR 惯例**不改写原行**、另加偏差注。
- **多游戏粒度修正（T-048）**：① `build:cocos` 由"根层裸命令"改为 **per-package 声明 + 根 `pnpm -r` 聚合**——`games/<game>/cocos/` 每款游戏都有，根层裸命令**说不清构建哪一款**；② `sync-levels-data.mjs` 原**硬编码 breakout**，导致 beads **有真源、有产物却零门禁且静默报绿**（K-031 族）→ 改「**每游戏 header 模板 + 通用遍历**」+ **覆盖面断言**，新游戏零改共享脚本。
- **门禁补齐后首跑即抓到 beads「漂移」——但定性后是格式漂移，不是数据漂移**：beads 的产物由**另一个渲染器**产出（单引号 / 紧凑数组 / `6.0`），其**数据与真源结构等价**（用 sortDeep 逐字段证明相同）。**教训：门禁报「不一致」时必须先定性再覆盖**——否则会把"格式差异"误报成"数据事故"，反向也可能抹掉手工修正。
- **新脚本首版漏「仅直接调用时执行」守卫**：`sync-levels-data.mjs` 顶层有写盘副作用，而它要导出 `buildModuleSource()` 供测试复用 ⇒ **一次 `import` 就改写了 beads 产物**。已补守卫并实测「import 不写盘 = true」。**教训：任何被测试 import 的脚本，写盘必须收进 `main()` + `import.meta.url === process.argv[1]` 守卫。**
- **文档回填 8 处**：`architecture.md §5`「gzip 后统计」措辞（实现是 **raw 判定**；raw ≥ gzip，按 raw 卡严格更安全）、`cocos/README §2.1` 与 `VERSION.md G1` 的 **strip-suffix 反向漂移**（文档写"拷贝件保留 `.js` + 备有 `--strip-suffix`"，实现是 `stripSuffix = !includes('--keep-suffix')` 即**默认剥除**；实测拷贝件确无后缀 ⇒ 该残余风险对本工程已不适用）、`ADR-0009 §3.2` P2 偏差、`test-plan Q9`、`cocos-setup §12`。
- **顺手抓到 3 处**：`my-mcp/README.md` **两个 `## 5.`**（T-046 插节未重编号）；`settings/mcp-server.json` **已提交版本键名错**（`debugLog` vs 扩展认的 `enableDebugLog`）⇒ 该开关一直失效；未跟踪目录 `games/breakout/cocos/preview-template/` **未被 gitignore**（`git add -A` 会静默入库，**待决**）。
