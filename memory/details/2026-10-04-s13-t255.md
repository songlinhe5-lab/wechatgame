## 三十五批 · mask 只进 2/4 的确诊 + 档位宏 + 产物门禁（2026-10-05 · WXG-T-255 · ADR-0030 §5.5 第十五刀）

**四项未闭环收口的第一批**（用户令「S5′-3 层序、S3 两端对拍、`[R]` 低端机、mask 是否进打包产物 收口」）。
我先做的是**事实核**（⛔ 未写生产代码），结论 = 四件不是并列，是一条关键路径 **④ → ① → ② → ③**。

**用户裁定推翻了我给的三个选项**：「hole 和 holeless 图片纹理打包到主包，**暂时设定宏**，指向 hole 相关图片纹理，可以编码切换到 holeless」。
这条裁定的价值不在"少两张图"，而在它**改写了注入前提**：`warmup()` 旧前提「4/4 齐才注入」⇒ 任何构建档恒 2/4 ⇒ **永不注入**
⇒ `carrier=on` 静默落回矢量臂（屏幕上看不出任何异常，编辑器 Preview 是唯一跑得通的环境）。前提收为「宏要的那几张齐」后
`holed` 两张已在包 ⇒ 构建档当场可注入 ⇒ ①②③ 的验证闸门**不必等编辑器**就解除。

**确诊读数**：`build/{wechatgame,web-mobile}` 两份产物里 mask 都只进 2/4 —— `cbf588aa`（bead-hole 8,750 B）✅、`a626af4b`（grid-hole 3,395 B）✅、
`dcc16bba`（bead-holeless 4,210 B）❌、`f8648f92`（grid-holeless 2,872 B）❌。包体不是问题（四张合计 19,227 B）。
**根因是引擎规则、不是工时问题**：Cocos 构建期依赖分析只打包被 `.prefab`/`.scene`/`.mtl` 静态引用的资产；
载体 `MASK_UUID` 里的 **uuid 字符串不构成引用** ⇒ 引擎看不见。进包那两张是被 `assets/effects/tint-mask*.mtl` + `assets/probe/tint-probe.scene` 顺带带进去的。

**⚠ 本轮最值钱的取证自纠**：第一轮明文 `grep <uuid> config.json` 得出「wechatgame 档一张都没进」= **假阴性** ——
该档 `config.json` 的 `uuids` 存**压缩 base64**（`cb9YiqOrhBiq9CXqa0/guc@6c48a`）。正确取证面 = 直接看
`assets/main/native/<uuid 前 2 位>/<uuid>.png`（命名确定、无需解索引）。⇒ 沉淀 **K-108**（含"产物级门禁"这条做法）。

**落点选择（ponytail：一处守卫住查表处）**：宏解析 `resolveTintGauge()` 只住在 `tintMaskId()` / `tintTileMaskId()` **查表处**
⇒ 一处覆盖**两宿主 × 两形态**（珠面 / 底 tile），⛔ 不在 `view-model` 两个调用点各写一遍；
需求集 `requiredTintMaskIds()` 由**两宿主共同消费**（装载 / 预热 / warmup 阈值），⛔ 各自硬编码 4 张；
`MASK_UUID` **保留四张完整目录** ⇒ 宏改回 `null` 时宿主零改动。`TINT_MASK_GAUGE_PIN` 住 `tuning.ts` 并明写「临时接线，⛔ 非 §3 冻结数值」。

**新门禁 = 把"静默降级"变成可见**：`tools/scripts/check-cocos-mask.mjs`（`pnpm run check:cocos-mask`，挂 verify 第 **21** 项，`check:size` 之后）。
无产物 ⇒ `STATUS: SKIP`（同 `check:size` BD-18 体例，⛔ 当通过）；缺张 ⇒ FAIL 并打二选一出路。**负腿必测**：`--pin=null` ⇒ 需求集 4 张 ⇒ 两张报 `❌ 不进包` + exit 1。

**⛔ 本批拒写的东西**：`loadBundle` 分支（编辑器动作未落地 = 无产物可验的预见代码，只在载体头注留两种形态的说明）；
holeless↔holed 像素 A/B（宏生效期两档恒同一张图，无从对比）；手编 `.meta`（L1）。

**读数**：beads **808 + 1 skipped**（改 1 条现役宏语义 + 新增 2 条：宏两态 / 需求集两态）· `typecheck` ✅ · `cocos:check` 2/0 ·
`framework:sync` 写 0 / 未变 100+69（镜像已一致）· 收口 `verify` **PASS 21 / WARN 0 / SKIP 0 / FAIL 0**。⛔ 未 commit。

**未完与解除条件**：① **④ 真正落地 = 一条编辑器动作**（`assets/textures` 标 bundle，或给 `holeless` 补一条构建期引用）⇒ 之后 `TINT_MASK_GAUGE_PIN → null`
复跑门禁验 **4/4**（bundle 路线需把加载面改成 `assetManager.loadBundle(⋯).load(⋯)`；补引用路线宿主零改动）；
② 本批**未重新构建产物** ⇒ 宏的运行效果未在构建档/真机跑过；③ **① 层序真因**已确诊 = 一块 `Graphics` 同时装「盘面底板（须在珠下）」与
「三处全屏遮罩（暂停/结算/庆祝，须在珠上）」⇒ 插入序必错一侧，真解是把底板整块挪出 `Graphics`（= L0 本体）；④ S3 两端对拍、`[R]` 上机按路径推进。

**三十五批·补刀（2026-10-05 · ④ 路线拍板，撤销「⛔ 不预写 `loadBundle`」那条取舍）**：用户问「标 bundle 是 Cocos 还是微信的要求」⇒ 结论 = **纯引擎侧**（Creator 构建系统：bundle 目录全量收录、不看引用），微信只管已产出东西的摆放（主包 ≤4 MB / `game.json subpackages`）。用户择一 **Bundle 路线**，否决「逐张补构建期引用」（每新增一张纹理都得再挂一次材质，不自然）。官方口径：Bundle 是**目录级**配置，压缩类型默认「合并依赖」⇒ 输出为主包内本地目录 `assets/<bundle>/`；⛔ 只有选「小游戏分包」才挪进 `subpackages/`（那才第一次撞微信规则）⇒「打进主包」≠「微信分包」，别混。
落码：`MASK_UUID` → **`MASK_ASSETS`**（`uuid` + bundle 内 `path`）；`loadImageAsset()` 两腿 = `loadBundle('textures').load(path)` 优先 ⇒ 回落 `loadAny({uuid})`（编辑器动作落地前这是**唯一能跑的腿**，所以不是预见代码），哪条生效打日志；门禁改**逐 bundle 扫**（只扫 `main/` 会把已落地误报成没进包）。**还差你一步**：编辑器选中 `assets/textures` → 勾「配置为 Bundle」→ 名称 `textures` → 压缩类型保持默认（L1 禁手编 `.meta`）。读数：`cocos:check` 2/0 · beads **808 + 1 skipped** · `framework:sync` 写 0 · 门禁双腿（在册 `OK` / `--pin=null` `FAIL` exit 1）· `verify` **PASS 21 / FAIL 0**。沉淀：**K-108 修改**（补第 ⑤ 条：出路两层 + Bundle 化的加载面/门禁连带）。⛔ 未 commit。

**三十五批·收口（同日第三刀 · 用户回话「做完」）**：Bundle 已在编辑器配好（`assets/textures.meta` 由编辑器写 `isBundle: true, bundleName: "textures"`，⛔ 非手编）。本侧 `pnpm -C games/beads run build:cocos`（wechatgame debug，27.6s，编辑器 MCP 同时在线不冲突）⇒ 产物新增 `assets/textures/`：`holeless` 两张进 `native/{dc,f8}`，`holed` 两张仍在 `main/native/{cb,a6}`（被 `.mtl` 引用，PNG 字节不重复）⇒ **门禁不再需 `--pin`，在册即 4/4 ✅**（逐 bundle 扫这一步真的救了一次误报）。⇒ `TINT_MASK_GAUGE_PIN 'holed' → null`（接线拆除、留作 A/B 旋钮；头注改写并把 `bead-tint-arm.test.ts` 三条断言按新语义改写、harness 预热注释回到 4 id = 40 张预算顶格；顺手修掉头注里一处 `check:cocos-masks` 笔误）。读数：`framework:sync` 写 1 · beads **808 + 1 skipped** · `verify` **PASS 21 / FAIL 0**。⛔ 未 commit。**下一刀 = WXG-T-256（① S5′-3 层序：把盘面底板整块挪出 `Graphics`）**；仍未跑的是构建档/真机 `carrier=on` 观感（holeless 小豆档 A/B 是债）。
