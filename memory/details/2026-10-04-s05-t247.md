## 二十七批 · 第七刀：§19.1 落正本 + 三臂同宿主真 GPU 实测出数（2026-10-05 → 10-06 · WXG-T-247 S0）

用户三连令：① 「§19 例外**现在就**落 control-manifest 正本」② 三臂优缺点 / 推荐 / 是否有更优方案 ③ 「**实现后两个方案并打印真实性能数据做对比后选择**」
⇒ ③ 解除前几轮「只出文档零实现」约束（仅限 S0 取证面：`?bench=1` 门内 spike + 一个驱动脚本；⛔ 不进生产路径、不进框架镜像）。

**1) §19.1 已落正本**（`control-manifest.md:343`）：四条边界逐字从 ADR-0030 附录 A 入表，并明写「跟「128 唯一档」走、不跟载体走」
⇒ S5 硬前置的**文书半边**解除；S5 仍须过 `TC-TINT-18`（本例外只解「放大」半，不解「投放位图」半）。

**2) 取证通路（全部实证，可复跑，不靠真机不靠人点击）**：`build:cocos:web`（Cocos Creator 3.8.8 CLI，web-mobile debug，12.5 s）
→ `node:http` 静态服务 + `/mask-assets/` 只读白名单（绕开未进 bundle 的 `loadAny`）→ playwright chromium（**必须 `--use-angle=metal`**）
→ 页内 `__BENCH` 三臂探针。**四轮测量缺陷修复**（每个都是「读数看着正常但是假的」）：
① **取错对象层**：`app.game` = BeadsShell，`snapshot`/`setZoomForDebug` 在 `shell.play`（BeadsGame）⇒ 冒烟 `filled 0 / zoom 恒不变` 且不报错（K-099）；
② **GPU 计时两阶段坑**：先误用 `gl.RESULT_AVAILABLE_EXT`（undefined）；更致命 = Chromium 的 `EXT_disjoint_timer_query_webgl2` 扩展对象上**没有 `TIME_RESULT_EXT`**，
实测原型只有 `[QUERY_COUNTER_BITS_EXT, TIME_ELAPSED_EXT, TIMESTAMP_EXT, GPU_DISJOINT_EXT, queryCounterEXT]` ⇒ target 必须 `TIME_ELAPSED_EXT`，否则 `INVALID_ENUM 1280` 读数恒空；
结果读取走 WebGL2 核心枚举 `0x8867/0x8866`；为此加了驱动器 `--diag` 单发自检口（K-098）；
③ **`gl.finish()` 抽样在本宿主读 ≈0 = 无判别力**（降级保留但明写「不是等价降级」）；④ **`setArm` 竞态**：`this._arm = arm` 写在 `await ensureMasks()` 前
⇒ await 窗口内 `_c2d` 为 null 就被 `_draw` 使用（`null.draw`）⇒ 改为「先备资产、最后改 `_arm`」（K-100）。
另新增两项测量能力：`chg`（模型签名变化数，放在计时之后不污染 `drawMs`）与 `--disturb`（每帧 `±0.004` zoom 抖动 ⇒ 全盘几何每帧变）。

**3) 关键读数**（frames=150 warmup=40，`[E]` Apple M4 / dpr 2 / backbuffer 824×1830；完整表见 ADR §5.0.1）：
- **V 矢量**：CPU **3.0–3.9 ms**（= C/A 的 3–4×，且唯一**随 zoom 上升**：tris 37170→55145）、GPU 1.79–2.78 ms、dc 14/15；
- **C 丙′**：CPU 0.6–1.0 ms、GPU 0.71–1.40 ms、**dc 2**、**tris 182**、上传 0.2–0.4 ms、**每帧 6,031,680 B**（≈ 5.75 MiB）；
- **A 甲′**：CPU 0.8–1.1 ms、GPU 2.0–2.8 ms、**dc 16**、tris 3354/3137、图集 **7 格**、280 Sprite 节点、**零每帧上传**；
- **`chg` = 静置 3–4/150 vs disturb 150/150**；三臂 `frame p50` 恒 ≈16.7 ms（vsync ⇒ 无判别力）；两轮复跑同向。

**4) 推荐（数据侧，本批未代用户改裁 DEC-1）**：
① **先做跟载体无关的「脏帧门控」**（静置期三臂都在每帧无效重放：V 白烧 3 ms/帧、C 白传 6 MB/帧）；
② **主选 甲′**（无任何未证平台能力 + 零每帧上传）；③ **丙′ 降第二候选**（本档最快但 S0-1 二值门 `wx.createCanvas` + canvas→纹理未过，⛔ 不得由 `[E]` 外推）；
④ **更优形态 甲″** = 静态底图烘纹理 + 珠层 Sprite 池 + UI 层 Graphics（目标 dc 16→≈ 3）。
**口径陷阱已写进结论 8**：tint 运行时把 12 命令/珠压成 1 blit ⇒ `cmds 2031→479`，故 **V↔C/A 混有「换模型」收益，只有 C↔A 是纯载体对比**。
**H-FILL 本档判不了**（三臂 GPU 不随 zoom 变，M4 远未 fill-bound）⇒ 不得据此说「填充不是瓶颈」。
