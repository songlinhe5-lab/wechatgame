## WXG-T-214 r6 批：六裁「孔径 = 真透的区域」—— holeRatio 语义回正 + facet-4 孔拆两枚（Qoder 主理人会话）

- **用户原话**：「`BEAD_DRAW_INSET 是包括真透的区域，孔径是真透的区域`」⇒ 这不是调值，是**改口径语义**：
  珠面 26 含孔区，`holeRatio` 派生的**孔径 = 真透圆**（底色实际透出），墨环**外扩吃珠面**。
  四裁的「外缘制」是对这条语义的误读（它把 ratio 钉在描边中心线上），本裁回正。
- **值**：`holeRatio 0.538 → 0.4615`（= 12/26 精确）⇒ 恒等档 `round(26×0.4615/2)=6` ⇒ **真透 ⌀12 / 外缘 ⌀14**，

  J4 取整对象改回**真透半径**（⇒ 真透恒偶，外缘 = 真透 + 2×1dp 同偶）。
- **连带结构变更（本批真正的代价）**：旧 #6 单命令 `fill+stroke` 表达不了「底 = 真透 r、环 = 外扩 r+1」
  ⇒ facet-4 孔拆为 **stroke-only 孔环 + pit 孔底**两枚同心圆 ⇒ **层集 6 → 7 命令**（= C7 上限**压线、余量 0**，
  后续再加任何图元必触 C11）；`contract.ts` 的 `circle.fill` 转**可选**（rect/polygon 仍必填，⛔ 不引入 `line` 图元）。
