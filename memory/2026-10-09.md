
### 限色口径拍板：产出 = N 或 N−1（beads-gen.mjs）

- 用户拍板「输入框设定 N，实际用色应是 N 或 N−1，不允许别的结果」。排查发现两个真 bug：
  1. **separateAdjacent 无 allow 保护**（统一根因）：相邻格 ΔE 去噪在全色板取色 ⇒ 复活禁用色，实测 --colors 4 出 8 色、设定 8 出 9 色。修复：加 allow 白名单参数，调用点传 allowSet（与 balance 同源）。
  2. 候选缩水：k-means 簇吸附品牌色去重后 kept 可能 << N。修复：每簇贪心取「最近且未被占用」品牌色（nearestLabFreeIdx），簇心互异 ⇒ 候选 = N 或 N−1。
- **用色保底**：全部改色步骤后，若实际 < N−1，把改判代价最小（格均色 Lab² 差）的格换判给 0 格候选；ΔE>25 弃置防毁图。弃置欠额写 report.colorShortfall+shortfallNote（图像可达色数不足 = 源图极限，如实标注不强塞）。
- 验证（14×13 测试图）：4→3、8→7、12→10（欠额 1 = 图像极限，87 格单色区 67 格）；mis=full 回归 8→7、错位 87 正常。
