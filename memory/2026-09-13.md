## ADR-0010 完成（08:20，WXG-T-034，engineering-lead-4）

**结论：用户方案 D（my-plugins 符号链接→四 IDE 各自加载）字面不可行**——四 IDE 插件机制互不兼容且全为注册表/缓存制（CodeBuddy=plugin.json+marketplace、WorkBuddy=marketplace 键控用户级缓存、Qoder=只读已装目录、Cursor 无本地目录插件加载），符号链接进 `.cursor/.qoder` 不会让任何一家加载插件。my-skills 模式成立的前提（明文 Markdown、无加载注册表）对插件不存在。

**推荐 C+D'**（ADR 落 `docs/architecture/adr/ADR-0010-weixin-minigame-helper-integration.md`，Proposed 待批）：
- 能力层：官方 MCP 包**版本锚定 0.1.13 禁 @latest**，根 `.mcp.json` 一份覆盖 **CodeBuddy+Qoder**（两家共读同一文件，关键发现）、`.cursor/mcp.json` 覆盖 Cursor、WorkBuddy 沿用用户级插件（唯一例外，已装）
- 知识层：my-skills/weixin-minigame-helper 改名改造为 **`wxgame-minigame-bridge`**（消同名双注册 + 防漂移 + 写仓库适配：入口=构建产物、Cocos 构建前置、MCP-first 不复制工具表）
- 治理层（D'）：`my-plugins/` 最小形态 = vendor 留档 + 版本锚定 + CodeBuddy 本地 marketplace 可选通道；不自研 MCP 如实否决（上游 3 个月 8 版）
- 实测：npm latest 0.1.13（2026-04-23 发布）；CodeBuddy `mcp add -s project` / `plugin marketplace add <本地路径>` 均有文档实锤
- 风险上报：能力被双前置卡住（AppID+私钥+IP 白名单、Cocos 构建链未通——集成≠可用）；npm 包无 repository 字段（供应链面）；与 Cocos MCP 端口冲突待实测；插件 hook/agent/commands 在本仓库全弃用
