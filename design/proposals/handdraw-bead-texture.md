## 调研结论：程序**能**画出手绘质感（对比稿四档验证）

| 档 | 手法 | 观感 |
|---|---|---|
| A 现状 | 纯几何 + 1px 同色自描边 | 干净「塑料感」 |
| B 粗手绘描边 | 描边 `0.11×R` + **轮廓顶点随机抖动**（14 边形近似圆，顶点 ±4.5%） | 立刻手绘感，远看不糊 |
| C = B + 噪点斑 | 每珠 5 个伪随机深浅斑（压暗 16% / 提亮 12%，α≈0.3） | 蜡笔颗粒感 |
| **D = C + 双色区带** | 对角渐变（左上提亮 / 右下压暗，模拟邻珠阴影斑驳） | **最接近参考图** |

⚠ 描边色用**深绿**（`#2a4630`）而非纯黑——首版用近黑在远看时糊成色块（已实测踩坑）。

## 三手法与工程要点

1. **顶点抖动描边**：`circle` → `polygon` ⟹ **图元数不变**，封箱压力最小
2. **噪点斑**：每珠 +5 `circle` ⟹ 满盘 156 珠 ≈ **+900 图元** ⟹ 需重算静态基线四口径
   （①~④）+ 过封箱复评（T-211 体系，流程有先例）
3. **⛔ 帧一致性硬约束**：所有随机必须 `seed = 格坐标`（mulberry32 等确定性 PRNG），
   **绝不可用 `Math.random()`**——否则每帧闪烁，LOD/帧一致判据直接爆
