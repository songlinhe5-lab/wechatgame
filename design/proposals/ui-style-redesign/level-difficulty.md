## 1. 定位与消歧（先钉死，防后文漂）

### 1.1 「图元」有两种，本文件管第一种

| 词 | 本文件含义 | 归属 |
|---|---|---|
| **图元 P（Piece）** | **一关的可填格数 `N`** —— `pattern` 中非 `.` / `x` 的格数 = 一关的珠数 = 「这张图有多少元件」 | ✅ 本文件 §4 的线性律对象 |
| 图元（渲染义） | 渲染命令数（draw primitive） | ⛔ 不是本文对象；它在 `risks.md` K-6 / K-051 项下由落码批差分复算（招牌与缩略的珠数线性增长） |

> 用户原话「图元在同类型内，按照难度线性增长」中的「同类型」= 同一**类别**（`menu-architecture.md` §4 的丙案 = 难度带）。本文件按此读法落公式。

### 1.2 难度分只管「序」，不管「价」（关键边界，不得越界）

| 量 | 是什么 | 真源 | 用途 |
|---|---|---|---|
| **`DI`（难度分）** | **结构难度分**，单位 = 「等效错位珠数」 | **本文件 §3**（先验、零实测、可落码） | ① 陈列序 ② 类别分带 ③ 生成期目标反解 ④ 单调/无退化守卫 |
| `steps`（实测批量动作数） | 真引擎实测 BAC 动作数 | `tools/scripts/beads-bot.ts` | **定价**：`T₁ = clamp(steps × SEC_PER_STEP, 30, 2500)`（§3.5 v1.50）+ 规模闸（§3.13） |

> **⛔ `DI` 不得用于定价。** 依据（不是本单发明，是 §3 已有教训）：§3.5 明写「`SEC_PER_STEP` 仅当**新关先验**……八关实测残差仍达 ±29%」；§3.13 明写静态闸（曾拟 `M ≤ 280 ∧ B_med ≥ 8`）**经实测证伪并删除**，理由是「静态量无分辨力、用作闸纯误伤」。本单 §5.3（H-3）用自己的数据复核了这条：**先验公式对 `steps` 的绝对预测残差最大 ≈ +102%（L00001）／最负 ≈ −59%（L00005），极差 ≈162 个百分点**（n=9，2026-10-10 换盘后新池）。⇒ 只敢用作**序**。
>
> ⚠ **口径写死（换盘后新加，防第二把尺子，判例 K-012）**：取池内比值 `k = mean(DI/steps)`（新池 k = **1.571**）作**唯一**标定常数，逐关残差 = `|DI/k − steps| / steps`。同一口径下旧池为 +33%／−27%、极差 ≈60% —— 原稿那句「≈58%」正是这个量级，但**未写推导、所引的「§5.4」在本单从未存在**（悬空引用，本次一并订正为 §5.3）。
>
> 反向也不成立：实测 `steps` **不能**代替 `DI` 做陈列序 —— 新关入关时 `steps` 可能尚未跑 bot（§3.13「bot 不可用 ⇒ 500，不回落静态估算」）⇒ 陈列序会开天窗。

## 2. 输入变量（逐项定义 + 口径）

| 变量 | 定义（可落码） | 域 | 方向 | 备注 |
|---|---|---|---|---|
| `N` | `pattern` 中非 `.` / `x` 的格数（**= 图元**） | `[1, GRID_MAX_COLS × GRID_MAX_ROWS]` = [1, 1024] | ↑N ⇒ ↑DI | 受 §3.3 `GRID_MAX_COLS/ROWS` 32 管辖 |
| `M` | 错位珠数（`misplaced` 行串中非 `.`/`x` 的格数） | `[MISPLACED_PAIRS_MIN, N]` = [1, N] | ↑M ⇒ ↑DI | §3.13 `MISPLACED_PAIRS_MIN = 1` 是 swaps 型下界；misplaced 型由 BOOT「错位 ≥1」管辖 |
| `ρ` | **错位占比** = `M / N` | `(0, 1]` | ↑ρ ⇒ ↑DI | ⚠ **现池 9 关恒 = 1.000（零方差）** ⇒ 对现池无分辨力（§5.3 诚实登记） |
| `C` | **用色数** = `pattern` 中出现的不同色索引数 | `[1, BEAD_COLOR_MAX]` = [1, 35] | ↑C ⇒ ↑DI | 上界引 §3.2 `BEAD_COLOR_MAX = 35`；语义 = 色索引基数，非候选色板规模（§3.2 v1.55 语义） |
| `A` | **同色相邻率** = `adjSame / adjTot`（4-邻域，只在可填格间计） | `[0, 1]` | ↑A ⇒ ↓DI | 变量沿用 §3.5 v1.38 三维度估算的自变量名（`levels-spec §5.0` v0.1，公式已作废、**变量集沿用**） |
| `K` | **碎片度** = `1 − A` | `[0, 1]` | ↑K ⇒ ↑DI | `A` 的补数，只为让公式单调方向统一 |
| cols × rows | **盘面尺寸** | ≤ 32 × 32 | **约束项，非 DI 自变量** | 它已经通过 `N ≤ cols×rows` 与 §3.3 顶格档（`c_max = 20`）进入约束；**不重复计入** `DI`，否则大盘被二次惩罚 |

> **为什么 `steps` 不是输入**：`steps` 是**结果**不是结构属性，且需跑引擎 ⇒ 会让 `DI` 失去「先验」性质（新关入关即要能排序）。

## 3. 公式本体（固定、可落码）

```
DI(level) = round10( M × f_C × f_K )

  M   = ρ × N                                      错位珠数（ρ = M/N，实测直读时 M 优先）
  f_C = clamp( 1 + c_C × (C − C_REF),  FC_LO, FC_HI )      色数难度因子
  f_K = max( FK_FLOOR, 1 + c_K × (K − K_REF) )              碎片度难度因子
```

### 3.1 系数与常量（**全部为设计锚定值，非回归拟合值** —— 理由见 §3.3）

| 常量 | 值 | 语义锚（为什么是这个方向/量级） |
|---|---|---|
| `c_C` | **0.10** | 每多 1 色，等效错位珠数 +10%。锚 = §3.13「k 相同下**长环**的心理难度 > 多个独立短对换」：色数 ↑ ⇒ 同色可用落点变稀 ⇒ 追踪链变长、找色成本 ↑ |
| `C_REF` | **5**（⛔ 未动） | 语义锚 = **「入门图」锚**，使小色数图 `f_C < 1` 得到折扣。⚠ 原理由句「现池色数中位数（C 实测 3/5/5/6/7/7/7/7/8 ⇒ 中位 7）」是**换盘前旧池**的事实；新池 `C ∈ {3, 4, 6}`（中位 **4**）⇒ 「现池中位数」这半句已失效、**如实划掉**，但 `C_REF = 5` 与全部系数一字未动（动它 = 改公式 = 全表 `DI` 变，本单无权也无需动） |
| `c_K` | **1.60** | 碎片度每高 0.1，等效珠数 +16%。锚 = 组批量机制（T-186 组归位 / `tray:selected` 组选）：**同色聚块 ⇒ 一次选择可批量落多颗** ⇒ 步数显著下降；碎片 ⇒ 逐颗周转 |
| `K_REF` | **0.50** | 中间锚（碎片度中位），使聚块图 `f_K < 1`、碎片图 `f_K > 1` |
| `FK_FLOOR` | **0.35** | 防退化地板：`K → 0`（近纯色块）时 `f_K` 不得归零（否则 `DI = 0` = 无难度 = 退化） |
| `FC_LO` / `FC_HI` | **0.60** / **2.00** | 色数因子钳位；`C = 1` ⇒ 0.60，`C ≥ 15` ⇒ 2.00（**外推区未实测**，见 §8） |

### 3.2 取整口径（必须逐字一致，否则跨端漂移）

| 步 | 口径 |
|---|---|
| `A` | `Math.round(A × 1000) / 1000`（三位小数） |
| `K` | `1 − A`（三位） |
| `f_C` / `f_K` | `Math.round(x × 1000) / 1000`（三位） |
| `DI` | `Math.round(M × f_C × f_K × 10) / 10`（**一位小数**） |
| `N_target`（反解） | `Math.round(...)`（整数格） |
| 排序相等（tie） | **关号升序**（确定性、零 RNG，铁律 L4） |

### 3.3 ⛔ 系数为什么不用回归标定（诚实记录，防后人重算时误判）

在**当时那 9 关**上做最小二乘拟合可得 `R² ≈ 0.97` 的模型，但**最优解给出 `c_C = −0.065`（负数）**——即「色数越多越简单」，**物理上错误**（与 §3.13 长环结论相反）。根因：n = 9 且 `C` 与 `A` 在此样本内负相关 ⇒ 共线。

> ⚠ **换盘后诚实标注**：上述拟合**跑在旧池上，本单未在新池复算**（复算 = 重标定，属 §8 B-2 的待批动作）。已知新池的病理**换了方向**：`C` 与 `K` 在新池转为**正相关**（实测 r ≈ **+0.71**，旧池为负）⇒ 旧池那条「最优解给负 `c_C`」未必复现。**但裁定不变** —— 立论的结构性理由仍在（n = 9、`ρ` 零方差、因子共线风险），且换向后的共线同样会让拟合不可信，只是坏在另一头。

⇒ **本单裁定：系数由语义锚定（§3.1），拟合只用于事后**序**校验。** 校验结果见 §5.2（Spearman = **0.833**，2026-10-10 新池；换盘前旧池 0.933）。

## 4. 图元线性律（用户硬要求 b 的第二半）

### 4.0 Q6 裁定：**双轨 —— 门禁只锁单调（契约）· 生成器保留等差（默认实现，可配可替换）**

> **用户质疑（2026-10-07）**：「`DI_START / ΔDI` 为什么要固定？根据门禁，同类型里保证难度升序即可。」
> **裁定（接受双轨，但主客易位）**：
> **`DI_START / ΔDI` 从「门禁参数」降级为「生成器参数」—— 门禁判据不得引用它们。**

| 轨 | 是什么 | 锁什么 | 是否可改 |
|---|---|---|---|
| **校验器（门禁 G5 / G6）** | **契约** | 只锁 **同类别内 `DI` 严格递增（难度不断升级）**⟹ **⛔ 不设任何数值阈值**（第四轮终裁） | 改它 = 改契约，需走变更单 |
| **生成器（造关反解）** | **默认实现** | 用等差 `DI_target(d) = DI_START + (d−1) × ΔDI` 给 `N_target` 一个**确定解** | ✅ **可配、可整条替换**（换非等差曲线不被门禁拦） |

**为什么必须双轨（逐条，回答用户）**：

| # | 断言 | 依据 |
|---|---|---|
| A-1 | **纯校验器不够：造关要反解 `N_target`，必须有一个标量目标** | `N_target(d) = DI_target(d) / (ρ·f_C·f_K)`。若不给目标函数 ⇒ 生成器**无解**，只能退回「拍脑袋定 N」——那正是乱序的根源 |
| A-2 | **纯生成器（等差进门禁）过头：`DI` 是相对序，不是物理量** | §1.2 已证：`DI` 对 `steps` 的绝对预测残差 **最大 +102%／最负 −59%（极差 ≈162pp，n=9 换盘后新池；旧池同口径极差 ≈60%）**。把未标定的先验值**固化成硬公差** ⇒ 等于宣称「我们知道 45 分是什么手感」，但数据不支持 |
| A-3 | **解耦点（这是双轨的关键）** | 门禁**只判「严格递增」、不引用任何数值阈值**；生成器**只引用** `DI_START` / `ΔDI`。**两者零交集** ⇒ 改生成参数不会让门禁变红，改门禁不影响造关 |

**若坚持「纯校验器、不设等差」——造关取值法（用户要求的备选，本单给全）**：

| 法 | 怎么定 `N` | 代价 |
|---|---|---|
| **(a) 图元预算直定** | `N` 由**包体 / 时长 / 盘面容量预算**给出（如「第 d 关 ≈ 40d 格」），`DI` 事后算、只校验单调 | ✅ 更诚实（不假装有先验难度尺）；❌ 只保证「图元随难度**单调**」，**不保证等差** ⇒ 用户硬要求 b「线性增长」退化为「单调增长」 |
| (b) 区间插值 | 按关号把 `N` 线性插值到 `[N_min, N_max]` | 同 (a)；且 `N_max` 受 §3.3 `32×32=1024` 顶格约束 |

> ⇒ **本单不采纯校验器**：用户硬要求 b 原文是「图元按难度**线性**增长」，(a)/(b) 只能给单调 ⇒ **会削掉用户自己的要求**。等差是满足「线性」的**最小充分实现**，且它只在生成器里，不进契约 ⇒ 用户的实质关切（「别把公差锁死」）已被双轨完全满足。

### 4.1 正律（难度 → 图元）—— **生成器侧，默认实现**

在**同一类别（同类型）内**，钳定 `(ρ, C, K)` 三因子后，`DI` 退化为 `N` 的正比函数 ⇒

```
N_target(d) = Math.round( DI_target(d) / ( ρ × f_C × f_K ) )
DI_target(d) = DI_START + (d − 1) × ΔDI          // 类别内第 d 关的目标难度分（等差·默认曲线）
```

⇒ **`N` 与 `DI` 成正比 ⇒ 图元随难度线性增长**，斜率 = `1 / (ρ × f_C × f_K)`（格/难度点）。

> ⛔ **`DI_START` / `ΔDI` 不进门禁**（§4.0 A-3）。它们与 `menu-architecture.md §3.0` 同族 ⇒ **也必须可配**（用户 Q4 同族要求）：
> ```json5
> // levels-spec.md §5.0.x + tuning.ts（不进 §3）
> DifficultyCurveConfig = {
>   curve:       'arithmetic',   // ✅ 可配：'arithmetic'(等差，默认) | 'explicit'(逐档 DI 数组) | 'geometric'
>   di_start:    50,             // ✅ 可配：类别内第 1 关目标难度分
>   di_step:     45,             // ✅ 可配：等差公差（ΔDI）
>   per_category: null,          // ✅ 可配：{ [catId]: { di_start, di_step } } —— 按类别各设一组
>                                //   （Q6 选项③；因每类关数不固定 ⇒ 各类档数不同，共用一组 ΔDI 会让关多的类爬到天花板）
>   di_ceil:     null,           // ✅ 可选：目标曲线上限；null = 不设，只受 §3.3 盘面钳位
>                                //   （N ≤ cols×rows ≤ 32×32）约束 —— **本单不发明该数值**
> }
> ```
> **为什么 `per_category` 必须留口**：`menu-architecture.md §3.6` 已裁「每类关卡数**不固定**」⇒ 类别 A 有 7 档、类别 B 有 15 档，若共用 `ΔDI = 45` ⇒ B 的第 15 档 `DI = 680`，反解 `N ≈ 596`（此处因子前提 = §4.2 **旧池**锚点 `C=7, K=0.469` ⇒ `f_C·f_K = 1.14`），逼近 32×32 顶格 ⇒ **无余量**。⇒ 建议默认仍共用一组（零配置），**但允许按类覆写**。（换盘后补注：按 §4.2 **新池**锚点 `C=4, K=0.226` ⇒ `f_C·f_K = 0.506`，同一 `DI = 680` 反解 **`N ≈ 1344 > 1024` ⇒ 直接破顶格**，「无余量」的结论只会更硬。）

### 4.2 现池锚点下的示例线性律（**默认配置下**：`ρ = 1.000, C = 4, K = 0.226` ⇒ `f_C = 0.900, f_K = 0.562`；`di_start=50, di_step=45`）

> 锚点 = 2026-10-10 **新池**的中位 `C`（= 4）与中位 `K`（= 0.226）。换盘前此处取旧池典型值 `C = 7, K = 0.469`（⇒ 斜率 0.877、ΔN 39）⇒ 本小节整张表随锚点重算。

斜率 = `1 / (1.000 × 0.900 × 0.562)` = **1.977 格/难度点**（`f_C × f_K` = 0.5058）；取 `DI_START = 50`、`ΔDI = 45`：

| 档 d | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| `DI_target` | 50 | 95 | 140 | 185 | 230 | 275 | 320 | 365 | 410 |
| **`N_target`（图元）** | **99** | **188** | **277** | **366** | **455** | **544** | **633** | **722** | **811** |

⇒ **ΔN ≈ 89 格/档**（等差，公差 89；因 `1.977 × 45 = 88.97`，取整后逐档差**恒为 89**）。

- ⚠ **斜率对「现池锚点」极敏感**（旧池锚 0.877 → 新池锚 1.977，**2.26 倍**）⇒ 换盘把「一个难度点对应多少珠」整条换算都移走了。这正是 §4.0 把 `DI_START` / `ΔDI` 关在**生成器侧**、不写进契约的实证理由。
- ⚠ **同一等差在不同因子组合下画出的珠数可差 4.4 倍**：第 9 档（`DI = 410`）在新池 L00006 型（`C=3, K=0.104` ⇒ `f_C·f_K` = 0.293 ⇒ 斜率 3.41）上反解 **N ≈ 1400 ⇒ 直接破 32×32 顶格**；在 L00007 型（`C=6, K=0.602` ⇒ 乘积 1.279 ⇒ 斜率 0.78）上只要 **N ≈ 321**。⇒ 等差 `DI` 目标**不等于**等差图元，线性律只在「钳定三因子后」成立（§4.1 前提）。
- `DI_START` / `ΔDI` 是**生成期目标参数**，住 `levels-spec.md`（**不进 §3**，判例同 `PAUSE_PANEL_H`）；`[待拍板]` 见 §9。
- 反解结果须再过两道钳位：`N ≤ cols × rows`、`cols ≤ 32 ∧ rows ≤ 32`（§3.3），以及 §3.13 规模闸（实测硬拦）。
