## §1.1（自主件 L63–L70 原样搬入，零改字）

- **语义拆解**：拼豆 = 玩法（品类词，利于微信搜索）；**小铺 = 陈列／收藏的扩展空间**——不是「森林」那种场景叙事，而是「作品被摆上架子」的**容器语义**。
- **视觉落点（一句话）**：**把「铺子」做成一只木框橱窗：招牌（珠拼游戏名）在上，货架格位（陈列已完成图案）在下**，玩家进游戏第一眼看到的不是风景，而是「我的作品会被摆在这里」。
- **两处呼应，形成闭环**（线框见 `screens.md` S0 / S5）：
  1. **boot 标题页 = 铺面**：珠拼招牌「拼豆小铺」（`beadText`）＋ 下方木框橱窗内 **3 格货架陈列**已完成的珠拼图案缩略（首次进入时为空槽 → 用既有「虚线槽」语言，与托盘扩展行同源，零新语言）⇒「小铺」= 一个等着被填满的陈列架。
  2. **finish 通关画面 = 上架**：通关时把已完成的图案**逐格摆进同一只橱窗**（8/9 关缩略上货架，未通关格 = 空槽）⇒ 玩家在最后一屏看见自己的作品「上架」，命名语义在此闭合。
- **为什么与甲案自洽**：橱窗 = 木框（木＝可按的材质语义延伸为「可打开的陈列」）+ 纸底（纸＝承载），**不新增第三族材质**；陈列内容用既有珠体绘制，零美术文件。
- ⚠ **本条为本轮新增建议，非用户已裁项**：替换的是初稿「珠拼大树」主视觉（大树与「小铺」无语义关联，且大树是「森林」命名的遗留物）。是否采纳请主理人转达用户；**不采纳则 boot 主视觉维持「珠拼大树」**，其余定名内容不变。珠面 recipe 在两种方案下均不动。
- ⚡ **用户 2026-10-07 裁：本条作废，boot/主菜单按 T-266 作品墙方案执行**（招牌 + 木框橱窗 4×3 作品格 + 木主钮；本节正文保留作史证，修订归美术侧另批）。
