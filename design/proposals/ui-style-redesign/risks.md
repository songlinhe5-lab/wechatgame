## 2. 封箱基准（`tests/bead-style-seal.test.ts` 体系）会否被触发

- **珠面 recipe 不触发**：封箱夹具锁的是珠体风格命令流（恒等档、legacy-ten 臂、四棱刻面等），本批零珠面改动 ⇒ 珠面 seal 预期全绿。
- **整帧 provenance 会变**：`palette.background` / `panel` 等进 `setBackground` 与面板命令 ⇒ `s3_frame_recheck_N` 体系的两帧 sha 必然变化（先例 r20/r21 各触发一次复评：`s3_frame_recheck_13/15/16`）⇒ **落码批必须同批走封箱复评并登记新 provenance 键**，不得静默跳过。
- **色表锁**（见 R-6）：新增 10 个 UI hex ⇒ 锁条数 35→45 量级（精确数以落码实测为准 `[待实测]`）+ sha1 追改。

## 3. 包体影响

- 位图 +0、字体 +0（系统字体）、图集 +0 ⇒ 主包增量 ≈ 0 KB（业务代码增量数百字节级）`[待实测]`（以 `check-bundle-size.mjs` 实跑为准）。
- 图元增量：木按钮 sheen+底缘线 +2/钮、全帧最坏 +≈20 `[待实测]`（K-051：不得沿用纸面值，落码须差分复算）。
- **boot 页（D-3 采纳后新增）**：珠拼标题 + 橱窗陈列格**复用珠体绘制** ⇒ 位图仍 **+0 KB**，但**图元数随珠数线性增长**（4 字招牌 + N 格缩略）⇒ 实测归落码批，本轮不预支数值（K-6）。
- 性能：无新动画通道、无逐帧新分配；按下态是状态切换非 tween。

## 4. 设计风险（如实登记，不软化）

| # | 风险 | 缓解 / 回退杠杆 |
|---|---|---|
| K-1 | 奶白珠 `#FDF6E9` 对暖底 `#F1E8D8` 是 10 色最弱对（ΔL≈5.4%） | 真机判糊 ⇒ `bg_base` 一步加深 `#EDE2CC`（ΔL≈7.7%），单 token 改动 |
| K-2 | wood（暖棕）与珠色8 赭棕 `#A5652C` 同族 | 明度差大（wood L≈0.13 vs 赭珠≈0.22）+ 珠有高光/倒角/投影，形态不同类；`[待真机]` 走查「木钮不读作大珠」 |
| K-3 | danger 只许纸底的约束把「告急切纸底」做成状态翻转 | 行为 = 现行「数字/图标切 danger + 脉冲」的超集，B3 三通道不变；若真机判翻转突兀，回退 = 计时胶囊恒纸底（现状），LV chip 仍木→纸化即可 |
| K-4 | 「材质=可交互」语义对色弱玩家依赖明度差 | 木/纸明度差 ≈ 0.84 vs 0.13（灰度下清晰可辨）✓ 三通道（明度+材质描边+位置）成立 |
| K-5 | 暖底上白描边高光（珠面 L3b rim、纸卡边）视觉体系混杂 | 珠面不动项不受影响；纸卡描边为暖沙色非纯白，已错开 |
| **K-6** | boot 页「珠拼招牌 + 橱窗/陈列格」是 D-3 采纳后**新增的图元来源**，按珠数线性增长（非 UI 换肤的常量增量） | **本轮不给纸面估计值**：落码须按 K-051 差分复算并走封箱复评（§2）；若实测超基线 ⇒ 回退杠杆 = 陈列格 3→2、或标题改单色珠拼（单参数，不动珠面 recipe） |
