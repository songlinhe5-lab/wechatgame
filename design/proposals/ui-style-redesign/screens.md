- **区域职责**：上 2/3 = 主视觉（招牌 + 陈列橱窗，纯装饰、零交互）／下 1/3 = CTA 拇指带（唯一主钮）。
- **控件清单（全页仅 1 件）**：`btn_start` = T3 木钮 320×88，文案「开始拼豆」，热区 ≥88 ⇒ 触发**既有** `boot→playing` 相位转换（`state.ts::BeadsPhase` 已含 `boot`；`beads-game.ts:1886` 状态机以 `boot` 为初态）。**进关扣心逻辑归 `systems-index §3.14` 不变**，本页零新功能。
- **boot 页与后续相位的唯一关系**：`boot --(点开始)--> playing`。boot **不是** overlay、不进暂停栈、不提供任何第二出口（无设置/无选关——选关与设置归 shell 主菜单，`ux-spec §2`）；`playing` 之后的一切相位转换沿用现行状态机，本页不新增分支。
- ⚠ **与 `ux-spec §4` 状态矩阵的口径差（登记，不自裁）**：`ux-spec §4` 首行 = 「BOOT｜（无交互）｜读档分流｜玩法·普通」，即现行规格下 boot 是**自动过渡**。D-3 已裁要画这一屏，故本页的「点开始」属 **ux 侧待补行**（二选一：① ux §4 增行「BOOT·点开始 → 玩法·普通」；② 保留自动过渡、按钮作兜底）。落码前须由主理人转 ux 侧裁定，本文不代裁（登记为 `risks.md` R-12）。
- **`beadText` 点阵珠标题的接线约束（硬）**：
  1. **只复用珠体绘制**——调用现有珠绘制通道（与盘面/托盘珠同一 renderer），**不得改动珠面 recipe**：层集、系数、倒角/高光、风格池（`bead-visual-style-spec §12`）零涉；WXG-T-263 蜡笔质感同样不实施。
  2. **新增的只有数据**：4 字的点阵字模（布尔位表，字节级）⇒ 不是美术文件、不是字体文件，**位图 +0 KB**。
  3. **色值**：只从既有 `palette` 珠色取色，**不新增珠色**（色表锁口径见 `tokens.md` 表头警示与 `risks.md` R-6）。
  4. **封箱**：珠面 recipe 不变 ⇒ 珠面 seal 预期不触发；但 boot 帧进整帧 provenance ⇒ **落码须同批复评**（`risks.md` §2）。
  5. **不进玩法渲染路径**：`beadText` 只服务 boot 页，不参与 `buildRenderModel()` 的盘面/托盘命令流（L5 口径不变）。
- **橱窗主视觉**：取代初稿「珠拼大树」（理由：大树是「森林」命名的遗留物，与「小铺」无语义关联，见 `art-bible-proposal §1.1`）——**本轮新增建议·待确认**，不取则退回「珠拼大树」（同样复用珠体绘制，接线约束不变）。橱窗格不可点 ⇒ 不产生新功能、不产生新热区判据。
- **几何口径诚实声明**：boot 页**不在 `systems-index §3.1` 冻结带表内**（带表只管 playing 的 HUD/PUZZLE/TRAY/POWERUP），故本页的 y 值（980/930/560/380/140 等）为**版面建议值**，落码按屏内净空实测回填 `[待实测]`；**安全区与胶囊避让照冻结值执行**（`SAFE_TOP_H` 120 / `CAPSULE_AVOID`）。
- **动效（定稿）**：入场复用 `ux-spec §5`「面板入 200ms」scale 0.9→1.0 一次性；**本批零新增毫秒**，不设专属动效。
