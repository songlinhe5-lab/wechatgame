## 一、整体风格定位：「手作治愈系」（handcraft cozy）

| 要素 | 定义 |
|---|---|
| **核心概念** | 「玩家 = 手作匠人，盘面 = 作品台」——UI 不包裹游戏，而是**工作台本身** |
| **底色** | 奶油纸纹（`#f6efe2` + 低频噪点），替代现在的冷灰面板 |
| **容器语言** | **木牌**（HUD/托盘面板：木色渐变 + 深木边 + 木钉）+ **纸板卡**（道具/缩放：米白圆角 + 干草色描边） |
| **珠面** | 手绘蜡笔质感（WXG-T-263 D 档：顶点抖动描边 + 噪点斑 + 双色区带） |
| **点缀色** | 珠子高饱和色 = 唯一的鲜艳来源（其余 UI 全部低饱和木/纸色）⟹ 玩家的「作品」自动成为视觉焦点 |
| **字体** | 圆体/手写体倾向（实施时选可嵌入的免费商用字体，注意包体） |

**玩法表达三处**：
1. **标题文字用拼豆拼出来**（标题页）—— 玩法即品牌，一眼懂「这是什么游戏」
2. 对局页目标提示条：「🟢 把绿色豆豆放进同色空格」—— 每帧可读的操作语义
3. 虚线目标环（现有 hint 环语言）+ 「连对 3 颗有惊喜」的连击钩子文案

## 三、游戏名称备选（6 个，均含品类词利于微信搜索）

| # | 名称 | 理由 |
|---|---|---|
| 1 | **豆豆森林** ⭐推荐 | 树形关卡主题强关联；「豆豆」系列化潜力（豆豆海洋/豆豆星球）；叠词亲切 |
| 2 | **拼豆小铺** | 手作工坊温馨感；「小铺」暗示收藏/作品陈列的扩展空间 |
| 3 | **拼豆物语** | 治愈叙事向，适合关卡—章节—故事的包装 |
| 4 | **拼豆工坊** | 品类最直白，商店搜索最友好；略平庸 |
| 5 | **豆趣拼拼** | 叠词活泼，休闲向；「趣」点出休闲定位 |
| 6 | **颗粒成画** | 文艺差异化；牺牲搜索性换记忆点 |

推荐：**豆豆森林**（品牌与主题最契合，且给续作留出宇宙）。
