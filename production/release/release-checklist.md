# 发布清单（Release Checklist）· 《砖阵》Breakout

- 项目：微信小游戏矩阵 · 首款 demo `breakout`
- 版本：v1.0 · 2026-09-11
- 负责人：路远行（发布与 Live Ops）
- 适用发布类型：**首次提审发布（首发）** · 后续热修走 `rollback.md` 的简化流程
- 状态：**模板 / 待执行** —— 本仓库尚未接入微信开发者工具，本清单为「进入提审前的自检工具」，不是「本周会执行」的计划

---

## ⛔ 前置声明（务必先读）

> **`0.1.0` 是开发里程碑，不是可提审版本。本清单全部走完 ≠ 可以提审。**
>
> 当前仓库**尚不具备构建出微信产物的能力**（`tools/scripts` 构建脚本、`cocos/assets/scripts` 引导脚本、`dev/harness` 均未落地；微信开发者工具未安装），详见 §1.3 与 §1.4。
> 因此 **§7 的 Go/No-Go 当前判定为 `NO-GO`**。本清单是"将来工具链就绪后照做"的模板，**不是"走完即可上线"的承诺**。
> 后续任何人在此清单上打勾前，请先确认 §1.3「依赖与工具就绪」已全部通过。

## 0. 使用说明（先读）

1. 每项含四要素：**判据**（做没做到怎么算）、**负责人（角色）**、**证据形式**（留痕物）、**勾选框**。
2. 角色代号（不点个人名，点职责）：
   - `ENG` 工程（程基岩 / engineering-lead）
   - `QA` 质量（严守真 / quality-lead）
   - `DES` 策划（文策渊 / design-strategist）
   - `ART` 美术（林绘澄 / art-director）
   - `AUD` 音频（阮和鸣）
   - `OPS` 发布与运营（路远行 / release-ops-lead）
   - `LEAD` 主理人（游承峰 / team-lead）
   - `USER` 用户（最终决策人，掌舵）
3. **门控性质**：`🚦 门控` 标记的项未通过 → **不得进入下一阶段**（no-go），除非 `USER` 明确书面豁免。
4. **诚实约定**：带 `⚠️ 待核实` 的条目，指"需在官方渠道确认后才能定稿"，见 `wechat-submission.md`。

| ☐ | 🚦 功能范围与代码一致 | 已交付能力 vs GDD 无未登记漂移（见 §1.4 漂移登记） | ENG + DES | 漂移登记表 |
| ☐ | 变更日志就绪 | `changelog.md` 当前版本段落完整、玩家可读 | OPS | `changelog.md` |

### 1.2 包体预算核对（红线 vs 目标，分清）
> 口径权威来源：`games/breakout/design/gdd/systems-index.md §3.8` 与 `art/assets-spec.md §5`。

| ☐ | 检查项 | 判据 | 负责人 | 证据形式 |
|---|---|---|---|---|
| ☐ | 已知红线 | 主包 ≤ **4096 KB**；主包+分包 ≤ **30720 KB**（平台约束） | OPS | 本文 §1.2 |
| ☐ | 🚦 内部目标 | 主包合计 ≤ **2000 KB**（引擎 ≤1800 / 业务 ≤400 / 美术位图 0 / 其他 ≤100） | ENG | `check:size` 报告 |
| ☐ | ⚠️ 平台红线数值复核 | 上传前到微信官方文档确认当前主包上限（数值可能随版本调整） | OPS + USER | 官方文档截图/链接 |
| ☐ | 预算未越线 | 实际构建产物 ≤ 2000 KB；若逼近，记录原因与缓冲余量 | ENG | 包体报告 |

> **提醒**：4096 KB 是"不能越的线"，2000 KB 是"我们给自己定的线"。**程序侧按 2000 KB 做**，4096 KB 只作最后兜底。二者都对，层级不同，勿混用。

## 7. 门控汇总（Go / No-Go）

**进入提审的硬门控（全绿才 go）**：
1. §1.3 工具链就绪（typecheck / test / 构建脚本 / 包体脚本 / Cocos 引导 / 微信工具）
2. §1.2 主包 ≤ 2000 KB
3. §3.1 核心循环可玩 + 存档降级不崩
4. §3.2 真机运行通过
5. §4 主体/类目/资质就绪

**当前判定：`NO-GO`（未进入可提审状态）**
- 原因：构建脚本与 Cocos 引导尚未落地；微信开发者工具未安装；包体实测数据缺失。
- 这不是"质量不合格"，而是"**本轮目标就不是上线**"——本清单作为后续可执行模板交付。
