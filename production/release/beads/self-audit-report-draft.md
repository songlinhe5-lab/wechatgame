**二、内容自审情况**

本人已按照国家有关法律法规及微信小游戏平台规则，对本游戏的全部内容逐项自查，结论如下：

1. **玩法与美术内容**：本作为拼豆归位类休闲益智游戏 —— 棋盘上初始为**打乱位置**的彩色拼豆图案，
   玩家点选任一错位珠即选中「与该珠同色、8 向连通的整组」，再把这**一整组**归位到棋盘对应空格，
   系统按同色连通区域**批量填回**，逐步把整幅图案拼回原样以完成关卡。
   全部美术资源为原创或已获授权，不含他人商标、角色形象、影视 IP 等需授权内容。
2. **不含违法违规内容**：不含政治敏感、宗教极端、暴力血腥、恐怖惊悚、色情低俗、赌博博彩、毒品、
   教唆犯罪、人身攻击等任何违法违规或违背公序良俗的内容。
3. **不含用户生成内容（UGC）**：本作无玩家自由输入、无昵称展示、无聊天、无公会/社区功能，
   不存在玩家生成内容进入传播链路的情形。
4. **无诱导分享**：分享入口位于关卡结算面板，属**可选**行为；分享**不给予任何游戏内奖励**，
   不作为关卡解锁、复活、领奖的前置条件，不存在强制或诱导分享。
5. **无诱导消费**：本作**未开通虚拟支付**，无内购、无充值、无付费道具、无抽奖概率玩法。

**三、个人信息与数据**

1. 本作**不调用**微信登录、用户信息、用户云存储等接口，**不收集**玩家昵称、头像、手机号、地理位置、
   通讯录等任何个人身份信息。
2. 游戏进度仅保存在**玩家设备本地**（本地缓存），不上传服务器。
3. 本作不含服务器端业务接口，不涉及跨境数据传输与第三方数据共享。
4. 广告由微信广告组件（激励视频）提供，其数据处理遵循微信平台自身的规则与隐私政策；
   本作不自行采集、不二次使用广告相关数据。
5. 玩家可通过微信客户端清除本游戏数据，清除后游戏进度不可恢复（已在游戏内说明）。

**四、未成年人保护**

1. 本作**无付费功能**，不涉及未成年人充值消费风险。
2. 玩法为单人休闲益智，无社交、无对战、无陌生人互动。
3. 无连续在线时长强制要求，不设每日签到强制任务，不存在诱导未成年人沉迷的设计。
4. 广告展示由微信广告平台侧按平台规则过滤与管理。

**五、整改措施**

经上述自查，本版本未发现需整改的违规内容。本人承诺：后续版本迭代将持续执行同等自查，
新增玩法、美术、广告位前先自审合规性；一旦发现违规内容，立即下线整改并主动向平台报备。

**六、承诺**

本人承诺以上自审自查情况真实、准确、完整，愿承担因内容不合规所产生的一切责任。
