## 1. 逐项说明

### 1.1 正式 AppID（❌ 未取得；当前是小游戏测试号）

- **现状**：`wx8cf9f756e5390749` 的后台页面是「小游戏测试号」（只有开发者 ID / AppSecret / 服务器域名，无「设置 → 第三方设置 → 插件管理」）。测试号可 `cli preview`，但**不能授权 Cocos 引擎插件，也不能提审/发布**（2026-11-05 核实）。
- **AppID 不是单独申请的**：注册正式小程序/小游戏账号后由平台自动生成；测试号不能转为正式号，需新注册一个账号。
- **注册步骤**（官方入口 <https://mp.weixin.qq.com/>）：
  1. 「立即注册」→ 选择「小程序」；按 [小游戏接入指南](https://developers.weixin.qq.com/minigame/introduction/guide/) 选择「游戏」类目（部分入口直接写「小游戏」）。
  2. 填未被微信生态绑定过的邮箱、密码并激活；选择主体类型（个人 / 企业等）。
  3. 主体信息登记 + 管理员微信扫码；填写名称、头像、简介。
  4. 完成后在「开发 → 开发设置（或 设置 → 基本设置）」取得 **AppID**；AppSecret 同页，⛔ 只存本机、不入仓。
- **发布前还要办**：微信认证（企业主体，官方口径「企业主体必须认证才能提交小程序备案」）、**小游戏备案 + 小程序备案（ICP）**、类目与资质审核。本作按纯广告变现（IAA）准备：软著 + 游戏自审自查报告 + 备案；若以后开通虚拟支付（IAP），再补版号等。以官方 [IAA 指引](https://developers.weixin.qq.com/minigame/introduction/guide/) / IAP 指引为准。
- **拿到正式 AppID 后**：改本机 `games/beads/cocos/profiles/v2/packages/wechatgame.json` 的 `appid`（该目录 gitignore，不入仓）→ 重建 release → 在正式后台「设置 → 第三方设置 → 插件管理」添加 Cocos 引擎 → 复跑 `cli preview` / `cli upload`。
- ⚠ 测试号截图含 AppSecret，已提示重置；正式号 AppSecret 同样只存本机安全位置。

### 1.2 上传密钥 + IP 白名单（❌ 待办；正式 AppID 之后的硬前置）

- 位置：微信公众平台 → 开发管理 → 开发设置 → 「小程序代码上传」。
- 两件事：① 生成/下载**上传密钥**；② 把**当前出口 IP** 加入白名单（换网络/换机器需更新）。
- 纪律：密钥**永不入仓、不入对话、不进日志**（`control-manifest §10`）。
- 判据：`cli upload --project games/beads/cocos/build/wechatgame -v <版本> -d <描述>` 成功返回开发版。
- 官方入口：<https://developers.weixin.qq.com/miniprogram/dev/devtools/cli.html>（以官方为准）。

### 1.3 ICP 备案域名（❌ 无；首版不需要）

- 只在这些情况需要：公告走远端接口 / 热更下载 / 任何 `wx.request`。
- 硬要求（官方口径）：HTTPS；**不能**用 IP 或 localhost；域名必须 **ICP 备案**（新备案 24h 后才可配）；在「开发管理 → 开发设置 → 服务器域名」登记 **request 合法域名**；每月修改申请有次数上限。
- 本仓现状：`platform.ts::httpGet` 已支持 `wx.request`，但**没有任何调用方**；公告首版 = 本地随包（`src/config/announcements.ts`）。
- 官方入口：<https://developers.weixin.qq.com/doc/oplatform/developers/basic_func/domain.html>（以官方为准）。

### 1.4 云开发环境（❌ 未开通；可选）

- 适合：想让公告「不发版就能改」，但不想买域名/走备案。
- 好处：`wx.cloud.callFunction` / 云数据库走微信内部通道，**不需要配置服务器域名**。
- 前提：**正式 AppID**（当前只有测试号）+ 开通云开发环境（主体实名、计费与额度以官方为准）。
- 与远端接口的关系：公告条目形状不变（`{id,date,title,body}`）⇒ 换源只换读取方，面板与数据零改。
- 官方入口：<https://developers.weixin.qq.com/miniprogram/dev/wxcloud/basis/getting-started.html>（以官方为准）。
