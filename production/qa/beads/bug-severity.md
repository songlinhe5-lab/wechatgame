# 《拼豆填色消除》(beads) 缺陷分级定义 · Bug Severity

- 任务号：WXG-T-011 ｜ 作者：严守真 ｜ 版本 v1.0 ｜ 日期 2026-09-11
- 分级原则与报告模板沿用 `../bug-severity.md`（P0–P4 + 复现率/影响面/workaround/seed）；本文给出 **beads 语境的判定细则与实例**。所有示例引用 GDD 条目。

## 分级表

| 级别 | 定义（beads 语境） |
|---|---|
| **P0 Blocker** | 主链路不可用 / 崩溃 / 进度数据损坏；**事件驱动架构的关键事件漏发**；玩法真源被破坏（filled 可回退、locked 可填） |
| **P1 Critical** | 核心规则违反但可绕过 / 冻结与裁决语义错误 / 可访问性承诺未兑现 |
| **P2 Major** | 次要功能错误、统计口径偏差超容差、反馈噪声 |
| **P3 Minor** | 文案、动效毫秒级偏差、轻微排版 |
| **P4 Trivial** | 非承诺范围优化（backlog） |

## beads 专项判定细则（按系统）

### S1/S5 状态与裁决
| 场景 | 级别 | 依据 |
|---|---|---|
| `level:cleared` / `level:failed` **漏发或同帧误判 failed**（cleared 未优先） | **P0** | `core-loop §8.5`、`timer-gameover §8.4`（generosity 判例；同帧判 failed = 玩家通关被吞） |
| 归零不判负 / 或托盘满被误判负 | **P0** | `systems-index §3.5`（失败唯一条件 = 归零）、决策 D7 |
| 重试后五项重置缺一项（如扩展未回基线） | **P1** | `timer-gameover §2.4/§8.6` |
| 暂停期间计时/供料仍在走 | **P0** | `core-loop §8.7`、`timer §8.5`、F1 冻结补偿承诺 |
| 存档越界导致崩溃/卡死 | **P0** | `core-loop §8.10`（降级优先于报错判例） |
| 重复 `game:paused` 覆盖保存值（恢复后时间错位） | **P1** | `timer §8.9` |

### S3 网格（玩法真源）
| 场景 | 级别 | 依据 |
|---|---|---|
| **`filled` 格可被道具消除或回退** | **P0** | `bead-grid §8.6`、`§3.6`（已填格=玩家进度，不可回退） |
| **`locked` 格可被填入** | **P0** | `bead-grid §2.2`（locked 恒定，不参与转移） |
| `bead:placed` / `bead:rejected` 漏发、多发或 payload 缺 slot | **P0**（事件驱动架构：S4/S7 均以此驱动，漏发=状态失同步） | `bead-grid §8.2/§8.3`、`systems-index §4` |
| 同帧双落子两条都生效（重复计 placed） | **P1** | `bead-grid §8.7`（串行化裁决） |
| colorIdx 越界（0/99）导致崩溃或错填 | **P1** | `bead-grid §8.9`（防御性拒绝） |
| 锁定/已填格点击播放了错误反馈（噪声） | **P2** | `core-loop §6`（零噪声原则） |
| 13×12 极端关坐标偏差 >0.5px | **P2** | `bead-grid §8.8` |

### S4 托盘与供料
| 场景 | 级别 | 依据 |
|---|---|---|
| 满槽判负 / 满槽继续供料导致 13 颗 | **P0/P1**（判负=P0 破坏 D7；继续供料=P1 破坏容量不变量） | `core-loop §8.3`、`tray-spawner §2.2` |
| 供料节律偏差超 ±1 颗/60s 或间隔 >±0.1s | **P1** | `tray-spawner §8.1`（压力节拍器是支柱 2 载体） |
| `tray:full` 漏发 / 满槽期间每帧重播（告警刷屏） | **P1/P2** | `tray-spawner §8.4/§6`（允许去重） |
| 抽色权重偏离 3:1 超容差（如杂色吃掉一半供料） | **P1** | `tray-spawner §8.3`（±10pp）——直接破坏"轻策略"体验 |
| 落槽均匀性偏差 >±20% | **P2** | `tray-spawner §8.2` |
| 双击同珠产生两次 `tray:selected` / 双 selected 叠加 | **P2** | `tray-spawner §8.6`、`core-loop §6`（幂等） |
| 扩展跨关保留 | **P2** | `§3.4` A1（不跨关保留，终裁） |
| 道具清槽后 affectedSlots 与实际不符 | **P1** | `tray-spawner §8.10`（结算统计消费） |

### S2 输入
| 场景 | 级别 | 依据 |
|---|---|---|
| 面板打开时玩法区仍可点击（误落子/误道具） | **P1** | `input-control §2.3/§8.3`（门禁短路） |
| 重叠区命中非最近格心 / 带间隙误触 | **P2** | `input-control §8.4/§6` |
| 20 触摸/帧导致崩溃或事件错序 | **P1** | `input-control §8.10` |
| 多指引发缩放/旋转 | **P2** | `input-control §2.4`（只取第一触点） |
| `btn_expand` 热区未扩到 88 高（132×48 可点） | **P1**（C1 修正项未落地） | `accessibility.md C1` |

### 可访问性（横切）
| 场景 | 级别 | 依据 |
|---|---|---|
| `wrong` 描边闪 >2 次/秒 / 告急脉冲 >3Hz / 出现全屏白闪 | **P1** | `systems-index §3.8`、`accessibility.md D2` |
| 减弱动效开启后关停项仍播（抖动/脉冲/弹跳） | **P1** | `accessibility.md D1` |
| 减弱动效把"颜色/符号变化"也关了（命中反馈消失） | **P1** | D1 保留清单 |
| 灰度下 10 色不可辨（缺符号或明度档） | **P1** | `accessibility.md A1/A3` |

## 报告必附

- `rngSeed`（供料随机槽 / 随机消除均走 `services.rng`，控制清单 L4）；
- 事件监听计数器输出（涉及"恰 1 次 / =0"断言的缺陷）；
- 统计类缺陷附样本量与分布（TC-TRAY-02/03 类）；
- 环境（Node / DevTools / 真机 + 机型 + 基础库）。
