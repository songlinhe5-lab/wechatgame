# 《拼豆填色消除》(beads) 缺陷分级定义 · Bug Severity

- 任务号：WXG-T-011 / **WXG-T-084** ｜ 作者：严守真 ｜ 版本 **v1.1** ｜ 日期 **2026-09-14**
- 分级原则与报告模板沿用 `../bug-severity.md`（P0–P4 + 复现率/影响面/workaround/seed）；本文给出 **beads 语境的判定细则与实例**。所有示例引用 GDD 条目。
- **v1.1 背景**：本轮 G4 实跑（`g4-regression-report.md`）暴露出 v1.0 分级表的一个**结构性盲区**：全部细则都是「逻辑违反型」（事件漏发 / 状态可回退 / 计时跑动），**无一条针对「反馈不存在」** ⇒ BD-01/03/04 这类「整类反馈零实现」在字面细则下只能归 P2/P3，与实际影响（主链路不可用）严重不符。**v1.1 补「可感知层定级细则」与 BD-01..BD-26 登记表**。

## 分级表

| 级别 | 定义（beads 语境） |
|---|---|
| **P0 Blocker** | 主链路不可用 / 崩溃 / 进度数据损坏；**事件驱动架构的关键事件漏发**；玩法真源被破坏（filled 可回退、locked 可填）；**（v1.1 拟补，待主理人确认）关键反馈零通道**——玩法目标信息、操作即时确认、首屏可操作对象、死局出口 **四类中任一「整类不存在」**（区别于「毫秒偏差」或「噪声」） |
| **P1 Critical** | 核心规则违反但可绕过 / 冻结与裁决语义错误 / 可访问性承诺未兑现；**（v1.1 拟补）取证基础设施不可信**——使一整类用例结论不可信或使门失去发现能力（如坐标换算错位、构建阻塞、文档假绿） |
| **P2 Major** | 次要功能错误、统计口径偏差超容差、反馈噪声；**（v1.1 拟补）判据自身缺陷**（互斥 / 不可构造 / 容差不当）——不伤玩家但伤门禁可信度 |
| **P3 Minor** | 文案、动效毫秒级偏差、轻微排版；**文档数值陈旧但约束仍满足** |
| **P4 Trivial** | 非承诺范围优化（backlog） |

> **定级争议登记纪律（v1.1 新增）**：凡实际定级与上表字面不完全对应者，必须在缺陷单「定级依据」列**显式写明上调/下调理由**，并列入 §「待主理人确认的定级」表，**不得静默按感觉定级**。

### 可感知层（横切，**v1.1 新增** —— GAP-14 / BD-14 定级依据来源）

> 本节是本轮 **BD-01..BD-06 / BD-10 / BD-11** 定级的唯一依据。原则：**「整类反馈不存在」与「反馈参数偏差」必须分级**——前者使玩家无法完成核心动作，后者只是体验瑕疵。

| 场景 | 级别 | 依据 |
|---|---|---|
| **玩法目标信息零通道**：玩家无法从画面得知「哪格填什么色」（空槽无目标色/无幽灵符号） | **P0** | `assets-spec §1.2` `empty` 行（E1/E3/E4）+ `ux-spec §1-3` 裁定 (a) 引导通道 ①；**定级理由**：填色玩法的**唯一目标信息**不存在 ⇒ 玩家只能穷举试错 ⇒ 「主链路不可用」（叠加 A2/A2b/A3 承诺未兑现，本应 P1，被 P0 吸收） |
| **首屏零可操作对象**：开局 >1.5s 托盘仍空（无珠可选） | **P0** | `ux-spec §6.1`（1.5s = PLAYING 第 1 帧首珠已在托盘）；**定级理由**：微信首屏留存窗口直接失守，且使 FTUE 全部 Playtest 数据作废 ⇒ 「主链路不可用」 |
| **操作即时确认零通道**：落子/拒绝**无任何动效与音效**（不是毫秒偏差，是整类不存在） | **P0**（**定级上调，待主理人确认**） | `ux-spec §5` 四行 VFX + `audio-events §4` A05-01/05；**定级争议**：v1.0 字面把「动效毫秒级偏差」列 P3、「反馈噪声」列 P2——但本项不是偏差而是**整类缺失**，玩家无法判断操作是否生效 ⇒ 等价「主链路不可用」。**建议把「关键反馈零通道」补进 P0 细则** |
| **死局零出口**：尾盘满槽+死珠后画面上**不存在任何非「整关重置」出口** | **P0** | `ux-spec §4` 尾注（「这是判负，不是兜底」）+ `§8` U8；**定级理由**：玩家操作空间归零且无可点出口，只能等归零 ⇒ 「主链路不可用」。⚠️ **续时不算出口**（`REVIVE_BONUS_SEC` 只加时间不清托盘） |
| **引导零载体**：裁定 (a) 0 文字教学，但三条引导通道均未实现 | **P0** | `ux-spec §1-3` + `playtest-plan` 第 1 轮 FAIL 线（「3 秒看懂」<80% 即 FAIL）；**定级理由**：三载体分别由上表三项承担 ⇒ 引导路径**整体不成立** |
| **可访问性告急通道单靠颜色**（脉冲/图标未实现 ⇒ 色盲下完全不可辨） | **P1** | `accessibility B3`（已诚实标 ⚠️）+ `timer-gameover §8-10`；**定级理由**：「可访问性承诺未兑现」= P1；不阻断主链路（倒计时数字仍在） |
| **单一反馈形态缺失**（如 `hint` 态无承载体、无选中点网格无轻提示） | **P2** | `assets-spec §1.2` `hint` 行；`input-control §8-7`；**定级理由**：「次要功能错误」；⚠️ **但若 T-086 以 hint 为引导主载体，则随「引导零载体」升 P0** |
| **音频清单不闭合**（clip 数 < 规格要求）但**静音可通关** | **P1** | `audio-events §4` A05-23/24；**定级理由**：音频非通关必需 ⇒ 不上 P0；但「关键反馈视觉+音效双通道」红线与视觉同缺 ⇒ **叠加效应记入上表 P0 项的定级理由**，不重复计级 |
| **框架级取证能力缺失**（三平台 `NullAudioBackend`） | **P1** | 影响面为**全矩阵**（breakout 亦无声），且使所有 `[B]/[P]/[R]` 判据**不因真机到位而解除** |
| **文档假绿**：规格矩阵标「✅ 落地」但代码零命中 | **P1** + **另计流程缺陷 P0** | `accessibility` 矩阵；**定级理由**：单看每项 = 「可访问性承诺未兑现」 P1；但「同一类假绿**跨游戏重复四轮**」= **玩法真源被破坏的流程等价物**（门禁结构上无法捕获表现层缺陷）⇒ 另计 **BD-14 = P0（流程）** |
