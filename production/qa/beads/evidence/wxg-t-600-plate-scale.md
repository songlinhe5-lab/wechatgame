# WXG-T-600 · 木牌字号「像素级」复核（同尺归一后）

> **证据等级 = 实现自证**（`device-walkthrough §0-4`）：下面所有读数都来自「渲染模型 → SVG → 光栅化」，
> ⛔ **不是真机证据**，也不能替代浏览器/真机观感确认。它证明的是「代码画出来的字确实是这个尺寸」，
> 不是「玩家看到的就是这样」。

## 1. 要回答的问题

`WXG-T-599` 把木牌改成 关名 34 粗 / 次行 22 粗 / 胶囊 `130×27` 之后，**实际画出来**是不是就是这三个数，
以及和设计稿（402×146，胶囊宽 172）归一后还差多少。

## 2. 可复现步骤

```bash
# ① 十一帧渲染模型 → SVG（与金样本同源同种子）
node --experimental-transform-types --import=./tools/scripts/lib/ts-js-resolve.mjs \
     tools/scripts/render-ui-shots.mjs

# ② 只裁木牌区包成子 SVG（viewBox = x 245..505 / y 880..1010，y 轴为上原点）
#    然后 qlmanage 光栅化：750 宽 ⇒ scale = 750 / 260 = 2.885
qlmanage -t -s 750 -o temp/ui-shot temp/ui-shot/plate-crop2.svg
```

⚠ 不能对整帧 `main-menu.svg` 直接光栅化后量：`qlmanage -t` 只产**正方形缩略图**，整帧会被缩放，
读数全错（本次实测第一次就踩到，缩略图 750×750 里木牌已不是 1:1）。

## 5. 对照图（**本地产物，不入库**）

- 字身 → 墨高换算用系统中文黑体实测：粗体 ≈ **0.88 em**（40→35、34→31.6、22→20.2 三档同斜率）。
