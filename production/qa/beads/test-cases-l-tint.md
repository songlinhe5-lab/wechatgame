# §L · tint 臂判据（WXG-T-226/230 · 2026-10-07 判据裁定会并入；详细推导与盲区推导 = `wxg-t-228-tint-criteria.md §11`）

> **适用臂**：tint 臂（整盘单图元）。矢量臂仍走 C12/C7 现式，两式并存不互替。常量单一化：`MASK_SHAPE_OPAQUE_MIN = 250` / `MASK_SHAPE_AA_MIN = 5` 三处共同引用，⛔ 不得各写一份阈值。

## L.1 C12-t（主体色不变式 · tint 臂）

**统计域**：珠 mask 纹理像素的不透明芯 `B ≥ 250`。**逐像素出图色**：`(d,l) = (R/255, G/255)`，`out_c = base_c·d + (1 − base_c)·l` 逐通道（mask 侧零颜色 ⇒ 保持 V-1 mask-stable 红线）。**归桶**：端点集 `{base, lit, edge, pit, hole}`（`palette.ts::endpointOf`）求 RGB 欧氏最近 ⇒ 计数；最近距离 > 8/255 进 `unassigned` 桶打台面（不静默归桶）。**断言（弱读式）**：argmax ∈ 本格 base 同族端点集；占比分布表全量输出（C11）。**禁项**：⛔ 表外 mix 档不得入候选端点（否则恒绿，K-035 假绿谱系）。**已知盲区（结构性登记）**：`plate −0.44 ≡ pit` ⇒ D1 类编码渗漏在 C12-t 下归桶 pit（∈ base 同族）⇒ **结构性失明**——拦截职责 = TC-TINT-09（纯本色区面积>0）+ TC-TINT-19（四扇逐档），⛔ 不得以「C12-t 绿」叙述 D1 已拦（D1 本体已由 WXG-T-229 修复，本盲区防将来同类渗漏）。**判别力自证三臂**（K-060）：A 换他格 base 档必红且指认 / B 夺 argmax 的扇朝格心缩半必变 / C 合规正例不误伤。

## L.2 K3 改写（孔底透色 · tint 臂分述）

满豆有孔档孔为**真透孔**（J4 ⌀12）⇒ tint 臂孔底透出 **B0 tile `edge` 档（−0.30）**，非 `pit`（−0.44）；**矢量臂（legacy/LOD 回退）孔底仍 = `pit` live**。两臂差 0.14 档 = **已登记结构差异**（R-3），非缺陷。~~旧文：孔底 = 该格目标色 pit 档~~（矢量臂语境仍逐字有效，tint 臂按本条改述）。**引用面回写清单**：`bead-visual-style-spec §12.2 C5` / `test-cases §K K.5 行 10` / `TC-STY-07` 期望值分臂 / `assets-spec 7.11 行 6`（归属各正主，已挂账）。

## L.3 C7 拆分（配方复杂度门 + 运行时预算门）

**C7-a（沿用旧值，语义改写）**：统计域 = 层集配方侧；珠体命令数 ≤7 且真 α ≤2；语义 =「**配方复杂度上限**」——⛔ tint 臂下不再约束运行时开销，**不得再称「运行时开销门」**。**C7-b（运行时预算门，新值已裁 ①）**：统计域 = 整盘 RenderModel：① 每帧 blit ≤ 1/珠 ② draw call 增量 ≤ +1 ③ 三角 ≤ 2/盘 `[纸面·待复算]` ④ 真 α = 0。**判别力自证**（K-060，落码必交）：注入按格 blit ⇒ ①② 必红；纹理档位 128→192/256 归 `control-manifest §19`/art §4.3 D4 门，C7-b 不判。

## L.4 R-9 分域（AA fringe · 已裁 ①）

**芯区（B ≥ 250）**：保留 T1 原两线，按距轮廓分两子域——芯区-本体（距轮廓 >2px）：平均 ΔE < 2 + p95 登记；芯区-孔缘邻域（距孔缘 ≤2px）：ΔE < 5。**边缘带（5 < B < 250，已裁新值 ①）**：p95(ΔE) ≤ 12 · 单点 max ≤ 20 · **无振铃机械式**（法线方向局部极大值唯一 + 孤立 >20 像素距轮廓 ≤2px 判红 + ΔE 口径钉死 g4-probe 现役式，换式 = 换判据须重裁）。**后果句**：分域是换统计域非放宽容差；若坚持合并域 <5 ⇒ tint 路线不可能通过（等价否决，已被本裁定否决该路径）。
