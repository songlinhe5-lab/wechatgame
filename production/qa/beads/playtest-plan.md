## 0. 可执行性评估（v1.1 新增，WXG-T-084）

### 0.1 结论：**三轮均不可执行**

> 任务单问题：「现有 Playtest 计划在 GAP-05（静音）+ GAP-07（点不中）+ GAP-13（只到 L5）未修前能否执行？」——**答：不能，且阻塞项远不止这三项**。本轮 G4 实跑（`g4-regression-report.md`）证实：即使工具链全修好，**游戏本体也不具备被 Playtest 的条件**——因为玩家看不到目标色、开局 6s 无珠、零动效零音效。

| 轮次 | 可否执行 | 逐条阻塞项 | 若不修而强行的后果 |
|---|---|---|---|
| **第 1 轮 FTUE** | ❌ **不可执行** | ① **BD-01** 空槽无目标色 ⇒「3 秒看懂」必然 <80%，但这测的是**实现缺失**而非**设计失败**；② **BD-02** 开局 6.02s 无珠 ⇒「首次落子耗时 ≤15s」数据全废；③ **BD-03** 零引导载体；④ **BD-04/05** 零动效零音效 ⇒「拒绝反馈理解」无物可理解 | 得到一批**假阳性结论**：会把「实现未落地」误归因为「概念/设计错误」，可能误导回概念层重做 |
| **第 2 轮 心流与难度** | ❌ **不可执行** | ① **BD-06** 尾部软锁死 ⇒ 观测到的是**卡死**而非心流；② **BD-13** harness 只到 L5 ⇒ L6–L8 颜色数爬坡（7/8 色）不可达；③ **BD-07** 点不中 ⇒ 错误率（`bead:rejected` 频次）测的是**坐标错位**而非难度；④ 无埋点 | 「满槽频次 1–3 次为轻压力带」将测到 **满槽后永不恢复**；「难度倒挂」无法判定 |

### 0.2 BLOCKED 口径（**采纳并升级** `audio-spec §5`）

> `audio-spec §5` 明文：「任何 Playtest 报告**不得**对『解压/治愈』下 PASS 结论，只能记 **BLOCKED（音频后端未落地）**」。
>
> **本 QA 采纳并升级为双通道口径**：
>
> **【BLOCKED-双通道】本轮及波次 2 完成前，任何 Playtest 报告不得对以下四个维度下 PASS / FAIL 结论，只能记 BLOCKED：**
> 1. **「解压 / 治愈」**（支柱 1）——视觉通道（BD-04 四类 VFX）+ 音频通道（BD-05/05b）**同时为零**；
> 2. **「一眼读懂」**（支柱 1 / 3 秒看懂）——引导三通道（BD-01/11/10）全缺；
> 3. **「失败体验 / 重试意愿」**——BD-06 死局零出口，观测到的不是「归零挫败」而是「卡死无奈」；
> 4. **「手感 / 即时反馈」**——BD-04 + BD-16（无选中零轻提示）。
>
> **只允许下结论的维度**：计时冻结（F1，Node 层已可断言）、存档降级与续进（S8，Node 层已可断言）、道具规则理解（S6，事件层已可断言）——**且这三项应用 `[Node]` 自动化而非真人 Playtest 取证**（避免浪费样本）。

## 第 1 轮 · 新玩家首次体验（FTUE）

**目标**：验证支柱 1"3 秒看懂 + 治愈节奏"；观察教学零成本。
**样本**：4–6 名未玩过本作玩家（含 1–2 名休闲/非玩家）；只玩第 1–2 关。
**环境**：真机。

| 观察项 | 问法/埋点 | 判定线 |
|---|---|---|
| 3 秒看懂 | 玩前不给说明，90s 后追问"这游戏在干嘛" | ≥80% 复述出"把珠子填进图案" |
| 首次落子耗时 | 从进入 PLAYING 到第一次 `bead:placed` | ≤15s；>30s = 路由/引导问题 |
| 拒绝反馈理解 | 第一次 `bead:rejected` 后行为 | ≥80% 立即换颜色或换格（抖动+描边是否传达"颜色不对"） |
| 托满初体验 | 第 1 关是否发生满槽；发生时情绪 | 满槽不引发"我以为输了"误解（D7 沟通） |
| 首关时长 | L1 清关耗时 | 4–6 分钟带内（300s 档）；>7min = 颜色数/尺寸过大 |
| 再来意愿 | L1 结束后 | ≥3.5/5 |

**通过**：6 项达 5 项 → PASS；"3 秒看懂"或"拒绝理解"未达 → **FAIL**（支柱 1 核心受损）。

## 第 2 轮 · 心流与难度曲线（三旋钮）

**目标**：验证时间×空间双张力是否落在心流区；托满焦虑是否过度。
**样本**：5–8 名；连打至 L5 或自然失败 2 次。
**环境**：真机 + 埋点。

| 观察项 | 埋点 | 判定线 |
|---|---|---|
| **单关时长体感** | 每关清关/失败耗时 + 主观"感觉太久吗" | 客观 4–6 分钟/关；主观"刚好/还行" ≥70% |
| **满槽频次** | 每关 `tray:full` 次数 + 首次满槽时刻 | 每关 1–3 次为"轻压力"带；**0 次 = 空间压力未起效（供料偏慢），>5 次 = 焦虑过度（支柱 1 受损）** |
| **道具使用** | 清槽类道具使用率、使用时机 | ≥60% 玩家至少主动用 1 次；集中在满槽后 = 道具定位正确 |
| 颜色数爬坡 | 3→8 色各关错误率（`bead:rejected` 频次） | 随色数单调上升但不陡增；L5+ 错误率 <30% 落子次数 |
| 供料间隔体感 | 6.0→2.5s 档位主观压迫评分 | 压迫感递增但"想关掉"≤20% |
| 放弃点 | 哪一关/何状态退出 | 无单关放弃率 >40% |
| 难度倒挂 | 后关比前关显著更易 | 不出现（三旋钮单调） |

**通过**：时长带内 ≥6/8 关、满槽频次在带内、无放弃率 >40%。
**需调参**（回策划，QA 不定参）：满槽 >5 次/关 → 供料间隔上调或 `DECOY_COLORS_MAX` 下调；0 满槽 → 间隔下调；时长 >7min → 图案尺寸/颜色数回退一档。

## 第 3 轮 · 韧性 / 可访问性 / 中断恢复

**目标**：验证 F1 暂停冻结、D1 减弱动效、三重编码、杀进程续进。
**样本**：5–8 名 + 1–2 名色觉障碍/动效敏感玩家 + 低端机。
**环境**：真机（含刘海机、低端机）。

| 观察项 | 场景 | 判定线 |
|---|---|---|
| 暂停冻结 | 倒计时 <10s（告急态）暂停 60s | 恢复后 remaining 不变；期间零供料、零 tick（F1 承诺） |
| 告急可辨 | 色盲玩家在告急段 | 靠脉冲+图标可辨，不单靠红色（B3/§3.8） |
| 减弱动效 | 开启后打满一关 | 关停 5 项不播、保留 3 项仍在（D1 清单）；命中反馈不丢失 |
| 灰度三重编码 | 系统灰度滤镜 | 10 色 + 6 状态 100% 可辨（A1/A2/A3） |
| 杀进程续进 | L4 进行中杀进程 | 100% 续进已解锁最远关 |
| 存档降级 | 手工注入 `unlockedLevel=99` | 降级进第 1 关、不崩溃 |
| 低端机帧率 | L6+ 高密度 13×12 图案 | ≥30fps；落座动画不掉帧 |
| 热区 | 单手操作 | `btn_expand` 132×88 热区可稳定点中；相邻珠不误触（66²+8px） |

**通过**：续进/降级/冻结/减弱动效 100% PASS；灰度可辨；低端机 ≥30fps。
**FAIL 线**：任一续进失败或暂停跑动 → P0 Bug 阻断（见 `bug-severity.md`）。
