#### BD-61 配套机检门与生成器（2026-10-18 已落码）

- **生成器**：`games/beads/design/ai-workflows/quantize-cocos-textures.py`——从设计正本出投放件，配方 = **RGB FASTOCTREE(256) + 原 α 贴回**（⛔ 不再用 RGBA 八叉树，那正是塌缩源）。三种模式：`--selftest`（配方有效性断言：旧配方必须仍抹平、新配方必须保住 —— PIL 行为一变就红）· `--check`（全量体检，含「在册保持率」）· 点名件写盘（写后**回读逐位断言**）。写盘模式要求逐个点名，不给全量写盘（防误覆盖）。
- **门禁**：`tools/scripts/check-cocos-mask.mjs` 新增两条腿（均与产物无关，无产物也跑），已入 `pnpm run verify`。资产腿两条判据：**① 归属**（own ≤ 最近同尺寸他正本 + 2.0）；**② 互异保持率**（同族两态在投放件上的互异 / 正本上的互异 ≥ 0.5；真差 < 2.0 不判）。①单独用会误判（本单初版就这么错了一次），②才能抱住「量化把反馈吃掉」这类病。
- **第三条腿 = 产物等值（BD-61 收尾腿，2026-10-18 晚补）**：`cocos/assets/<bundle>/<path>.png` 逐件经 `.meta` 的 uuid 定位构建产物 `assets/<bundle>/native/<xx>/<uuid>.png`，先比字节 md5、不等再比解码像素 ⇒ **源改了但未 reimport / 未重建 ⇒ 这里红**。需求集真源 = 载体 `BITMAP_ASSETS` 字面条目（⛔ 脚本不抄清单）；关卡缩略图族（`OPEN_ARCS` 展开项）不在本腿范围。
  - 实测（产物 = 10-16 22:47，源 = 10-18 09:51）：18 件**字节相同**（Cocos 原样拷贝 ⇒ 本腿是真等值不是像素近似），只有本单两件 ❌「产物 ≠ 源」⇒ 精确报出「修一半」。
  - **为何不围 CI**：构建产物被 `games/beads/cocos/.gitignore:8 build/` 排除 ⇒ 干净检出无产物 ⇒ 本腿走 SKIP 路径；只有「本地有旧产物」的开发机会红，**这正是该被叫醒的那个人**。因此**不加豁免、保持纯硬**（本单也不得因「只是本地红」而提前关）。
- **判据选型理由**：① 不用绝对误差阈值而用相对比较 —— 投放件是量化产物，绝对差天然漂；② 只比同尺寸正本 —— 跨尺寸 resize 后的差值不是同类比较（收紧后本腿 2.6s → 0.5s）。实测基线（20 件，11 件参与归属判定、9 件无同尺寸可比对象；互异 6 对）：参与件 own ≤ 1.65、他正本 ≥ 5.00；保持率除 arrow 旧态 0.13 外均 1.00。
- **双向已实测（K-089：先验守卫能不能红）**：把两件回刷成旧配方 ⇒ 资产腿 **FAIL / exit 1**，输出「互异保持率 0.13 < 0.5」与「现役 RGBA-octree 配方塌缩」；跑生成器修回 ⇒ 资产腿绿、**产物腿接住红**（包里仍旧）。全链无豁免（初版的 `KNOWN_RED` 机制在修复落地后按 K-025 当场删除，门 = 纯硬）。
- **包体账（本单相关部分）**：两件投放件 2.0K → 2.3K / 2.0K → 2.5K（共 **+0.8 KB**），不改变任何判定档位。今日 `check:size` 实测：**beads 主包 3422.2 KB / 108 文件**（距 4096 红线余量 673.8 KB）、breakout 1886.1 KB / 24 文件。⚠ **自纠**：本单初版与 ADR-0031 §6 初版曾把 **1886.1 KB 误记为 beads 且宣称「重建后不变」**——那实为 breakout 的读数（`check:size` 逐 `games/*` 报，先例见 `production/archive/TASKS-DETAIL-archive.md:4091` 的同型在册自纠）；重建前未留 beads 准确读数，故**不宣称「不变」**，只记今日实测值。该读法坑已入判例 **K-140**（`check:size` 已改为输出行首带游戏名的单行摘要）。
- **另修掉共享 helper 的一处假绿**：`pixelMd5` 原先失败时返回哨兵串 `'解码失败'` ⇒ **两端都失败时相等 = 报绿**。现改为返回 `null` 且比较要求非 null（归属腿批量版同口径）；同文件的「无产物 ⇒ SKIP」早退也会吞掉与产物无关的资产腿红，一并改为先判红再 SKIP（K-036 型）。
