# 《砖阵》(Breakout) 缺陷分级定义 · Bug Severity

- 任务号：WXG-T-004 ｜ 作者：严守真 ｜ 版本 v1.0 ｜ 日期 2026-09-11
- 关联：`test-plan.md`、`test-cases.md`、`smoke-tests.md`

> **分级原则**：严重度看**对玩家的破坏力**（能否继续玩、公平性、能否回来），不看修复成本。**所有示例均为本项目真实场景**。分级为**建议性**——最终取舍由用户/主理人决定。

---

## 分级表

| 级别 | 名称 | 定义（判定标准） | 响应要求 | 发布影响 |
|---|---|---|---|---|
| **P0** | **Blocker 阻断** | 无法启动 / 无法继续游戏 / 数据损坏或丢失 / 崩溃卡死 / 玩法承重墙失效导致**必输或必赢** | 立即修复，阻塞发布 | **阻断发布** |
| **P1** | **Critical 严重** | 核心功能错误但可绕过；明显违背 GDD 验收标准；公平性受损；关键反馈缺失 | 本轮必须修复 | 阻断发布（可申请豁免） |
| **P2** | **Major 主要** | 次要功能错误 / 体验明显退化 / 视觉或音效显著异常；有规避手段 | 排期修复 | 可不阻断，需登记 |
| **P3** | **Minor 次要** | 轻微体验瑕疵、文案/排版、偶发不精确；不影响完成主线 | 有空再修 | 不阻断 |
| **P4** | **Trivial 琐碎** | 吹毛求疵、未来优化、非承诺范围 | 记入 backlog | 不阻断 |

**辅助维度（不改级别，但影响排期）**：`复现率`（必现/偶发）、`影响面`（全机型/特定机型）、`可规避`（有/无 workaround）、`确定性`（是否有 seed）。

## 逐级实例（本项目真实场景）

### P0 · Blocker

| 场景 | 为什么是 P0 | 依据 |
|---|---|---|
| **存档非法导致启动崩溃/卡死**（`currentLevel=99`、`version>1`、半截 JSON） | 玩家**再也进不去游戏**；违反"降级优先于报错" | `save-progress.md §6.3/§6.8/§6.9`、`core-loop.md §6.6` |
| **杀进程后重启无法续进，且从 L1 重来**（丢失进度） | 违反核心承诺"随时能走、回来能继续"；进度即资产 | `save-progress.md §4`、`ux-spec.md §1.4` |
| **钢砖被炸弹破坏 / 可破坏砖清空却不判清关** | 玩法承重墙失效 → **关卡永远无法通关**（必输死局） | `bricks.md §2.6 S`、§6.7 |
| **3 命耗尽不触发 GameOver / 或第 1 次失球就 GameOver** | 生命系统失效，破坏失败-重开闭环 | `life-gameover.md §8` |
| **暂停期间世界仍在动（道具计时/慢放在跑）导致丢命** | 违反"暂停彻底冻结"；玩家因系统而非操作丢命 | `pause-settings.md §2.1/§8` |
| 任意状态**卡死/无法继续**（如 READY 不发球且无输入响应） | 玩家被困，只能杀进程 | `core-loop.md §8` |

### P1 · Critical

| 场景 | 为什么是 P1 | 依据 |
|---|---|---|
| **炸弹波及范围与 GDD 不符**（如把对角 6224 也当命中，或把边界 4624 排除） | 直接改变关卡策略与难度；且视觉/伤害不同符会误导玩家 | `bricks.md §2.6 B`；`assets-spec.md §1.5`"视觉与伤害同符同范围" |
| **`S` 钢砖派发了 `brick:destroyed`**（或计入通关条件） | 违反不可破坏契约；可能误清关或误计分/误掉落 | `bricks.md §2.6 S` |
| **连击倍率阶梯错误**（如 comboStep≠3 或上限≠5） | 经济系统核心数值错误，破坏"越打越爽"与公平性 | `score-combo.md §2.2` |
| **清关与失球同帧判为失球（扣命）** | 玩家因已清空的关卡丢命，严重挫败 | `core-loop.md §6.4`、`life-gameover.md §6.2` |
| **暂停恢复后 READY 自动发球计时被重置** | 恢复语义错误，玩家被"偷走/延长"倒计时 | `pause-settings.md §6.2`（见 Q8） |
| **减弱动效开启后仍播放屏震/粒子**（违反可访问性承诺） | 对前庭敏感玩家造成不适；承诺未兑现 | `assets-spec.md §6.1`、`systems-index §3.7` |
| **减弱动效开启后连命中反馈（白闪/飘字）也一并被关** | 玩家失去命中可读性，玩法受损 | `assets-spec.md §6.2` |
| **`G` 金砖掉落率错误**（如必掉、或未 ×3、或未封顶 1.0） | 违反终裁；经济失衡 | `bricks.md §2.6 G` |
| **重玩第 1 关清除了已解锁关卡/最高分** | 进度资产被误删 | `pause-settings.md §8`、`life-gameover.md §2.4` |
| 高分机/高倍率下**球穿模**（穿墙/穿挡板/穿砖） | 破坏公平与手感；违反 720px/s 验收 | `core-loop.md §8` |

### P2 · Major

| 场景 | 为什么是 P2 | 依据 |
|---|---|---|
| **硬砖受损态视觉不可辨**（黑白/色盲下难区分） | 血量可读性受损，但游戏可继续 | `bricks.md §2.6 T`、`ux-spec.md §7` |
| **重开本关后残留裂纹视觉**（HP 已重置但图未刷新） | 状态误导（玩家以为还是受损态），可继续玩 | `bricks.md §6.6` |
| 道具**同类重复拾取叠加数值**（挡板无限变宽） | 数值失控，非死局 | `powerups.md §2.4` |
| 场上道具 >3 或球数 >9（无上限保护） | 视觉混乱/性能风险 | `powerups.md §6.1`、`systems-index §3.6` |
| **最终结算面板不显示 NEW BEST** | 正向反馈缺失 | `ux-spec.md §3.1/§3.4` |
| 过度动画/无静音开关导致观感差 | 体验退化 | `powerups.md §4` |
| 关卡 `rows` 越界未在开发期断言，静默错位 | 内容隐患，但已发布关卡可玩 | `bricks.md §6.5` |

### P3 · Minor

| 场景 | 为什么是 P3 |
|---|---|
| 分数飘字时长偏离 600ms（如 700ms） | 观感微差，不影响理解 |
| 生命点空心/实心颜色在特定背景对比略低 | 轻微可读性问题 |
| 连击数字从 `×5` 变 `×10` 时 HUD 轻微挤压（未换行但边距紧） | 排版瑕疵，`score-combo.md §6.6` 有约束 |
| 关卡号显示 `3/5` 与实际不一致一帧（同步延迟） | 瞬时不同步 |
| 提示文案"拖动屏幕移动挡板"停留超 1.5s 未淡出 | 轻量体验瑕疵 |

### P4 · Trivial

| 场景 | 为什么是 P4 |
|---|---|
| 未来资产替换提示词（`assets-spec.md §2`）拼写优化 | 非玩家可见 |
| 关卡名"霓虹终章"字数导致首屏换行（若发生） | 文案排版微调 |
| v2 才做的慢放/磁吸/激光参数表 | 非本期范围 |
| 建议给设置页加的说明文案微调 | 文档/文案 |

## 用"钢砖被炸弹破坏"定位示例（任务指定）

**场景**：炸弹爆炸波及 `S` 钢砖，钢砖被扣血/破碎/派发 `brick:destroyed`。

- **定级：P0（Blocker）** —— 但需结合**后果**细分，不能一律 P0：
  - 若导致**关卡无法通关**（钢砖被误计入清关条件后反而算已清 / 或钢砖消失改变了布局使某处可达性丢失）→ **P0**（死局）。
  - 若仅**误派发事件/误加特效**，但钢砖实体未消失、清关判定仍正确 → **P1**（违反契约、可能误计分/误掉落）。
  - 若**仅视觉**：给钢砖播了破碎粒子但砖仍在、无功能影响 → **P2**（视觉误导）。
- **判据来源**：`bricks.md §2.6 S`："炸弹爆炸不对钢砖造成伤害、不破碎、不触发二次爆炸"；`§6.2`："炸弹连锁引爆钢砖 → 钢砖不受爆炸伤害（HP=Infinity）"。
- **报告必带**：`rngSeed`、炸弹与钢砖的 `(row,col)` 与中心坐标、`EXPLODE_R=68` 下的 `d²` 值（判定 4624 边界）。

> **准则**：**功能后果决定级别，"违反文档"本身只作为定性依据**。同一 bug 在不同后果下可升/降级。
