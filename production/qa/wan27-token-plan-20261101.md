# wan2.7-image 在 Token Plan 上的能力实测：补 pro 3.0 的两条缺失（2026-11-01）

> 触发 = 用户令「如果 3.0 pro 真的这么差，wan2.7-image / -pro 是否可以弥补一些能力缺失」，选项 2 = 修文档 + 跑探针包。
> 承接 WXG-T-527（pro 无 mask、无 alpha）与 WXG-T-528（pro ①② 无优势）。
> **选型裁定正本仍是 `model-matrix.md`**，本件只登记证据。

## 1. 结论（三条，其中一条推翻了我上一轮的验收口径）

| 命题 | 结论 | 硬读数 |
|---|---|---|
| **框选局部编辑**（pro 缺的那条腿） | ⚠ **补上了"指引"，没补上"像素锁"**：`parameters.bbox_list` 生效（框内 99.99% 重绘、四组拼豆全清），框外漂移比 pro 无 mask **降 43% 且零平移** ⇒ 回贴可省对齐步骤，但**回贴仍必需** | 框外 meanΔ **7.57**、maxΔ **165**、改动>8 占 **39.03%**；平移 **dx+0 dy+0**（pro 3.0 = MAE 13.26、dx **+8**）；框内 meanΔ 33.86 |
| **真 alpha 抠图** | ⛔ **照样补不上**，且**伪装度更高**：输出 `mode=`**`RGBA`** 但 `alpha=0` 占 **0.00%**、`alpha` min **253** ⇒ 官方文档那句「PNG（不支持透明通道）」是对的，坑在于**通道存在但无语义** | 3/3 样本同读数 |
| **单元素中文短文案** | ✅ **可用**：招牌「拼豆小铺」两 seed + CTA「开始游戏」一发，**8 个汉字逐字全对**，无伪汉字、无拉丁替换 | 目测 3/3；CTA 两端保持纯色木纹（9-slice 可切） |

⇒ **本轮最重要的副产品是判据修正**：WXG-T-527 写进 `wxgame-image-gen §3` 的验收法是「不查 `Image.mode` 就会当成品入库」——**只查 mode 不够**，wan2.7 回的正是 RGBA。验收必须查 **alpha 分布**（`alpha==0` 占比）。

## 4. 与在册裁定的关系（⛔ 三处不得误读）

1. **不翻「整屏多标签必乱」的案**。矩阵 §1 判负的是**整屏多标签**（小字档）；本轮是**单元素短文案**，恰好**支持**在册裁定「单元素短文案可烧进图」（原依据＝本地 25 步 4/4）。本轮只是把它扩到「云 wan2.7 也 3/3、且 12s」。
2. **bbox ≠ mask**。④ 方向的硬判据是「mask 外 maxdiff **必须为 0**」，wan2.7 单发 maxΔ 165 ⇒ **不达标**，必须配回贴。它改善的是"回贴前要不要对齐"这一步。
3. **⑤ 方向不改首选**。目测 wan2.7 的玻璃反光与暖白调**比 527 的 pro 更贴 base**，但那是**单 seed 单图**，且 pro 那张未做 dx+8 对齐 ⇒ 不构成排序依据。要动 §1 ⑤ 首选需同指令、同底图、两 seed 复测。
