# qwen-image-3.0-pro 两条能力验证：局部修改 / 抠图（2026-11-01）

> 触发 = 用户令「使用 Token Plan 中更贵的 pro 3.0 能力验证主界面设计稿局部修改和抠图能力」。
> 端点与参数口径见 `games/beads/design/ai-workflows/backend-token-plan.md` §3；

## 1. 结论（两条，都可机检复现）

| 命题 | 结论 | 依据 |
|---|---|---|
| **局部修改**（定稿别处不许动） | ⚠ **效果达标、机制不达标**：模型无 mask 输入 ⇒ 整图重绘，框外锁不住；**必须配程序化回贴**才可用 | 锁死区（mask 外 74%）MAE **13.26 / 13.64**（两 seed），且整体**右移 8 px**；回贴后锁死区 **maxΔ = 0** |
| **抠图**（输出带透明通道的元件） | ⛔ **判负**：输出 `mode=RGB` **无 alpha 通道**，且把**透明棋盘格画进 RGB**（伪装成成功产物，比"没透明"更危险） | B1 目测 + `Image.mode`；官方文档只给 **2.1 系**标了「自动决定输出带透明通道的图像」 |

⇒ 本地程序化抠（`cut-single-local.py` 第六道机检 **回贴 maxdiff = 0**）**不可替代**，云端无对应能力。

## 2. 实验设置

- 底图 = `games/beads/design/art/proposals/menu-design-v2-20261031/menu-design-master-20261031.png`（752×1344，RGBA，主界面设计稿正本）
- 编辑区 mask = 同目录 `edit-20261031/masks/mask-showcase.png`（白 = 编辑区，占 23.1%；黑 = 保留区）
- 指令（A）= 「把橱窗玻璃内的拼豆图案全部移除，只留空的橱窗背景与底部托盘；画面其余部分（招牌木牌、四个圆形按钮、左右箭头、开始按钮、木屋墙壁）保持原样不变」
- `size=752*1344`（1K 档，与底图同尺寸）、`prompt_extend=False`、seed **42 / 7** 两发
- 判据脚本**全部复用现成件**：`temp/plate-cut-20261031/cloudpaste.py`（最佳平移 + 锁死区 maxΔ/meanΔ）、`paste-back.py`（回贴 maxdiff）

## 3. 读数

| 样本 | 输出尺寸 | 整体平移 | 锁死区 MAE（平移前→后） | 回贴后锁死区 maxΔ | 目测 |
|---|---|---|---|---|---|
| A1 seed 42 | 752×1344 | dx **+8** | 16.72 → **13.26** | **0**（占 74.0%） | 橱窗内四组图案（爱心/猫/蘑菇/星）全清，托盘与层板保留 |
| A2 seed 7 | 752×1344 | dx **+8** | 17.02 → **13.64** | **0**（占 74.0%） | 同上，两 seed 结论一致 |
| B1 seed 42 | 752×1344，**RGB** | — | 全图改动像素 **99.99%**、maxdiff 752 | 不适用（无 alpha） | 招牌被缩小移位 + **背景画成灰白棋盘格** |

三条附带观察（不当判据用）：

1. **中文文字在两发 A 里全部保持正确**（拼豆小铺 / 小猫咪 / 第1关 / 开始）⇒ 但这是"**保留**已有文字"，与矩阵 §5 判负过的"**新写**中文"不是同一命题，⛔ 据此翻案。
2. 云输出把橱窗做成了**两层 + 每层两个托盘**，与在册裁定「只需要一层橱窗，中间单独一个托盘」不符 ⇒ 指令要逐条写死，否则模型按"合理布局"自行加件。
3. 单发即判负（B 未跑第二 seed）：**无 alpha 通道属结构性缺失**，不是抽样运气；矩阵「≥2 seed 才可结论」的铁规针对效果排序与改判，不适用于此。

## 4. 与既有路线的对照（谁该让位）

| 需求 | 现路线 | 本轮证据后的处置 |
|---|---|---|
| 定稿局部微调（擦/换，别处不动） | 本地 qwen-2.1 + mask inpaint（`maxdiff=0`） | **不让位**：云无 mask，只能靠回贴补救，多一道对齐且吃 Credits |
| 平涂带上擦矩形元素 | 程序化 `remove-box-fill.py`（复现 maxΔ 0） | **不让位**：零成本、确定性 |
| **背景有结构**的剔除（橱窗内有层板/托盘） | 程序化不适用 → 本地 inpaint | ⚠ **云 pro + 回贴是可用备选**：本轮两发都干净剔除了图案且未破框外（回贴后），代价 = 1 张 Credits + 8 px 对齐 |
| 元件抠图（真 alpha 切图） | 本地 PIL 洪水填充 + 回贴 maxdiff=0 | **不让位**：云端无此能力，且会画假透明 |
